# MegooArti for coding agents

- Branch off `develop`, and open pull requests into `develop`. `main` changes only at a
  release.
- Never change the version (`VERSION`, `backend/pyproject.toml`,
  `backend/src/megooarti/__init__.py`, `frontend/package.json`) outside a release.
- Push only when you are told "push".
- Release only when you are told "release", and then follow
  [docs/releasing.md](docs/releasing.md) step by step.
- How to run MegooArti from source, the tests and the rules of the code are in
  [docs/development.md](docs/development.md).
- The web UI has rules of its own: [frontend/AGENTS.md](frontend/AGENTS.md).
