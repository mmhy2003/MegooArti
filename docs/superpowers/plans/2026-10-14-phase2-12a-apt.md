# APT Repositories Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** apt on Debian and Ubuntu installs from a hosted APT repository whose indexes MegooArti writes and signs with a key of the repository's own, and through a proxy of a distribution's mirror.

**Architecture:** A `.deb` is read once, as it is uploaded: its `control` file is kept in the asset's attributes, and the package is stored at its pool path. A hosted repository of a format that writes its indexes counts its changes (a revision in its row, raised in the transaction of each change); its `Packages` and `Release` files are written from a snapshot of one revision, in a worker thread, signed with the repository's OpenPGP key, and kept in memory by repository and revision. The key is made the first time it is needed, sealed like a proxy's password, and can be replaced through the API. A proxy is the generic engine, with the mirror's `dists/` as metadata.

**Tech Stack:** Python 3.13, FastAPI, SQLAlchemy 2 (async), PostgreSQL 17, Alembic; `pysequoia` (OpenPGP, Sequoia), `zstandard`; pytest; Docker images `debian:13` and `ubuntu:26.04` for the real-client tests.

**Spec:** [docs/superpowers/specs/2026-10-14-linux-package-formats-design.md](../specs/2026-10-14-linux-package-formats-design.md), sections 3 (D1–D7, A1–A4), 4, 5.1–5.3, 9, 10, 11 and the row of plan 12a in section 12. Groups (5.4) are plan 12b; the web UI is plan 12e.

## Decisions this plan settles

| # | Decision | Reason |
| --- | --- | --- |
| P1 | OpenPGP is done with `pysequoia` 0.1.35, not GnuPG. It installs as a wheel for Windows and for Linux on amd64 and arm64, generates Ed25519 and RSA 4096 keys that never expire, signs clear and detached, and reads a key exported by GnuPG. Task 6 shows apt on Debian 13 and Ubuntu 26.04 verifying what it signed. The wheel has Sequoia's library built in, which is LGPL-2.0-or-later; MegooArti's own code stays MIT and uses it as a library. | Spec section 11: decided by a test that apt verifies what was signed. GnuPG would be a program in the image and a process for every signature. |
| P2 | A key is made the first time it is needed (an index, the public key, or `GET .../signing-key`), not in the request that makes the repository. Two requests that find none at once each make one, and the first stored is kept. | One path for every repository, however it was made, and for those that exist before an upgrade. Spec 4.2 says "made with the repository"; to whoever uses it the two cannot be told apart. |
| P3 | `InRelease` signs `Release` without its last line ending, as GnuPG does: Sequoia would otherwise sign a blank line more than `Release` has. | What apt reads out of `InRelease` is then `Release` exactly. |
| P4 | `Packages` is written byte for byte as `dpkg-scanpackages` writes it: the control fields in the package's order, `Filename`, `Size`, `MD5sum`, `SHA1` and `SHA256` before the first of `Section`, `Priority`, `Multi-Arch`, `Homepage`, `Description` and `Tag`, and a blank line after every paragraph. `Release` lists `MD5Sum` and `SHA256`. | Spec 10 asks for the indexes to be held against what the format's own tools write; `data/Packages.scanned` is what dpkg-scanpackages 1.22 wrote of four real packages. |
| P5 | A component is a package's name and its version with its epoch (`1:2.0~rc1-1`), read from what was kept of its `control`; a proxy's package, which has nothing kept, is read from its file's name, without the epoch. `describe_component` is given the file's attributes for this (spec 4.1), in this plan and not in plan 12c. | The usage snippet `apt install name=version` needs the epoch, and the pool path has none. |
| P6 | The revision is raised after a path's lock and before a blob's or a component's, in every change to such a repository, and also when its key is replaced. A snapshot reads the revision before and after the files and reads again if they differ (at most five times, then `503 repository_busy`). | Two changes to one repository then wait for each other in one order, and an index never names a file its revision does not have. |
| P7 | A file read from a staged upload is closed as soon as what is needed was read. | On Windows a file that is still open can be neither moved into the store nor removed: the refusal of a broken package answered `500`. |
| P8 | The changelog is not changed. | Its first heading must be this version (a test says so). What plan 12a adds is written there when the version that has it is released. |

## Global Constraints

- **A format never touches a table or a file:** it works through the repository context. New context methods: `revision()`, `snapshot()`, `open_staged()`.
- **What is read of an uploaded package is bounded** (spec 9): a `.deb`'s control archive at 16 MiB, packed and unpacked.
- **No answer carries a private key.** The private key is stored sealed with `secrets_box.seal` (`enc:v1:…`).
- **Every test of a stack is marked `docker`** and reaches the stack through the gateway (`http://gateway` from a container, `http://127.0.0.1:18000` from the tests).
- **A table's line under its headings is `| --- | --- |`.**
- **Commits end with** `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

**Working directories:** run `uv` and `pytest` commands in `backend/`, `pnpm` commands in `frontend/`, and `git` commands in the repository root. Backend tests need the `db` Compose service; set `MEGOOARTI_TEST_DATABASE_URL` as `docs/development.md` describes.

## Review Focus

What the tests of this plan do not reach, most likely first. The reviewer reads for these.

1. **A package that says something unexpected in its `control`**: fields in another order, continuation lines, a field an index writes itself, characters a client would read as the start of a field. It must not change what an index says of another package, nor of its own file.
2. **Two uploads, or an upload and a delete, at the same moment in one repository**: the revision, the component's architectures, and the snapshot an index is written from.
3. **A repository with many packages**: the index is written in a worker thread and kept, but a snapshot reads every file's row; the first request after a change pays for it.
4. **apt's own checks that the tests do not make**: a `Date` that goes backwards after a key is replaced or a package deleted, a suite whose name another client already knows, a client that only reads `Release` and `Release.gpg`.
5. **The key's lifetime**: replaced while a client is between `InRelease` and `Packages`, unreadable after the secret key changed, imported with a subkey that only certifies.

```python
"""Debian packages made in memory, as dpkg-deb writes them, and the real ones it wrote."""

import gzip
import io
import lzma
import tarfile
from collections.abc import AsyncIterator
from pathlib import Path

import zstandard

DATA = Path(__file__).parent / "data"
# Four packages dpkg-deb 1.22 wrote, one for each way it compresses a control archive,
# and the index dpkg-scanpackages wrote of them. `data/make.sh` says how.
REAL = {
    "gzip": "megooarti-hello_1.0-1_all.deb",
    "xz": "megooarti-hello_2.0~rc1-1_amd64.deb",
    "zstd": "megooarti-tool_0.3_arm64.deb",
    "none": "megooarti-plain_1.0_amd64.deb",
}


def control_text(
    package: str = "megooarti-hello",
    version: str = "1.0-1",
    architecture: str = "all",
    description: str = "Says hello\n A package made for the tests.",
    extra: str = "",
) -> str:
    return (
        f"Package: {package}\nVersion: {version}\nArchitecture: {architecture}\n"
        "Maintainer: MegooArti Tests <tests@example.com>\nInstalled-Size: 1\n"
        f"{extra}Description: {description}\n"
    )


def ar(members: list[tuple[str, bytes]]) -> bytes:
    """An ar archive, as dpkg-deb writes one."""
    out = bytearray(b"!<arch>\n")
    for name, data in members:
        header = f"{name:<16}{0:<12}{0:<6}{0:<6}{100644:<8}{len(data):<10}`\n"
        out += header.encode("ascii") + data + (b"\n" if len(data) % 2 else b"")
    return bytes(out)


def tar_of(files: dict[str, bytes]) -> bytes:
    buffer = io.BytesIO()
    with tarfile.open(fileobj=buffer, mode="w", format=tarfile.GNU_FORMAT) as tar:
        for name, data in files.items():
            entry = tarfile.TarInfo(name)
            entry.size = len(data)
            tar.addfile(entry, io.BytesIO(data))
    return buffer.getvalue()


def compressed(data: bytes, compression: str) -> tuple[str, bytes]:
    """The control archive's name and bytes for a way of compressing it."""
    if compression == "gz":
        return "control.tar.gz", gzip.compress(data, mtime=0)
    if compression == "xz":
        return "control.tar.xz", lzma.compress(data)
    if compression == "zst":
        return "control.tar.zst", zstandard.ZstdCompressor().compress(data)
    return "control.tar", data


def make_deb(
    control: str | None = None,
    *,
    compression: str = "gz",
    data: bytes = b"the files of the package",
    before_control: list[tuple[str, bytes]] | None = None,
) -> bytes:
    """A package whose control file is `control`, compressed as dpkg-deb can."""
    archive = tar_of({"./control": (control or control_text()).encode()})
    name, packed = compressed(archive, compression)
    return ar(
        [
            ("debian-binary", b"2.0\n"),
            *(before_control or []),
            (name, packed),
            ("data.tar.xz", lzma.compress(data)),
        ]
    )


async def pieces(data: bytes, size: int = 7) -> AsyncIterator[bytes]:
    """Bytes as they arrive: a few at a time."""
    for start in range(0, len(data), size):
        yield data[start : start + size]
```

```python
import pytest

from megooarti.repositories.apt import control

TEXT = """Package: megooarti-hello
Version: 1.0-1
Depends: libc6 (>= 2.17)
Description: Says hello
 A package made for the tests.
 .
 It prints one line.
"""


def test_a_paragraph_is_read_field_by_field_and_written_back_as_it_was():
    paragraph = control.parse(TEXT)

    assert [name for name, _ in paragraph] == ["Package", "Version", "Depends", "Description"]
    assert control.get(paragraph, "description") == (
        "Says hello\n A package made for the tests.\n .\n It prints one line."
    )
    assert control.format_paragraph(paragraph) == TEXT


def test_a_value_that_begins_on_the_next_line_is_written_so():
    paragraph = control.parse("Package: a\nConffiles:\n /etc/a abc\n")

    assert control.get(paragraph, "Conffiles") == "\n /etc/a abc"
    assert control.format_paragraph(paragraph) == "Package: a\nConffiles:\n /etc/a abc\n"


def test_comments_blank_lines_around_and_trailing_spaces_go():
    paragraph = control.parse("# made by hand\n\nPackage:  a  \nVersion: 1\t\n\n\n")

    assert paragraph == [("Package", "a"), ("Version", "1")]


def test_a_field_is_found_whatever_the_case_of_its_name():
    assert control.get(control.parse("package: a\n"), "Package") == "a"
    assert control.get(control.parse("Package: a\n"), "Version") is None


@pytest.mark.parametrize(
    ("text", "said"),
    [
        ("", "it has no fields"),
        ("Package: a\n\nPackage: b\n", "more than one paragraph"),
        (" continued\nPackage: a\n", "begins with a continuation line"),
        ("Package: a\nPackage: b\n", "given twice"),
        ("Package: a\npackage: b\n", "given twice"),
        ("Package: a\r\n", "carriage return"),
        ("Package a\n", "is not a field"),
        ("-----BEGIN PGP SIGNED MESSAGE-----\n", "is not a field"),
        ("Pack age: a\n", "is not a field"),
    ],
)
def test_text_that_is_not_one_paragraph_is_refused(text, said):
    with pytest.raises(control.InvalidControl, match=said):
        control.parse(text)


def test_a_continuation_line_cannot_begin_a_field_of_its_own():
    paragraph = control.parse("Package: a\nDescription: x\n Filename: ../../etc/passwd\n")

    assert control.get(paragraph, "Filename") is None
```

```python
    ar,
    compressed,
    control_text,

def scanned() -> dict[str, control.Paragraph]:
    """The paragraphs dpkg-scanpackages wrote, by file name."""
    text = (DATA / "Packages.scanned").read_text(encoding="utf-8")
    paragraphs = [control.parse(part) for part in text.split("\n\n") if part.strip()]
    return {
        control.get(paragraph, "Filename").removeprefix("./"): paragraph for paragraph in paragraphs
    }


@pytest.mark.parametrize("compression", sorted(REAL))
async def test_a_package_dpkg_deb_wrote_says_what_dpkg_scanpackages_read_of_it(compression):
    filename = REAL[compression]
    expected = scanned()[filename.replace("2.0~rc1-1", "1:2.0~rc1-1")]

    deb = await debs.read(pieces((DATA / filename).read_bytes(), size=100))

    without_index = [field for field in expected if field[0].lower() not in debs.INDEX_FIELDS]
    assert sorted(deb.control) == sorted(without_index)
    assert (deb.package, deb.version) == (
        control.get(expected, "Package"),
        control.get(expected, "Version"),
```

```python
"""A Debian control paragraph: fields, in order, as `control` files and `Packages` have them.

A value keeps its continuation lines, each beginning with a space, so that writing a
paragraph again gives back what was read. A continuation line cannot begin a field of
its own: whatever a package says, it cannot add a field to an index it is listed in.
"""

import re

# A field's name: printable, without a colon or a space, and not beginning with `#`
# or `-`, which a control file uses for comments and for signatures.
_NAME = re.compile(r"[!-9;-~][!-9;-~]*")
_LINE = re.compile(r"([^:\s]+):(.*)")

type Paragraph = list[tuple[str, str]]


class InvalidControl(ValueError):
    """Text that is not one control paragraph."""


def parse(text: str) -> Paragraph:
    """The fields of one paragraph, in order. Comments and blank lines around it go."""
    fields: Paragraph = []
    seen: set[str] = set()
    ended = False
    for line in text.split("\n"):
        if "\r" in line:
            raise InvalidControl("a line ends in a carriage return")
        if line.startswith("#"):
            continue
        if not line.strip():
            ended = ended or bool(fields)
            continue
        if ended:
            raise InvalidControl("there is more than one paragraph")
        if line[0] in " \t":
            if not fields:
                raise InvalidControl("it begins with a continuation line")
            name, value = fields[-1]
            fields[-1] = (name, f"{value}\n{line.rstrip()}")
            continue
        found = _LINE.fullmatch(line)
        if found is None or _NAME.fullmatch(found[1]) is None or found[1][0] in "#-":
            raise InvalidControl(f"a line is not a field: {line[:60]!r}")
        name = found[1]
        if name.lower() in seen:
            raise InvalidControl(f"the field {name} is given twice")
        seen.add(name.lower())
        fields.append((name, found[2].strip()))
    if not fields:
        raise InvalidControl("it has no fields")
    return fields


def get(paragraph: Paragraph, name: str) -> str | None:
    """A field's value, whatever the case of its name. None if it is not there."""
    wanted = name.lower()
    return next((value for field, value in paragraph if field.lower() == wanted), None)


def first_line(value: str) -> str:
    return value.partition("\n")[0]


def format_paragraph(paragraph: Paragraph) -> str:
    """The paragraph as text, each field on its line, without a blank line after it."""
    lines = []
    for name, value in paragraph:
        lines.append(f"{name}:{value}" if value.startswith("\n") else f"{name}: {value}")
    return "\n".join(lines) + "\n"
```

```python
"""Debian package names, versions and architectures, and the order dpkg puts versions in.

A version is `[epoch:]upstream[-revision]`. Two versions are compared as dpkg compares
them: the epoch as a number, then the upstream part and the revision piece by piece,
with `~` before everything, even the end.
"""

import re
from functools import cmp_to_key

NAME = re.compile(r"[a-z0-9][a-z0-9+.-]+")
ARCHITECTURE = re.compile(r"[a-z0-9][a-z0-9-]*")
_UPSTREAM = re.compile(r"[0-9][A-Za-z0-9.+~-]*")
_REVISION = re.compile(r"[A-Za-z0-9.+~]+")
_EPOCH = re.compile(r"[0-9]{1,9}")
_LONGEST = 255


def split(version: str) -> tuple[int, str, str] | None:
    """Epoch, upstream part and revision, or None for a version dpkg would refuse.

    A colon in the upstream part is refused as well: the part is in the file's name.
    """
    if not version or len(version) > _LONGEST:
        return None
    epoch, colon, rest = version.partition(":")
    if not colon:
        epoch, rest = "0", version
    elif _EPOCH.fullmatch(epoch) is None:
        return None
    upstream, hyphen, revision = rest.rpartition("-")
    if not hyphen:
        upstream, revision = rest, ""
    elif _REVISION.fullmatch(revision) is None:
        return None
    if _UPSTREAM.fullmatch(upstream) is None:
        return None
    return int(epoch), upstream, revision


def without_epoch(version: str) -> str:
    """The version as a file's name has it."""
    return version.partition(":")[2] if ":" in version else version


def _order(character: str) -> int:
    if character == "~":
        return -1
    if character.isalpha():
        return ord(character)
    return ord(character) + 256


def _compare_part(left: str, right: str) -> int:
    """dpkg's `verrevcmp`: letters before non-letters, `~` before all, digits as numbers."""
    i = j = 0
    while i < len(left) or j < len(right):
        difference = 0
        while (i < len(left) and not left[i].isdigit()) or (
            j < len(right) and not right[j].isdigit()
        ):
            ours = _order(left[i]) if i < len(left) and not left[i].isdigit() else 0
            theirs = _order(right[j]) if j < len(right) and not right[j].isdigit() else 0
            if ours != theirs:
                return -1 if ours < theirs else 1
            i += 1
            j += 1
        while i < len(left) and left[i] == "0":
            i += 1
        while j < len(right) and right[j] == "0":
            j += 1
        while i < len(left) and left[i].isdigit() and j < len(right) and right[j].isdigit():
            if not difference:
                difference = ord(left[i]) - ord(right[j])
            i += 1
            j += 1
        if i < len(left) and left[i].isdigit():
            return 1
        if j < len(right) and right[j].isdigit():
            return -1
        if difference:
            return -1 if difference < 0 else 1
    return 0


def compare(left: str, right: str) -> int:
    """-1, 0 or 1, as dpkg orders two valid versions."""
    ours, theirs = split(left), split(right)
    if ours is None or theirs is None:
        raise ValueError("only valid versions are compared")
    if ours[0] != theirs[0]:
        return -1 if ours[0] < theirs[0] else 1
    return _compare_part(ours[1], theirs[1]) or _compare_part(ours[2], theirs[2])


version_key = cmp_to_key(compare)
```

Create `backend/src/megooarti/repositories/apt/debs.py`:

```python
"""What a `.deb` says of itself: the `control` file inside it.

A `.deb` is an `ar` archive of three members, in this order: `debian-binary`, the
control archive (`control.tar`, compressed with gzip, xz, zstd or nothing), and the
files. Only the first two are read, as the package arrives or from where it was
stored: the files, which can be gigabytes, are never looked at. What is read is
bounded, so a package cannot make the server hold or unpack more than a few megabytes.
"""

import io
import lzma
import tarfile
import zlib
from collections.abc import AsyncIterator
from dataclasses import dataclass

import zstandard

from megooarti.repositories.apt import control, versions

# The most of the control archive that is read, packed and unpacked: a real one is a
# few kilobytes.
CONTROL_MOST = 16 * 1024 * 1024
_MAGIC = b"!<arch>\n"
_HEADER = 60
# Fields the server writes into an index itself: a package cannot say them.
INDEX_FIELDS = frozenset({"filename", "size", "md5sum", "sha1", "sha256", "sha512"})


class InvalidPackage(ValueError):
    """Bytes that are not a Debian package the server can list."""


@dataclass(frozen=True)
class Deb:
    """What a package says of itself."""

    control: control.Paragraph
    package: str
    version: str
    architecture: str


class _Reader:
    """Bytes from pieces, a given number at a time."""

    def __init__(self, chunks: AsyncIterator[bytes]) -> None:
        self._chunks = chunks
        self._held = bytearray()

    async def exactly(self, count: int) -> bytes:
        while len(self._held) < count:
            chunk = await anext(self._chunks, None)
            if chunk is None:
                raise InvalidPackage("it ends early")
            self._held += chunk
        taken = bytes(self._held[:count])
        del self._held[:count]
        return taken

    async def skip(self, count: int) -> None:
        while count > 0:
            if not self._held:
                chunk = await anext(self._chunks, None)
                if chunk is None:
                    raise InvalidPackage("it ends early")
                self._held += chunk
            dropped = min(count, len(self._held))
            del self._held[:dropped]
            count -= dropped


async def _member(reader: _Reader) -> tuple[str, int]:
    """The next member's name and size."""
    header = await reader.exactly(_HEADER)
    if header[58:60] != b"`\n":
        raise InvalidPackage("it is not an ar archive")
    name = header[0:16].decode("ascii", "replace").rstrip(" ").rstrip("/")
    size_text = header[48:58].decode("ascii", "replace").strip()
    if not size_text.isdigit():
        raise InvalidPackage("a member of it has no size")
    return name, int(size_text)


def _unpacked(name: str, packed: bytes) -> bytes:
    """The control archive, decompressed as its name says, and no larger than allowed."""
    try:
        if name == "control.tar":
            data = packed
        elif name == "control.tar.gz":
            data = zlib.decompressobj(wbits=47).decompress(packed, CONTROL_MOST + 1)
        elif name == "control.tar.xz":
            data = lzma.LZMADecompressor().decompress(packed, CONTROL_MOST + 1)
        elif name == "control.tar.zst":
            reader = zstandard.ZstdDecompressor().stream_reader(io.BytesIO(packed))
            data = b""
            while len(data) <= CONTROL_MOST:
                piece = reader.read(CONTROL_MOST + 1 - len(data))
                if not piece:
                    break
                data += piece
        else:
            raise InvalidPackage(f"its control archive is {name}, which is not one dpkg writes")
    except (zlib.error, lzma.LZMAError, zstandard.ZstdError) as error:
        raise InvalidPackage(f"its control archive cannot be unpacked: {error}") from None
    if len(data) > CONTROL_MOST:
        raise InvalidPackage("its control archive is larger than this server reads")
    return data


def _control_file(archive: bytes) -> str:
    try:
        with tarfile.open(fileobj=io.BytesIO(archive), mode="r:") as tar:
            for entry in tar:
                if entry.isfile() and entry.name in ("control", "./control"):
                    data = tar.extractfile(entry).read()
                    break
            else:
                raise InvalidPackage("its control archive has no control file")
    except tarfile.TarError as error:
        raise InvalidPackage(f"its control archive is not a tar archive: {error}") from None
    try:
        return data.decode("utf-8")
    except UnicodeDecodeError:
        raise InvalidPackage("its control file is not UTF-8") from None


def describe(text: str) -> Deb:
    """What a control file says, checked as dpkg would check a binary package's."""
    try:
        paragraph = control.parse(text)
    except control.InvalidControl as error:
        raise InvalidPackage(f"its control file is not valid: {error}") from None
    said = {name: control.get(paragraph, name) for name in ("Package", "Version", "Architecture")}
    for name, value in said.items():
        if not value:
            raise InvalidPackage(f"its control file has no {name}")
    package, version, architecture = said["Package"], said["Version"], said["Architecture"]
    if versions.NAME.fullmatch(package) is None:
        raise InvalidPackage(f"{package[:60]!r} is not a Debian package name")
    if versions.split(version) is None:
        raise InvalidPackage(f"{version[:60]!r} is not a Debian version")
    if architecture == "any" or versions.ARCHITECTURE.fullmatch(architecture) is None:
        raise InvalidPackage(f"{architecture[:60]!r} is not an architecture")
    kept = [(name, value) for name, value in paragraph if name.lower() not in INDEX_FIELDS]
    return Deb(kept, package, version, architecture)


async def read(chunks: AsyncIterator[bytes]) -> Deb:
    """What the package in these pieces says of itself. Raises InvalidPackage."""
    reader = _Reader(chunks)
    if await reader.exactly(len(_MAGIC)) != _MAGIC:
        raise InvalidPackage("it is not an ar archive")
    name, size = await _member(reader)
    if name != "debian-binary" or size > 16:
        raise InvalidPackage("it does not begin with debian-binary")
    if not (await reader.exactly(size)).startswith(b"2."):
        raise InvalidPackage("it is not in the format dpkg 2 writes")
    await reader.skip(size % 2)
    while True:
        name, size = await _member(reader)
        if not name.startswith("_"):  # a member for tools, which dpkg skips
            break
        await reader.skip(size + size % 2)
    if not name.startswith("control.tar"):
        raise InvalidPackage("its second member is not the control archive")
    if size > CONTROL_MOST:
        raise InvalidPackage("its control archive is larger than this server reads")
    return describe(_control_file(_unpacked(name, await reader.exactly(size))))
```

```python
"""What a path of an APT repository is, and where a package is kept.

The standard layout, as Debian's mirrors have it:

    dists/<suite>/InRelease, Release, Release.gpg
    dists/<suite>/main/binary-<arch>/Packages, Packages.gz, Packages.xz
    pool/main/<letter>/<package>/<package>_<version>_<arch>.deb

plus `public.key`, the key a hosted repository signs with. The root is where a
package is uploaded.
"""

import re
from dataclasses import dataclass

from megooarti.repositories.apt import versions

COMPONENT = "main"
SUITE = re.compile(r"[A-Za-z0-9][A-Za-z0-9._-]{0,63}")
RELEASE_FILES = ("InRelease", "Release", "Release.gpg")
PACKAGES_FILES = {"Packages": "", "Packages.gz": "gz", "Packages.xz": "xz"}
PUBLIC_KEY = "public.key"
_PACKAGES = re.compile(r"dists/([^/]+)/([^/]+)/binary-([^/]+)/(Packages(?:\.gz|\.xz)?)")
_RELEASE = re.compile(r"dists/([^/]+)/(InRelease|Release|Release\.gpg)")


@dataclass(frozen=True)
class AptPath:
    # upload (the root), key, release, packages, pool, dists (anything else there), other
    kind: str
    suite: str = ""
    filename: str = ""
    component: str = ""
    architecture: str = ""


def classify(path: str) -> AptPath:
    if path == "":
        return AptPath("upload")
    if path == PUBLIC_KEY:
        return AptPath("key")
    found = _RELEASE.fullmatch(path)
    if found is not None:
        return AptPath("release", suite=found[1], filename=found[2])
    found = _PACKAGES.fullmatch(path)
    if found is not None:
        return AptPath(
            "packages",
            suite=found[1],
            component=found[2],
            architecture=found[3],
            filename=found[4],
        )
    if path.startswith("dists/"):
        return AptPath("dists")
    if path.startswith("pool/") and path.endswith(".deb"):
        return AptPath("pool")
    return AptPath("other")


def letter(package: str) -> str:
    """The pool's directory for a package: its first letter, or four for a library."""
    return package[:4] if package.startswith("lib") and len(package) > 3 else package[0]


def pool_path(package: str, version: str, architecture: str) -> str:
    """Where a package is kept: Debian's file name, without the version's epoch."""
    filename = f"{package}_{versions.without_epoch(version)}_{architecture}.deb"
    return f"pool/{COMPONENT}/{letter(package)}/{package}/{filename}"


def in_pool(path: str) -> tuple[str, str, str] | None:
    """The package, version and architecture a package's file name says, or None.

    A mirror keeps a package under its source package's directory, which may have
    another name, so only the file's own name is read. Its version has no epoch.
    """
    if not path.startswith("pool/") or not path.endswith(".deb"):
        return None
    parts = path.rpartition("/")[2].removesuffix(".deb").split("_")
    if len(parts) != 3 or not all(parts):
        return None
    package, version, architecture = parts
    return package, version, architecture
```

```python
"""The index files of a hosted APT repository, written from what its packages said.

`Packages` lists each package as dpkg-scanpackages does: its control fields, with
`Filename`, `Size` and the checksums before `Section`. `Release` names every
`Packages` file with its size and checksums. Both are written the same way for the
same packages, byte for byte, so a client that has them already is told so.
"""

import gzip
import hashlib
import lzma
from collections.abc import Iterable, Sequence
from dataclasses import dataclass
from datetime import UTC, datetime

from megooarti.repositories.apt import control, versions
from megooarti.repositories.apt.paths import COMPONENT

# Where a package's file and checksums go: before the first of these, as dpkg puts them.
_AFTER_FILE = frozenset({"section", "priority", "multi-arch", "homepage", "description", "tag"})
# Listed when a repository has no package of any one architecture, so that a client
# of either of the two most common ones finds the packages for all of them.
DEFAULT_ARCHITECTURES = ("amd64", "arm64")
_DAYS = ("Mon", "Tue", "Wed", "Thu", "Fri", "Sat", "Sun")
_MONTHS = ("Jan", "Feb", "Mar", "Apr", "May", "Jun", "Jul", "Aug", "Sep", "Oct", "Nov", "Dec")


@dataclass(frozen=True)
class Listed:
    """A package as an index lists it: what it said of itself, and where its file is."""

    path: str
    size: int
    md5: str
    sha1: str
    sha256: str
    control: control.Paragraph
    package: str
    version: str
    architecture: str


def entry(listed: Listed) -> str:
    """A package's paragraph in `Packages`."""
    file = [
        ("Filename", listed.path),
        ("Size", str(listed.size)),
        ("MD5sum", listed.md5),
        ("SHA1", listed.sha1),
        ("SHA256", listed.sha256),
    ]
    fields = list(listed.control)
    at = next((i for i, (name, _) in enumerate(fields) if name.lower() in _AFTER_FILE), len(fields))
    return control.format_paragraph(fields[:at] + file + fields[at:])


def _order(listed: Listed) -> tuple:
    return (listed.package, versions.version_key(listed.version), listed.architecture)


def packages(listed: Iterable[Listed]) -> bytes:
    """A `Packages` file: the paragraphs, in order of name, version and architecture.

    Each ends with a blank line, the last one too, as dpkg-scanpackages writes them.
    """
    return "".join(entry(one) + "\n" for one in sorted(listed, key=_order)).encode()


def architectures(listed: Iterable[Listed]) -> list[str]:
    """The architectures a repository lists: those of its packages but `all`."""
    found = sorted({one.architecture for one in listed} - {"all"})
    return found or list(DEFAULT_ARCHITECTURES)


def packages_files(listed: Sequence[Listed]) -> dict[str, bytes]:
    """Every `Packages` file of the component, by its path under the suite.

    A package for all architectures is listed under each of them.
    """
    files = {}
    for architecture in architectures(listed):
        mine = [one for one in listed if one.architecture in (architecture, "all")]
        text = packages(mine)
        directory = f"{COMPONENT}/binary-{architecture}"
        files[f"{directory}/Packages"] = text
        files[f"{directory}/Packages.gz"] = gzip.compress(text, compresslevel=9, mtime=0)
        files[f"{directory}/Packages.xz"] = lzma.compress(text)
    return files


def date(moment: datetime) -> str:
    """A moment as `Release` writes it, whatever the locale."""
    utc = moment.astimezone(UTC)
    day, month = _DAYS[utc.weekday()], _MONTHS[utc.month - 1]
    return f"{day}, {utc.day:02d} {month} {utc.year} {utc:%H:%M:%S} UTC"


def release(
    *,
    label: str,
    suite: str,
    moment: datetime,
    architectures: Sequence[str],
    files: dict[str, bytes],
) -> bytes:
    """The `Release` file of a suite whose index files are `files`."""
    lines = [
        "Origin: MegooArti",
        f"Label: {label}",
        f"Suite: {suite}",
        f"Codename: {suite}",
        f"Date: {date(moment)}",
        f"Architectures: {' '.join(architectures)}",
        f"Components: {COMPONENT}",
        "Acquire-By-Hash: no",
    ]
    for heading, algorithm in (("MD5Sum", "md5"), ("SHA256", "sha256")):
        lines.append(f"{heading}:")
        for path, data in sorted(files.items()):
            lines.append(f" {hashlib.new(algorithm, data).hexdigest()} {len(data):>16} {path}")
    return ("\n".join(lines) + "\n").encode()
```

```python
"""Index files written from a snapshot of a repository, kept in this process.

They are kept by repository and revision: a revision's files are the same whenever
they are written, so once written they are served until the repository changes. A new
revision makes the old files unreachable, and the least recently used go first. Each
process keeps its own; two that write the same revision write the same bytes, but for
the signatures, which are each valid.
"""

import uuid
from collections import OrderedDict

# How many revisions' files are kept, of every repository together.
MOST = 32

type Files = dict[str, bytes]

_kept: OrderedDict[tuple[uuid.UUID, int], Files] = OrderedDict()


def get(repository_id: uuid.UUID, revision: int) -> Files | None:
    key = (repository_id, revision)
    files = _kept.get(key)
    if files is not None:
        _kept.move_to_end(key)
    return files


def put(repository_id: uuid.UUID, revision: int, files: Files) -> None:
    _kept[(repository_id, revision)] = files
    _kept.move_to_end((repository_id, revision))
    while len(_kept) > MOST:
        _kept.popitem(last=False)


def forget() -> None:
    """Drop everything kept. For tests."""
    _kept.clear()
```

```python
"""The keys repositories sign their indexes with.

A hosted repository of a format that signs has one key. It is made the first time it
is needed, so that every repository has one however it was made; an administrator may
generate another, or import their own. The private key is sealed with the
installation's secret key, as a proxy's password is, and no answer ever carries it.
A new key is a new revision of the repository: its indexes are signed again with it.

OpenPGP is done by Sequoia (`pysequoia`), whose signatures apt and dnf verify.
"""

import asyncio
from dataclasses import dataclass

import pysequoia
import structlog
from sqlalchemy import select, update
from sqlalchemy.dialects.postgresql import insert
from sqlalchemy.ext.asyncio import AsyncSession

from megooarti.clock import utcnow
from megooarti.config import Settings
from megooarti.errors import ApiError
from megooarti.repositories.formats import get_format
from megooarti.repositories.models import Repository, SigningKey
from megooarti.secrets_box import SecretUnreadable, seal, unseal

log = structlog.get_logger(__name__)

OPENPGP = "openpgp"
# What an administrator may ask for when generating a key, and what it is made with.
GENERATED = {"ed25519": pysequoia.CipherSuite.Cv25519, "rsa4096": pysequoia.CipherSuite.RSA4k}
DEFAULT_ALGORITHM = "ed25519"
# What an imported key's algorithm is called, by what Sequoia calls it.
_IMPORTED = {"EdDSA": "ed25519", "Ed25519": "ed25519", "RSAEncryptSign": "rsa", "RSASign": "rsa"}


class KeyUnusable(ValueError):
    """Text that is not a private key this server can sign with."""


@dataclass(frozen=True)
class Material:
    """A key as it is stored, before its private part is sealed."""

    algorithm: str
    fingerprint: str
    public_key: str
    private_key: str


def _signer(private_key: str) -> object:
    return pysequoia.Tsk.from_bytes(private_key.encode()).signer()


def _algorithm(signer: object) -> str:
    detached = pysequoia.sign(signer, b"", mode=pysequoia.SignatureMode.DETACHED)
    named = str(pysequoia.Sig.from_bytes(detached).key_algorithm).rpartition(".")[2]
    return _IMPORTED.get(named, named.lower())


def generate_openpgp(user_id: str, algorithm: str = DEFAULT_ALGORITHM) -> Material:
    """A new key that never expires, with a subkey that signs."""
    secret = pysequoia.Tsk.generate(
        user_id, profile=pysequoia.Profile.RFC4880, cipher_suite=GENERATED[algorithm]
    )
    certificate = secret.extract_certificate()
    return Material(algorithm, certificate.fingerprint.upper(), str(certificate), str(secret))


def read_openpgp(private_key: str) -> Material:
    """An administrator's key, checked: it must be private, unprotected, and able to sign."""
    try:
        secret = pysequoia.Tsk.from_bytes(private_key.encode())
        signer = secret.signer()
    except RuntimeError as error:
        said = str(error)
        if "encrypted" in said:
            raise KeyUnusable(
                "The key is protected by a passphrase. Export it without one."
            ) from None
        if "signing" in said:
            raise KeyUnusable("This is not a private key that can sign.") from None
        raise KeyUnusable("This is not an OpenPGP private key.") from None
    certificate = secret.extract_certificate()
    return Material(
        _algorithm(signer), certificate.fingerprint.upper(), str(certificate), str(secret)
    )


class Signer:
    """Signs with one repository's key."""

    def __init__(self, private_key: str) -> None:
        self._signer = _signer(private_key)

    def clear(self, data: bytes) -> bytes:
        """`data` with a signature around it, as `InRelease` is.

        The line ending at the end of `data` becomes the one before the signature, as
        GnuPG writes it: what is signed is the text without it.
        """
        text = data.removesuffix(b"\n")
        return pysequoia.sign(self._signer, text, mode=pysequoia.SignatureMode.CLEAR)

    def detached(self, data: bytes) -> bytes:
        """A signature of `data` on its own, as `Release.gpg` is."""
        return pysequoia.sign(self._signer, data, mode=pysequoia.SignatureMode.DETACHED)


def signs(repository: Repository) -> str | None:
    """The kind of key this repository signs with, or None if it signs nothing."""
    format = get_format(repository.format)
    if format is None or repository.type != "hosted":
        return None
    return format.signs


def _user_id(repository: Repository) -> str:
    return f"MegooArti {repository.name}"


async def _keep(
    db: AsyncSession, settings: Settings, repository: Repository, material: Material, kind: str
) -> SigningKey:
    """Store a key in place of any the repository has, and make a new revision of it."""
    values = {
        "kind": kind,
        "algorithm": material.algorithm,
        "fingerprint": material.fingerprint,
        "public_key": material.public_key,
        "private_key": seal(settings, material.private_key),
        "created_at": utcnow(),
    }
    await db.execute(
        insert(SigningKey)
        .values(repository_id=repository.id, **values)
        .on_conflict_do_update(index_elements=[SigningKey.repository_id], set_=values)
    )
    await db.execute(
        update(Repository)
        .where(Repository.id == repository.id)
        .values(
            revision=Repository.revision + 1,
            changed_at=utcnow(),
            updated_at=Repository.updated_at,
        )
        .execution_options(synchronize_session=False)
    )
    return await _stored(db, repository)


async def _stored(db: AsyncSession, repository: Repository) -> SigningKey | None:
    return await db.scalar(
        select(SigningKey)
        .where(SigningKey.repository_id == repository.id)
        .execution_options(populate_existing=True)
    )


def _signs_nothing() -> ApiError:
    return ApiError(404, "not_found", "This repository signs nothing: it has no signing key.")


async def key_of(db: AsyncSession, settings: Settings, repository: Repository) -> SigningKey:
    """The repository's key, made now if it has none. The caller commits.

    Two requests that both find none make one each, and the first to be stored is kept.
    """
    kind = signs(repository)
    if kind is None:
        raise _signs_nothing()
    held = await _stored(db, repository)
    if held is not None:
        return held
    material = generate_openpgp(_user_id(repository))
    await db.execute(
        insert(SigningKey)
        .values(
            repository_id=repository.id,
            kind=kind,
            algorithm=material.algorithm,
            fingerprint=material.fingerprint,
            public_key=material.public_key,
            private_key=seal(settings, material.private_key),
            created_at=utcnow(),
        )
        .on_conflict_do_nothing(index_elements=[SigningKey.repository_id])
    )
    return await _stored(db, repository)


async def generate(
    db: AsyncSession, settings: Settings, repository: Repository, algorithm: str
) -> SigningKey:
    """A new key in place of the repository's. The caller commits."""
    kind = signs(repository)
    if kind is None:
        raise _signs_nothing()
    # An RSA key takes a second or more to make: not on the loop that serves everyone.
    material = await asyncio.to_thread(generate_openpgp, _user_id(repository), algorithm)
    return await _keep(db, settings, repository, material, kind)


async def import_key(
    db: AsyncSession, settings: Settings, repository: Repository, private_key: str
) -> SigningKey:
    """An administrator's key in place of the repository's. Raises KeyUnusable."""
    kind = signs(repository)
    if kind is None:
        raise _signs_nothing()
    material = read_openpgp(private_key)
    return await _keep(db, settings, repository, material, kind)


def signer(settings: Settings, key: SigningKey) -> Signer:
    """What signs with a stored key."""
    try:
        return Signer(unseal(settings, key.private_key))
    except SecretUnreadable:
        log.error("signing_key_unreadable", repository_id=str(key.repository_id))
        raise ApiError(
            500,
            "signing_key_unreadable",
            "This repository's signing key cannot be read with the installation's secret key. "
            "An administrator must generate or import another.",
        ) from None
```

```python
def paragraphs(data: bytes) -> list[control.Paragraph]:

def verified(signed: bytes, public_key: bytes, signature: bytes | None = None) -> bytes:
    """What a signature vouches for, checked with a public key. Raises if it does not."""
    certificate = pysequoia.Cert.from_bytes(public_key)
    if signature is None:
        return pysequoia.verify(bytes=signed, store=lambda _: [certificate]).bytes
    pysequoia.verify(
        bytes=signed, store=lambda _: [certificate], signature=pysequoia.Sig.from_bytes(signature)
    )
    return signed
```

```python
"""The APT format: hosted repositories that apt installs from, and proxies of mirrors.

This is the only APT module that touches the repository context. What a path means,
what a package says of itself and what an index says come from the pure functions
beside it.

A package is uploaded to a hosted repository's root, or through the upload form, and
kept where Debian keeps it, under `pool/`. Its control file is read once, as it is
stored, and kept with it. The indexes are written from what was kept: once for each
revision of the repository, in a worker thread, and signed with the repository's key.
Until the next change they are served from memory.

A proxy is the generic engine: its remote's indexes are metadata, checked again after
the proxy's metadata age, and passed on as the remote signed them.
"""

import asyncio
import hashlib
from collections.abc import Sequence
from contextlib import aclosing
from datetime import datetime
from typing import Any

from starlette.requests import Request
from starlette.responses import Response

# Where what a package said of itself is kept among its file's attributes, and what is
# said of the version among its component's.
_DECLARED = "apt"
_DEB = "application/vnd.debian.binary-package"
_TEXT = "text/plain; charset=utf-8"
_COMPRESSED = {".gz": "application/gzip", ".xz": "application/x-xz"}
_SIGNATURE = "application/pgp-signature"
_KEY = "application/pgp-keys"
DEFAULT_SUITE = "stable"


def _invalid(reason: object) -> ApiError:
    return ApiError(400, "invalid_package", f"The package cannot be accepted: {reason}.")


def _not_found(message: str = "Nothing is served at this address.") -> ApiError:
    return ApiError(404, "not_found", message)


def _not_allowed(allowed: str) -> ApiError:
    return ApiError(
        405,
        "method_not_allowed",
        f"This address accepts {allowed}.",
        headers={"Allow": allowed},
    )


def _is_read(request: Request) -> bool:
    return request.method in ("GET", "HEAD")


def _control_of(attributes: dict[str, Any] | None) -> control.Paragraph | None:
    """What a stored package said of itself, as it was kept."""
    declared = (attributes or {}).get(_DECLARED)
    said = declared.get("control") if isinstance(declared, dict) else None
    if not isinstance(said, list):
        return None
    return [(str(name), str(value)) for name, value in said]


def _invalid_setting(field: str, message: str) -> ApiError:
    details = [{"field": field, "message": message}]
    return ApiError(422, "validation_error", "The request is not valid.", details)


def _suite(context: RepositoryContext) -> str:
    return context.repository.config.get("format_config", {}).get("suite", DEFAULT_SUITE)


# --- Uploading -----------------------------------------------------------------------


async def _read(context: RepositoryContext, staged: StagedBlob) -> debs.Deb:
    """What a staged package says of itself.

    Only its beginning is read, and the file is closed at once, read to the end or
    not: a file that is still open cannot be moved into the store, or removed, on
    every system.
    """
    try:
        async with aclosing(context.open_staged(staged)) as chunks:
            return await debs.read(chunks)
    except debs.InvalidPackage as error:
        raise _invalid(error) from None


async def _keep(context: RepositoryContext, staged: StagedBlob, deb: debs.Deb) -> tuple[str, bool]:
    """Store a package where Debian keeps it. Returns where, and whether it is new there."""
    path = paths.pool_path(deb.package, deb.version, deb.architecture)
    held = await context.component("", deb.package, deb.version)
    known = ((held.attributes if held else {}).get(_DECLARED) or {}).get("architectures", [])
    architectures = sorted({*known, deb.architecture})
    description = control.first_line(control.get(deb.control, "Description") or "")
    _, created = await context.store(
        path,
        staged,
        content_type=_DEB,
        attributes={_DECLARED: {"control": [list(field) for field in deb.control]}},
        component_attributes={
            _DECLARED: {"description": description, "architectures": architectures}
        },
    )
    return path, created


async def _upload(context: RepositoryContext, request: Request) -> Response:
    """One package, as `curl --upload-file` sends it to the repository's root."""
    # Refused before the body is read; the facade checks again when the file is stored.
    context.require_write()
    await context.release()  # the body needs no connection
    staged = await context.stage(
        request.stream(),
        expected_size=declared_size(request),
        expected_hashes=declared_hashes(request),
    )
    try:
        deb = await _read(context, staged)
    except ApiError:
        await context.discard(staged)
        raise
    path, created = await _keep(context, staged, deb)
    location = f"{await context.public_url(request)}/{path}"
    return Response(status_code=201 if created else 204, headers={"Location": location})


# --- The indexes ---------------------------------------------------------------------


def _listed(snapshot: Snapshot) -> list[indexes.Listed]:
    listed = []
    for held in snapshot.files:
        said = _control_of(held.attributes)
        if said is None:
            continue  # nothing a hosted repository holds, but it belongs to no index
        listed.append(
            indexes.Listed(
                path=held.path,
                size=held.size,
                md5=held.md5,
                sha1=held.sha1,
                sha256=held.sha256,
                control=said,
                package=control.get(said, "Package") or "",
                version=control.get(said, "Version") or "",
                architecture=control.get(said, "Architecture") or "",
            )
        )
    return listed


def _written(snapshot: Snapshot, suite: str, label: str, signer: signing.Signer) -> derived.Files:
    """Every index file of a suite, by its path under `dists/<suite>/`."""
    listed = _listed(snapshot)
    files = indexes.packages_files(listed)
    release = indexes.release(
        label=label,
        suite=suite,
        moment=snapshot.changed,
        architectures=indexes.architectures(listed),
        files=files,
    )
    return {
        **files,
        "Release": release,
        "InRelease": signer.clear(release),
        "Release.gpg": signer.detached(release),
    }


async def _indexes(context: RepositoryContext) -> tuple[derived.Files, datetime]:
    """The index files of this repository's revision, and when it was made.

    They are written now if they are not kept.
    """
    revision, changed = await context.revision()
    kept = derived.get(context.repository.id, revision)
    if kept is not None:
        return kept, changed
    snapshot = await context.snapshot()
    key = await signing.key_of(context.db, context.settings, context.repository)
    signer = signing.signer(context.settings, key)
    await context.release()  # writing them needs no connection
    files = await asyncio.to_thread(
        _written, snapshot, _suite(context), context.repository.name, signer
    )
    derived.put(context.repository.id, snapshot.revision, files)
    return files, snapshot.changed


def _content_type(filename: str) -> str:
    if filename == "Release.gpg":
        return _SIGNATURE
    return _COMPRESSED.get(filename[filename.rfind(".") :], _TEXT) if "." in filename else _TEXT


async def _index(context: RepositoryContext, request: Request, parsed: paths.AptPath) -> Response:
    if parsed.suite != _suite(context) or (
        parsed.component and parsed.component != paths.COMPONENT
    ):
        raise _not_found("This repository has no such suite or component.")
    if parsed.kind == "release":
        name = parsed.filename
    else:
        name = f"{parsed.component}/binary-{parsed.architecture}/{parsed.filename}"
    files, changed = await _indexes(context)
    data = files.get(name)
    if data is None:
        raise _not_found("This repository has no packages of that architecture.")
    return context.respond_with(
        data,
        request,
        filename=parsed.filename,
        content_type=_content_type(parsed.filename),
        last_modified=changed,
        etag=hashlib.sha256(data).hexdigest(),
    )


async def _public_key(context: RepositoryContext, request: Request) -> Response:
    key = await signing.key_of(context.db, context.settings, context.repository)
    return context.respond_with(
        key.public_key.encode(),
        request,
        filename=paths.PUBLIC_KEY,
        content_type=_KEY,
        last_modified=key.created_at,
        etag=key.fingerprint.lower(),
    )


class AptFormat(Format):
    name = "apt"
    types = frozenset({"hosted", "proxy"})
    derives_indexes = True
    signs = signing.OPENPGP

    def validate_config(
        self, repository_type: str, config: dict[str, Any], current: dict[str, Any] | None = None
    ) -> dict[str, Any]:
        """A hosted repository's suite, which never changes. A proxy has no settings."""
        if repository_type != "hosted":
            return super().validate_config(repository_type, config, current)
        unknown = sorted(set(config) - {"suite"})
        if unknown:
            raise _invalid_setting(f"format_config.{unknown[0]}", "This is not a setting of APT.")
        suite = config.get("suite", DEFAULT_SUITE if current is None else current.get("suite"))
        if not isinstance(suite, str) or paths.SUITE.fullmatch(suite) is None:
            raise _invalid_setting(
                "format_config.suite",
                "A suite is 1 to 64 letters, digits, '.', '_' or '-', and begins with a "
                "letter or a digit.",
            )
        if current is not None and suite != current.get("suite", DEFAULT_SUITE):
            raise _invalid_setting(
                "format_config.suite", "The suite cannot change once the repository is made."
            )
        return {"suite": suite}

    def describe_component(
        self, path: str, attributes: dict[str, Any] | None = None
    ) -> ComponentKey | None:
        """A package belongs to its name and version: what it said, or its file's name."""
        said = _control_of(attributes)
        if said is not None:
            return ComponentKey("", control.get(said, "Package"), control.get(said, "Version"))
        named = paths.in_pool(path)
        return None if named is None else ComponentKey("", named[0], named[1])

    def search_text(self, key: ComponentKey, attributes: dict[str, Any]) -> str:
        """Its name and version, its description's first line, and its architectures."""
        declared = attributes.get(_DECLARED)
        declared = declared if isinstance(declared, dict) else {}
        words = [super().search_text(key, attributes)]
        description = declared.get("description")
        if isinstance(description, str):
            words.append(description)
        architectures = declared.get("architectures")
        if isinstance(architectures, list):
            words.extend(str(architecture) for architecture in architectures)
        return " ".join(words)

    async def upload(self, context: RepositoryContext, form: UploadForm) -> list[str]:
        """Store packages as an upload of each to the repository's root would."""
        only_fields(form, ())
        if not form.files:
            raise invalid_upload("file", "At least one Debian package is needed.")
        read = []
        for file in form.files:
            if file.field != "file":
                raise invalid_upload(file.field, "A package is sent as `file`.")
            deb = await _read(context, file.staged)
            path = paths.pool_path(deb.package, deb.version, deb.architecture)
            if any(path == other for other, _ in read):
                raise invalid_upload("file", f"Two files are the same package: {file.filename}.")
            read.append((path, deb))
        return [
            (await _keep(context, file.staged, deb))[0]
            for (_, deb), file in zip(read, form.files, strict=True)
        ]

    def usage(self, address: str, key: ComponentKey, files: Sequence[str]) -> list[Usage]:
        if versions.NAME.fullmatch(key.name) is None or versions.split(key.version) is None:
            return []
        return [Usage("apt", "shell", f"sudo apt install {key.name}={key.version}")]

    def content_type(self, path: str, declared: str | None) -> str | None:
        parsed = paths.classify(path)
        if parsed.kind == "pool":
            return _DEB
        if parsed.kind in ("release", "packages"):
            return _content_type(parsed.filename)
        return declared

    def is_metadata(self, path: str) -> bool:
        """A suite's indexes change as packages are published, except those named by a hash."""
        return path.startswith("dists/") and "/by-hash/" not in path

    async def handle_hosted(
        self, context: RepositoryContext, request: Request, path: str
    ) -> Response:
        parsed = paths.classify(path)
        if parsed.kind == "upload":
            if request.method not in ("PUT", "POST"):
                raise _not_allowed("PUT, POST")
            return await _upload(context, request)
        if parsed.kind == "pool":
            if _is_read(request):
                return await context.respond(path, request)
            if request.method != "DELETE":
                raise _not_allowed("GET, HEAD, DELETE")
            if not await context.delete(path):
                raise _not_found("No such package.")
            return Response(status_code=204)
        if not _is_read(request):
            raise _not_allowed("GET, HEAD")
        if parsed.kind == "key":
            return await _public_key(context, request)
        if parsed.kind in ("release", "packages"):
            return await _index(context, request, parsed)
        raise _not_found()


register(AptFormat())

```

````markdown
- **Credentials** go in a file of `/etc/apt/auth.conf.d/`, as above: a user name and a
  password, or a user name and an API token. apt sends them over HTTPS to the host a
  `machine` line names; over plain HTTP only if the line says so
  (`machine http://repo.example.com`).
- **A hosted repository has one suite**, chosen when it is made (`stable` unless you
  say otherwise) and fixed after, and one component, `main`. For a second suite, make
  a second repository.
- **A package is uploaded to the repository's root**, with `PUT` or `POST`, or
  through the web UI or [the API](../api.md#uploading) (one or more `file` fields). Its
  `control` file says where it goes:
  `pool/main/<letter>/<name>/<name>_<version>_<architecture>.deb`, with the version's
  epoch left out of the file's name, as Debian does. A file that is not a Debian
  package, or whose `control` has no `Package`, `Version` or `Architecture`, is
  refused with `400 invalid_package`. Packages whose control archive is compressed
  with gzip, xz, zstd or nothing are taken; at most 16 MiB of it is read.
- **Uploading a package again** (the same name, version and architecture) follows the
  deployment policy. With `disable_redeploy` it answers `409`.
- **The indexes are written from the packages**: `Packages` (also `.gz` and `.xz`) for
  each architecture, and `Release`, signed as `InRelease` and `Release.gpg`. They are
  written once after each change and kept in memory until the next. A package for
  `all` architectures is listed under each; a repository with no package of any one
  architecture lists `amd64` and `arm64`.
- **The signing key** is made the first time it is needed: an Ed25519 OpenPGP key that
  never expires. `GET /api/v1/repositories/<name>/signing-key` shows it, and
  `POST /api/v1/repositories/<name>/signing-key/generate` (with
  `{"algorithm": "rsa4096"}` for an RSA key) or `PUT` of an armoured private key in
  `private_key` replaces it, for whoever holds `admin:repositories:write`. From then on
  the indexes are signed with the new key only: every machine must fetch the new
  `public.key`. The private key is kept sealed with the installation's secret key, and
  is never shown.
- **Deleting** a package (`DELETE` on its address under `pool/`) takes it out of the
  indexes at once.
- **A proxy**'s remote is a mirror's root. What is under `dists/` is checked again with
  the remote after `metadata_max_age_minutes`; packages, and files under a `by-hash/`
  directory, never change and are kept.
- Groups of APT repositories are not available yet.
````

```python
def apt(distribution: str, directory: Path, script: str):
    """Run a shell script in a distribution's image, beside the stack, with `directory`."""
    command = [
        "docker",
        "run",
        "--rm",
        "--network",
        NETWORK,
        "--volume",
        f"{directory}:/src:ro",
        IMAGES[distribution],
        "sh",
        "-c",
        f"{SETUP}\n{script}",
    ]
    return subprocess.run(
        command,
        capture_output=True,
        text=True,
        encoding="utf-8",
        errors="replace",
        timeout=900,
        check=False,
    )


def said(result: subprocess.CompletedProcess[str]) -> str:
    return f"exit {result.returncode}\n{result.stdout[-3000:]}\n{result.stderr[-3000:]}"


def send(method: str, path: str, data: bytes | None = None) -> tuple[int, bytes]:
    """A request to a repository from outside, as `ci`: (status, body)."""
    credentials = base64.b64encode(f"{USERNAME}:{PASSWORD}".encode()).decode()
    request = urllib.request.Request(
        f"http://127.0.0.1:{HTTP_PORT}/repository/{path}",
        method=method,
        data=data,
        headers={"Authorization": f"Basic {credentials}"},
    )
    try:
        with urllib.request.urlopen(request, timeout=60) as response:
            return response.status, response.read()
    except urllib.error.HTTPError as error:
        return error.code, error.read()

@pytest.mark.parametrize("distribution", sorted(IMAGES))
def test_apt_installs_a_package_uploaded_to_a_hosted_repository(published, distribution):
    installed = apt(
        distribution,
        published,
        f"with_apt /src/megooarti.asc {HOSTED} stable"
        f" && apt-get update && apt-get install -y {PACKAGE} && {PACKAGE}",
    )

    assert installed.returncode == 0, said(installed)
    assert installed.stdout.splitlines()[-1] == f"hello from {PACKAGE} 1.0"


@pytest.mark.parametrize("distribution", sorted(IMAGES))
def test_apt_refuses_a_repository_signed_with_a_key_it_was_not_given(published, distribution):
    refused = apt(
        distribution,
        published,
        f"with_apt {KEYRINGS[distribution]} {HOSTED} stable && apt-get update",
    )

    assert refused.returncode != 0, said(refused)
    assert "NO_PUBKEY" in refused.stdout + refused.stderr or "not signed" in refused.stderr


@pytest.mark.parametrize("distribution", sorted(IMAGES))
def test_apt_installs_a_public_package_through_a_proxy_of_its_mirror(published, distribution):
    installed = apt(
        distribution,
        published,
        f'with_apt {KEYRINGS[distribution]} apt-{distribution} "$VERSION_CODENAME"'
        " && apt-get update && apt-get install -y hello && hello",
    )

    assert installed.returncode == 0, said(installed)
    assert installed.stdout.splitlines()[-1] == "Hello, world!"
```
