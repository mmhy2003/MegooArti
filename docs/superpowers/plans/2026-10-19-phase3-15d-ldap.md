# External Identity: LDAP Sign-in Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** People sign in to the web UI and from package clients with the name and password their directory (OpenLDAP, Active Directory) knows them by, their groups giving them roles; an hourly check disables those the directory no longer has; an administrator sets a directory up with a form and tests it — proved against a real OpenLDAP over StartTLS.

**Architecture:** `security/ldap.py` is the `ldap` kind of plan 15a's registry: its settings, its sign-in (bind as the bind DN, find the one entry, bind as it, read its groups) and its Test, with `ldap3` in a thread and TLS in a context of its own made from the certificates 15c trusts (`Outbound.trusted`). `security/directory_check.py` is the hourly check, run by one container at a time. The web UI's source page asks a new source's kind, and its form is one, each kind's fields in `components/source-fields.tsx`.

**Tech Stack:** Python 3.13, `ldap3` 2.9.1, FastAPI, SQLAlchemy; Next.js, React, Vitest; Docker and `osixia/openldap:1.5.0` for the container test.

**Spec:** [docs/superpowers/specs/2026-10-19-identity-audit-selectors-design.md](../specs/2026-10-19-identity-audit-selectors-design.md): section 7, with 4, 11, 12, 14 and the row of plan 15d in 13; D1, D4; the "Settled" tables of 15a to 15c.

| L3 | An LDAP source's settings: `url` (`ldap://` or `ldaps://`, a host and a port only), `starttls` (not with `ldaps://`), `bind_dn` (a DN, or a user principal name as Active Directory takes) and `bind_password`, `user_base` and `user_filter` (with `{username}`; only `{username}` and `{dn}` in braces), the three attributes, and `groups` (`member_of`, `search` with `group_base`, `group_filter` and `group_name_attribute`, or `none`). | L4 | A directory answers a sign-in so: no entry for the name is `unknown` (the next source is asked); several, or a wrong password, is `refused`; an empty password is `refused` before the directory is asked. A user of the source is read by their DN. | Section 7, E3. |

| L6 | A directory that cannot be reached, or that refuses the bind DN, answers `503 source_unavailable`. Each request is given ten seconds. | Section 11, 7. |
| L7 | Test binds; given a name, it finds the entry and its groups, and says the roles they give. No password is tried. | Section 7. |
| L8 | The hourly check runs in one container at a time (an advisory lock), over the enabled LDAP sources' active users, each read by their DN: `noSuchObject` disables the user and signs them out; any other answer, or none, skips the source. | Section 7, D4: a directory that cannot be reached disables nobody. |
| L9 | A new source's page asks its kind first (OIDC or LDAP); the form is one, each kind's settings its own fields (`components/source-fields.tsx`). The list's button is "New source". | 15b's O13: LDAP's form comes with its plan. |
| L10 | The container test runs `osixia/openldap:1.5.0` beside the stack as `openldap`, with StartTLS by a certificate of an authority made in the test and RFC 7919's ffdhe2048 parameters (computed: generating some takes slapd minutes); groups are found by a search there, and by `memberOf` in the mock's tests. curl, with a directory password, is the package client. | Section 12. |

## Global Constraints

- **`{username}` is escaped as RFC 4515 has it** (section 7); a test with `*)(uid=*` (section 14).
- **An empty password is refused before asking: an LDAP server takes it as an anonymous bind** (section 7).
- **None or several entries for a name is a failed sign-in** (section 7).
- **Every hour, each enabled LDAP source's users are looked up by their DN; one not found is disabled (and its tokens with it), and logged. A server that cannot be reached disables no one** (section 7, D4).
- **"Test" tries no password** (section 7). **Timeouts of ten seconds** (section 7).
- **TLS trusts the system's authorities and the trusted certificates** (section 6); the shared context is never changed (15c's review).
- **Every secret of a source is sealed, and shown to nobody again** (E5); a kept secret is never sent where it was not given for (S16).
- **Every test of the stack is marked `docker`.**
- **A table's line under its headings is `| --- | --- |`** (one `---` cell a column). Commits end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

**Working directories:** run `uv` and `pytest` commands in `backend/`, with `MEGOOARTI_TEST_DATABASE_URL` set to your test database; `pnpm` commands in `frontend/`; `git` commands in the repository root.

## Review Focus

What could hurt a person using this most, and which test of this plan pins it.

1. **A name typed to change the filter** (`*`, `*)(uid=*`): nobody is found, nobody signed in. Task 1: `test_a_name_is_never_part_of_the_filter`.
2. **An empty password taken as an anonymous bind, signing anyone in:** refused before the directory is asked. Task 1: `test_an_empty_password_is_refused_before_the_directory_is_asked`.
3. **A directory that is down for an hour disabling every user:** the check disables nobody then. Task 2: `test_a_directory_that_cannot_be_asked_disables_nobody`.
4. **The bind password sent to another server, or in the clear:** a changed address, or StartTLS turned off, asks for it again. Task 1: `test_the_bind_password_is_asked_again_for_another_server_or_without_starttls`.
5. **TLS that trusts any certificate, or a change to it that weakens the HTTP client's:** a context of LDAP's own, refusing what is not trusted. Task 1: `test_ldaps_trusts_the_added_certificates_in_a_context_of_its_own`; Task 4: `test_starttls_is_trusted_once_the_directorys_authority_is_added`.

"""A directory of the tests' own, answered by ldap3's mock strategy (spec 12), in place of
the connections `security.ldap` opens."""

from typing import Any

from ldap3 import MOCK_SYNC, OFFLINE_SLAPD_2_4, Connection, Server
from ldap3.core.exceptions import LDAPSocketOpenError

BASE = "dc=corp,dc=example"
PEOPLE = f"ou=people,{BASE}"
GROUPS = f"ou=groups,{BASE}"
READER = f"cn=reader,{BASE}"
READER_PASSWORD = "the reader's password"


class Directory:
    def __init__(self) -> None:
        self._server = Server("ldap.corp.example", get_info=OFFLINE_SLAPD_2_4)
        self._seed = Connection(self._server, client_strategy=MOCK_SYNC)
        self.down = False
        self.binds: list[str | None] = []  # who each connection opened was to bind as
        self.add(
            READER, objectClass="person", cn="reader", sn="reader", userPassword=READER_PASSWORD
        )

    def add(self, dn: str, **attributes: Any) -> None:
        self._seed.strategy.add_entry(dn, attributes)

    def person(self, uid: str, password: str, *, ou: str = "people", **more: Any) -> str:
        dn = f"uid={uid},ou={ou},{BASE}"
        self.add(
            dn,
            objectClass=["inetOrgPerson"],
            uid=uid,
            cn=more.pop("cn", uid.title()),
            sn=uid,
            userPassword=password,
            **more,
        )
        return dn

    def group(self, name: str, *members: str) -> str:
        dn = f"cn={name},{GROUPS}"
        self.add(dn, objectClass="groupOfNames", cn=name, member=list(members))
        return dn

    def remove(self, dn: str) -> None:
        self._seed.strategy.remove_entry(dn)

    def open(
        self, settings: dict, context: Any, user: str | None, password: str | None
    ) -> Connection:
        """As `security.ldap._open`: a connection, not yet bound."""
        if self.down:
            raise LDAPSocketOpenError("socket connection error while opening: [WinError 10061]")
        self.binds.append(user)
        connection = Connection(
            self._server,
            user=user,
            password=password,
            client_strategy=MOCK_SYNC,
            raise_exceptions=False,
        )
        connection.strategy.entries = self._seed.strategy.entries
        connection.open()
        return connection
```

# --- TLS ----------------------------------------------------------------------------------


async def test_ldaps_trusts_the_added_certificates_in_a_context_of_its_own(app):
    ca = authority()
    remote.trust(app, [ca.pem])
    shared = remote.tls_of(app)
    reach = sources.outbound(app)
    async with https_server(ca) as port:
        settings = {
            "url": f"ldaps://127.0.0.1:{port}",
            "starttls": False,
            "bind_dn": None,
            "bind_password": None,
        }
        untrusted = ldap.context_for(())
        trusted = ldap.context_for(reach.trusted)
        with pytest.raises(sources.SourceUnavailable) as refused:
            await asyncio.to_thread(ldap._bound, settings, untrusted)
        with pytest.raises(sources.SourceUnavailable) as past_tls:
            await asyncio.to_thread(ldap._bound, settings, trusted)
    await remote.close_clients(app)

    assert "CERTIFICATE_VERIFY_FAILED" in str(refused.value)
    # Through TLS: what fails then is that an HTTPS server does not speak LDAP.
    assert "CERTIFICATE_VERIFY_FAILED" not in str(past_tls.value)
    assert trusted is not shared and shared is remote.tls_of(app)

"""LDAP sign-in sources (spec 7): a person's name and password checked against a
directory (OpenLDAP, Active Directory), their groups giving them roles.

`ldap3` is blocking: everything that talks to a directory runs in a thread. TLS (ldaps,
or StartTLS) trusts what every outbound connection trusts (15c), in a context of its own:
the shared one is never changed.
"""

import asyncio
import functools
import re
import ssl
from collections.abc import Sequence
from typing import Any
from urllib.parse import urlsplit

import ldap3
import structlog
from ldap3.core.exceptions import LDAPException
from ldap3.utils.conv import escape_filter_chars
from ldap3.utils.dn import parse_dn

from megooarti.repositories.remote import tls_context
from megooarti.security import sources
from megooarti.security.sources import (
    REFUSED,
    UNKNOWN,
    Identity,
    SourceUnavailable,
    Tested,
    invalid,
)

log = structlog.get_logger(__name__)

KIND = "ldap"
# How long a directory is given to connect, and to answer each request (spec 7).
TIMEOUT_SECONDS = 10
GROUP_MODES = ("member_of", "search", "none")
DEFAULTS = {
    "user_filter": "(uid={username})",
    "username_attribute": "uid",
    "name_attribute": "cn",
    "email_attribute": "mail",
    "groups": "member_of",
    "member_of_attribute": "memberOf",
    "group_filter": "(member={dn})",
    "group_name_attribute": "cn",
}
_ATTRIBUTE = re.compile(r"[A-Za-z][A-Za-z0-9-]{0,63}")
_NO_SUCH_OBJECT = 32
_PRINCIPAL_NAME = re.compile(r"[^@\s=,]+@[^@\s=,]+")


class _Trusting(ldap3.Tls):
    """ldap3's TLS, with the context the server's outbound connections trust (15c)."""

    def __init__(self, context: ssl.SSLContext) -> None:
        super().__init__(validate=ssl.CERT_REQUIRED)
        self._context = context

    def wrap_socket(self, connection: Any, do_handshake: bool = False) -> None:
        connection.socket = self._context.wrap_socket(
            connection.socket,
            server_side=False,
            do_handshake_on_connect=do_handshake,
            server_hostname=connection.server.host,  # checked by the context
        )


@functools.lru_cache(maxsize=4)
def context_for(pems: tuple[str, ...]) -> ssl.SSLContext:
    """A context of LDAP's own, trusting what the shared one trusts."""
    return tls_context(pems)


def _dn(value: Any, field: str, *, required: bool) -> str | None:
    text = str(value or "").strip()
    if not text:
        if required:
            raise invalid(field, "A DN is required, as ou=people,dc=corp,dc=example.")
        return None
    try:
        parse_dn(text)
    except LDAPException:
        raise invalid(field, "This is not a DN, as ou=people,dc=corp,dc=example.") from None
    return text


def _bind_name(value: Any) -> str | None:
    """Who the server binds as: a DN, or, as Active Directory takes, a user principal name
    (svc-megooarti@corp.example)."""
    text = str(value or "").strip()
    if _PRINCIPAL_NAME.fullmatch(text):
        return text
    return _dn(text, "settings.bind_dn", required=False)


def _filter(value: Any, field: str, default: str, *names: str) -> str:
    text = str(value or default).strip()
    if not (text.startswith("(") and text.endswith(")")) or text.count("(") != text.count(")"):
        raise invalid(field, "A filter is in parentheses, as (uid={username}).")
    if not any("{" + name + "}" in text for name in names):
        said = " or ".join("{" + name + "}" for name in names)
        raise invalid(field, f"The filter must name {said}, where the name goes.")
    leftover = re.sub(r"\{(username|dn)\}", "", text)
    if "{" in leftover or "}" in leftover:
        raise invalid(field, "Only {username} and {dn} may be in braces.")
    return text


class LdapKind(sources.Kind):
    name = KIND
    secrets = ("bind_password",)
    # The password goes to the server, and in the clear without StartTLS: either changed,
    # it is asked again (S16).
    bound = ("url", "starttls")
    takes_passwords = True

    def checked(self, settings: dict[str, Any]) -> dict[str, Any]:
        url = str(settings.get("url") or "").strip()
        parts = urlsplit(url)
        try:
            parts.port  # noqa: B018  (a port that is not a number raises)
        except ValueError:
            raise invalid("settings.url", "The port is a number.") from None
        if parts.scheme not in ("ldap", "ldaps") or not parts.hostname:
            raise invalid(
                "settings.url", "An ldap:// or ldaps:// address, as ldaps://ldap.corp.example."
            )
        if parts.path not in ("", "/") or parts.query or parts.fragment or parts.username:
            raise invalid("settings.url", "An address with a host and a port only.")
        starttls = bool(settings.get("starttls", False))
        if starttls and parts.scheme == "ldaps":
            raise invalid("settings.starttls", "ldaps:// is TLS already.")
        groups = settings.get("groups", DEFAULTS["groups"])
        if groups not in GROUP_MODES:
            raise invalid("settings.groups", f"Must be one of: {', '.join(GROUP_MODES)}.")
        values: dict[str, Any] = {
            "url": url.rstrip("/"),
            "starttls": starttls,
            "bind_dn": _bind_name(settings.get("bind_dn")),
            "bind_password": settings.get("bind_password") or None,
            "user_base": _dn(settings.get("user_base"), "settings.user_base", required=True),
            "user_filter": _filter(
                settings.get("user_filter"),
                "settings.user_filter",
                DEFAULTS["user_filter"],
                "username",
            ),
            "groups": groups,
        }
        for name in (
            "username_attribute",
            "name_attribute",
            "email_attribute",
            "member_of_attribute",
            "group_name_attribute",
        ):
            attribute = str(settings.get(name) or DEFAULTS[name]).strip()
            if not _ATTRIBUTE.fullmatch(attribute):
                raise invalid(
                    f"settings.{name}",
                    "An attribute's name is a letter, then letters, digits or -.",
                )
            values[name] = attribute
        if groups == "search":
            values["group_base"] = _dn(
                settings.get("group_base"), "settings.group_base", required=True
            )
            values["group_filter"] = _filter(
                settings.get("group_filter"),
                "settings.group_filter",
                DEFAULTS["group_filter"],
                "dn",
                "username",
            )
        return values

    async def password(self, outbound, settings, name, password, known):
        if not password:
            # A directory takes an empty password as an anonymous bind, which succeeds.
            return REFUSED
        return await asyncio.to_thread(
            _sign_in, settings, context_for(outbound.trusted), name, password, known
        )

    async def test(self, outbound, settings, name, password) -> Tested:
        return await asyncio.to_thread(_test, settings, context_for(outbound.trusted), name)


# --- Talking to the directory (in a thread) -----------------------------------------------


def _open(
    settings: dict[str, Any], context: ssl.SSLContext, user: str | None, password: str | None
) -> ldap3.Connection:
    """A connection to the directory, TLS started where it is asked for, not yet bound.
    The tests put a directory of their own here."""
    parts = urlsplit(settings["url"])
    server = ldap3.Server(
        parts.hostname,
        port=parts.port,
        use_ssl=parts.scheme == "ldaps",
        tls=_Trusting(context),
        connect_timeout=TIMEOUT_SECONDS,
        get_info=ldap3.NONE,
    )
    connection = ldap3.Connection(
        server,
        user=user,
        password=password,
        receive_timeout=TIMEOUT_SECONDS,
        raise_exceptions=False,
        read_only=True,
    )
    connection.open()
    if settings["starttls"] and not connection.start_tls():
        raise SourceUnavailable(f"{parts.hostname} did not start TLS.")
    return connection


def _bound(settings: dict[str, Any], context: ssl.SSLContext) -> ldap3.Connection:
    """A connection bound as the bind DN, or anonymously without one."""
    try:
        connection = _open(settings, context, settings["bind_dn"], settings.get("bind_password"))
        bound = connection.bind()
    except (LDAPException, OSError) as error:
        raise SourceUnavailable(f"The directory could not be reached: {error}") from None
    if not bound:
        said = connection.result.get("description", "refused")
        raise SourceUnavailable(f"The directory refused the bind DN ({said}).")
    return connection


def _attributes(settings: dict[str, Any]) -> list[str]:
    wanted = [
        settings["username_attribute"],
        settings["name_attribute"],
        settings["email_attribute"],
    ]
    if settings["groups"] == "member_of":
        wanted.append(settings["member_of_attribute"])
    return wanted


def _first(entry: dict[str, list[Any]], attribute: str) -> str | None:
    """An attribute's first value, as text; None for none, or one that is all spaces."""
    values = entry.get(attribute) or []
    value = values[0] if isinstance(values, list) and values else values
    text = str(value).strip() if value else ""
    return text or None


def _find(
    connection: ldap3.Connection, settings: dict[str, Any], name: str
) -> list[tuple[str, dict]]:
    """The entries the user filter gives for a name, at most two: one is the person."""
    wanted = settings["user_filter"].replace("{username}", escape_filter_chars(name))
    connection.search(
        settings["user_base"], wanted, ldap3.SUBTREE, attributes=_attributes(settings), size_limit=2
    )
    return [(entry.entry_dn, entry.entry_attributes_as_dict) for entry in connection.entries]


def _read(
    connection: ldap3.Connection, settings: dict[str, Any], dn: str
) -> tuple[str, dict] | None:
    """The entry of a DN, or None when the directory has none."""
    connection.search(dn, "(objectClass=*)", ldap3.BASE, attributes=_attributes(settings))
    if connection.result.get("result") == _NO_SUCH_OBJECT or not connection.entries:
        return None
    entry = connection.entries[0]
    return entry.entry_dn, entry.entry_attributes_as_dict


def _rdn_value(dn: str) -> str | None:
    try:
        return parse_dn(dn)[0][1]
    except (LDAPException, IndexError):
        return None


def _groups(
    connection: ldap3.Connection, settings: dict[str, Any], dn: str, entry: dict, name: str
) -> frozenset[str]:
    """Each group by its name and by its DN: a mapping may name either."""
    found: set[str] = set()
    if settings["groups"] == "member_of":
        for group in entry.get(settings["member_of_attribute"]) or []:
            found |= {str(group), _rdn_value(str(group)) or str(group)}
    elif settings["groups"] == "search":
        wanted = (
            settings["group_filter"]
            .replace("{dn}", escape_filter_chars(dn))
            .replace("{username}", escape_filter_chars(name))
        )
        connection.search(
            settings["group_base"],
            wanted,
            ldap3.SUBTREE,
            attributes=[settings["group_name_attribute"]],
        )
        for group in connection.entries:
            names = group.entry_attributes_as_dict.get(settings["group_name_attribute"]) or []
            found |= {group.entry_dn, *(str(value) for value in names)}
    return frozenset(group for group in found if group)


def _identity(
    connection: ldap3.Connection, settings: dict[str, Any], dn: str, entry: dict, name: str
) -> Identity:
    username = _first(entry, settings["username_attribute"]) or name
    return Identity(
        external_id=dn,
        username=username,
        display_name=_first(entry, settings["name_attribute"]) or username,
        email=_first(entry, settings["email_attribute"]),
        groups=_groups(connection, settings, dn, entry, name),
    )


def _sign_in(
    settings: dict[str, Any], context: ssl.SSLContext, name: str, password: str, known: str | None
) -> Identity | str:
    """Bind as the bind DN, find the one entry the name is, bind as it with the password,
    read its groups (spec 7)."""
    connection = _bound(settings, context)
    try:
        if known is not None:
            found = _read(connection, settings, known)
            entries = [] if found is None else [found]
        else:
            entries = _find(connection, settings, name)
        if not entries:
            return UNKNOWN
        if len(entries) > 1:
            log.warning("ldap_name_ambiguous", name=name)
            return REFUSED  # several people of one name: none of them is signed in
        dn, entry = entries[0]
        try:
            person = _open(settings, context, dn, password)
            if not person.bind():
                return REFUSED
            person.unbind()
        except (LDAPException, OSError) as error:
            raise SourceUnavailable(f"The directory could not be reached: {error}") from None
        return _identity(connection, settings, dn, entry, name)
    finally:
        connection.unbind()


def _test(settings: dict[str, Any], context: ssl.SSLContext, name: str | None) -> Tested:
    """Connect and bind; with a name, find its entry and groups. No password is tried."""
    connection = _bound(settings, context)
    try:
        if not name:
            return Tested(True, "The directory answered, and took the bind DN.")
        entries = _find(connection, settings, name)
        if not entries:
            return Tested(False, f"The directory has nobody the filter gives for {name}.")
        if len(entries) > 1:
            return Tested(False, f"The filter gives several entries for {name}: it must give one.")
        dn, entry = entries[0]
        identity = _identity(connection, settings, dn, entry, name)
        return Tested(True, f"{name} is {dn}.", identity)
    finally:
        connection.unbind()

def missing(settings: dict[str, Any], context: ssl.SSLContext, dns: Sequence[str]) -> list[str]:
    """Which of these DNs the directory no longer has. Raises SourceUnavailable when it
    cannot be asked: then nobody is said to be missing."""
    connection = _bound(settings, context)
    try:
        gone = []
        for dn in dns:
            connection.search(dn, "(objectClass=*)", ldap3.BASE, attributes=[])
            code = connection.result.get("result")
            if code == _NO_SUCH_OBJECT:
                gone.append(dn)
            elif code != 0:
                raise SourceUnavailable(
                    f"The directory answered {connection.result.get('description')}."
                )
        return gone
    finally:
        connection.unbind()

refused with them. A directory that cannot be asked disables nobody."""

import asyncio
from typing import Any

import structlog
from sqlalchemy import select

from megooarti.secrets_box import SecretUnreadable
from megooarti.security import ldap, sources
from megooarti.security.models import User
from megooarti.security.sessions import delete_user_sessions

log = structlog.get_logger(__name__)

CHECK_SECONDS = 3600
# Arbitrary constant, distinct from the other advisory lock keys.
LOCK_KEY = 0x4D45474F52


async def run(app: Any) -> int:
    """Check every enabled LDAP source's active users; how many were disabled."""
    reach = sources.outbound(app)
    async with app.state.sessionmaker() as db:
        checked = [
            source.id
            for source in await sources.in_order(db)
            if source.enabled and source.kind == ldap.KIND
        ]
    disabled = 0
    for source_id in checked:
        disabled += await _check(app, reach, source_id)
    return disabled


async def _check(app: Any, reach: sources.Outbound, source_id: Any) -> int:
    async with app.state.sessionmaker() as db:
        source = await sources.get_source(db, source_id)
        if source is None or not source.enabled:
            return 0  # deleted or turned off since
        users = list(
            await db.scalars(
                select(User).where(User.source_id == source.id, User.status == "active")
            )
        )
        if not users:
            return 0
        try:
            settings = sources.opened_settings(
                app.state.settings, sources.KINDS[ldap.KIND], source.settings
            )
            gone = set(
                await asyncio.to_thread(
                    ldap.missing,
                    settings,
                    ldap.context_for(reach.trusted),
                    [user.external_id for user in users],
                )
            )
        except (sources.SourceUnavailable, SecretUnreadable) as error:
            log.warning("directory_check_skipped", source=source.name, error=str(error))
            return 0
        for user in users:
            if user.external_id in gone:
                user.status = "disabled"
                await delete_user_sessions(db, user.id)
                log.info("directory_user_gone", username=user.username, source=source.name)
        await db.commit()
        return sum(user.external_id in gone for user in users)
```
