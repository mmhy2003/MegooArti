# apk Repositories Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** apk on the two newest Alpine Linux releases installs from a hosted apk repository whose indexes MegooArti writes, as `apk index` writes them, and signs with an RSA key of the repository's own, and through a proxy of Alpine's mirror.

**Architecture:** An apk package's signature and control part are read once, as it is uploaded: its `.PKGINFO` and its checksum (`Q1`, the SHA-1 of the control part as packed) are kept in the asset's attributes, and the package is kept in its architecture's directory under the name apk asks for it by. Each directory's `APKINDEX.tar.gz` is written from a snapshot of one revision, in a worker thread, by plan 12a's machinery, and signed as `abuild-sign` signs one, with an RSA key that `signing.py` now makes, imports and seals beside the OpenPGP ones. A proxy is the generic engine, with each `APKINDEX.tar.gz` as metadata.

**Tech Stack:** Python 3.13, FastAPI, `cryptography` (RSA), pytest; Docker images `alpine:3.24` (abuild 3.17, apk-tools 3.0) and `alpine:3.23` for the fixtures and the real-client tests.

**Spec:** [docs/superpowers/specs/2026-10-14-linux-package-formats-design.md](../specs/2026-10-14-linux-package-formats-design.md), sections 4.2, 4.3, 4.4, 7.1 to 7.3, 9, 10, 11 and section 12, with what plans 12a to 12d settled (P1 to P12, Q1 to Q14, R1 to R12, S1 to S14). Groups of apk repositories (7.4) are plan 12f (T1).

## Global Constraints

- **A format never touches a table or a file:** it works through the repository context (plan 12a's `revision()`, `snapshot()`, `open_staged()`, `respond_with()`, and the `derived` cache).
- **What is read of an uploaded package is bounded** (spec 9): its signature and control part at 16 MiB, packed and unpacked, refused with `400 invalid_package` beyond that, without the rest being read.
- **No answer carries a private key.** The private key is sealed with `secrets_box.seal`, as an OpenPGP one is.
- **Every test of a stack is marked `docker`** and reaches the stack through the gateway (`http://gateway` from a container, `http://127.0.0.1:18000` from the tests).
- **A table's line under its headings is `| --- | --- |`.** Commits end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

**Working directories:** run `uv` and `pytest` commands in `backend/`, and `git` commands in the repository root. Backend tests need the `db` Compose service; set `MEGOOARTI_TEST_DATABASE_URL` as `docs/development.md` describes.

## Review Focus

What the tests of this plan do not reach, most likely first. The reviewer reads for these.

1. **A `.PKGINFO` that says something unexpected**: a key said twice that is not a list, a value with a colon or spaces where apk splits, a field the index writes itself, a name or version that apk would read otherwise than the server; what it can make an index say of another package.
2. **A large hosted repository**: every revision writes every directory's index again, each signed with RSA 4096, from a snapshot of every package's kept `.PKGINFO`; the first request after a change waits for it.
3. **The same package in many directories**: a `noarch` package in each architecture's, two releases' directories, a package deleted from one; the component's architectures, and what each index lists.
4. **The key's lifetime**: replaced while machines keep the old key under the same file name, imported in a form `abuild-keygen` of another release writes, unreadable after the secret key changed.
5. **A proxy of a mirror that changes**: an index and the packages it names fetched at different moments, a package the mirror has dropped.

```python
def tar_of(files: dict[str, bytes], *, end: bool) -> bytes:
    """A tar, with its end or, as a signature and a control part have it, without."""
    buffer = io.BytesIO()
    for name, data in files.items():
        member = tarfile.TarInfo(name)
        member.size = len(data)
        buffer.write(member.tobuf(format=tarfile.USTAR_FORMAT))
        buffer.write(data + b"\0" * (-len(data) % 512))
    return buffer.getvalue() + (b"\0" * 1024 if end else b"")


def pkginfo(
    name: str = "megooarti-hello",
    version: str = "1.0-r0",
    arch: str = "noarch",
    description: str = "Says hello",
    extra: str = "",
) -> str:
    return (
        "# Generated by abuild 3.17.0-r0\n"
        f"pkgname = {name}\npkgver = {version}\npkgdesc = {description}\n"
        "url = https://example.com/megooarti-hello\nbuilddate = 1792051327\n"
        f"packager = Unknown\nsize = 48\narch = {arch}\norigin = {name}\n"
        f"license = MIT\n{extra}depend = busybox\n"
    )


def make_apk(
    info: str | None = None,
    *,
    signed: bool = True,
    data: bytes = b"the files of the package",
) -> bytes:
    """A package whose `.PKGINFO` is `info`, as abuild lays one out."""
    streams = []
    if signed:
        streams.append(tar_of({".SIGN.RSA.someone.rsa.pub": b"\x01" * 512}, end=False))
    streams.append(tar_of({".PKGINFO": (info or pkginfo()).encode()}, end=False))
    streams.append(tar_of({"usr/share/megooarti/file": data}, end=True))
    return b"".join(gzip.compress(stream, mtime=0) for stream in streams)


async def pieces(data: bytes, size: int = 300) -> AsyncIterator[bytes]:
    """Bytes as they arrive, a piece at a time."""
    for at in range(0, len(data), size):
        yield data[at : at + size]
```

```python
"""What an apk package says of itself: its `.PKGINFO`, and the identity apk knows it by.

A package as `abuild` writes it is gzip streams one after the other: a signature (left
out of an unsigned package), the control part (a tar of `.PKGINFO` and the scripts),
and the files. Only the first two are read, as the package arrives or from where it
was stored: the files, which can be gigabytes, are never looked at. What is read is
bounded, so a package cannot make the server hold or unpack more than a few megabytes.

apk knows a package by the SHA-1 of its control part as it is packed (`Q1` and the
digest in base64): an index lists it so, and apk installs a file only if it is the one
the index named.
"""

import base64
import hashlib
import io
import tarfile
import zlib
from collections.abc import AsyncIterator
from dataclasses import dataclass, field
from typing import Any

from megooarti.repositories.apk import versions

# The most of the signature and of the control part that is read, packed and unpacked:
# a real one is a few kilobytes.
CONTROL_MOST = 16 * 1024 * 1024
_GZIP = b"\x1f\x8b"
_ADB = b"ADB"
# Fields of `.PKGINFO` that may be said more than once, each a list in what is kept.
LISTS = frozenset({"depend", "provides", "install_if", "replaces", "triggers"})


class InvalidPackage(ValueError):
    """Bytes that are not an apk package the server can list."""


@dataclass(frozen=True)
class Apk:
    """What a package says of itself, and its identity."""

    checksum: str  # Q1 and the SHA-1 of the control part, in base64
    info: dict[str, Any] = field(default_factory=dict)  # `.PKGINFO`, by its keys

    @property
    def name(self) -> str:
        return self.info.get("pkgname", "")

    @property
    def version(self) -> str:
        return self.info.get("pkgver", "")

    @property
    def arch(self) -> str:
        return self.info.get("arch", "")

    @property
    def filename(self) -> str:
        """The file's name, as apk asks for it: `<name>-<version>.apk`."""
        return f"{self.name}-{self.version}.apk"

    def as_json(self) -> dict[str, Any]:
        return {"checksum": self.checksum, "info": self.info}

    @classmethod
    def from_json(cls, said: dict[str, Any]) -> "Apk":
        return cls(str(said.get("checksum", "")), dict(said.get("info", {})))


class _Streams:
    """The gzip streams of a file, one at a time, from pieces."""

    def __init__(self, chunks: AsyncIterator[bytes]) -> None:
        self._chunks = chunks
        self._held = b""
        self.started = False

    async def first_bytes(self, count: int) -> bytes:
        while len(self._held) < count:
            chunk = await anext(self._chunks, None)
            if chunk is None:
                break
            self._held += chunk
        return self._held[:count]

    async def next(self) -> tuple[bytes, bytes]:
        """The next stream as it is packed, and unpacked. Raises InvalidPackage."""
        unpack = zlib.decompressobj(wbits=31)
        packed, opened = bytearray(), bytearray()
        while True:
            if not self._held:
                chunk = await anext(self._chunks, None)
                if chunk is None:
                    raise InvalidPackage("it ends early")
                self._held = chunk
            try:
                opened += unpack.decompress(self._held, CONTROL_MOST + 1 - len(opened))
            except zlib.error:
                raise InvalidPackage("it is not gzip streams, as apk packages are") from None
            if unpack.unconsumed_tail:
                raise InvalidPackage(
                    f"its control part is larger than {CONTROL_MOST // (1024 * 1024)} MiB"
                )
            used = len(self._held) - len(unpack.unused_data)
            packed += self._held[:used]
            self._held = unpack.unused_data
            if len(packed) > CONTROL_MOST:
                raise InvalidPackage(
                    f"its control part is larger than {CONTROL_MOST // (1024 * 1024)} MiB"
                )
            if unpack.eof:
                return bytes(packed), bytes(opened)


def _members(opened: bytes) -> dict[str, bytes]:
    """The files of a tar that may lack its end, as a signature and a control part do."""
    found = {}
    try:
        with tarfile.open(fileobj=io.BytesIO(opened + b"\0" * 1024)) as tar:
            for member in tar.getmembers():
                if member.isfile():
                    found[member.name] = tar.extractfile(member).read()
    except tarfile.TarError:
        raise InvalidPackage("a part of it is not a tar archive") from None
    return found


def parse_info(text: str) -> dict[str, Any]:
    """`.PKGINFO`: `key = value` lines; a key of LISTS may be said more than once."""
    info: dict[str, Any] = {}
    for line in text.splitlines():
        if not line.strip() or line.startswith("#"):
            continue
        key, equals, value = line.partition(" = ")
        if not equals:
            raise InvalidPackage(f"a line of its .PKGINFO cannot be read: {line[:80]!r}")
        if key in LISTS:
            info.setdefault(key, []).extend(value.split())
        else:
            info[key] = value
    return info


def describe(control: bytes, opened: bytes) -> Apk:
    """What a control part says, as it was packed and as it unpacks."""
    files = _members(opened)
    if ".PKGINFO" not in files:
        raise InvalidPackage("its control part has no .PKGINFO")
    try:
        info = parse_info(files[".PKGINFO"].decode("utf-8"))
    except UnicodeDecodeError:
        raise InvalidPackage("its .PKGINFO is not UTF-8") from None
    name, version, arch = info.get("pkgname"), info.get("pkgver"), info.get("arch")
    if not (name and version and arch):
        raise InvalidPackage("its .PKGINFO says no pkgname, pkgver or arch")
    if versions.NAME.fullmatch(name) is None:
        raise InvalidPackage(f"its name cannot be a package's: {name[:80]!r}")
    if versions.VERSION.fullmatch(version) is None:
        raise InvalidPackage(f"its version cannot be a package's: {version[:80]!r}")
    if versions.ARCH.fullmatch(arch) is None:
        raise InvalidPackage(f"its architecture cannot be one: {arch[:80]!r}")
    checksum = "Q1" + base64.b64encode(hashlib.sha1(control).digest()).decode()
    return Apk(checksum, info)


async def read(chunks: AsyncIterator[bytes]) -> Apk:
    """What an apk package says of itself. Raises InvalidPackage.

    Reads no more of `chunks` than its signature and control part: the caller closes them.
    """
    streams = _Streams(chunks)
    start = await streams.first_bytes(3)
    if start == _ADB:
        raise InvalidPackage(
            "it is in apk-tools 3's package format (ADB), which this server does not read yet; "
            "build it with abuild as Alpine does, in the format of apk-tools 2"
        )
    if start[:2] != _GZIP:
        raise InvalidPackage("it is not an apk package")
    packed, opened = await streams.next()
    if any(name.startswith(".SIGN.") for name in _members(opened)):
        packed, opened = await streams.next()  # the signature: the control part is next
    return describe(packed, opened)
```

```python
"""A directory's `APKINDEX.tar.gz`: what apk reads to know the packages in it.

It is two gzip streams. The first is a signature: a tar of one file, named for the key
(`.SIGN.RSA.<key name>`), which holds the RSA signature of the second stream as it is
packed. The second is a tar of `DESCRIPTION` (a line that `apk update` shows) and
`APKINDEX`, a record of each package, written as `apk index` of apk-tools 3 writes it.

A package for no architecture (`noarch`) is listed under the architecture of its
directory, as `abuild` has `apk index` do (`--rewrite-arch`): apk asks for a package
at `<repository>/<architecture>/<name>-<version>.apk`, by what the index says.
"""

import gzip
import tarfile
from collections.abc import Sequence
from dataclasses import dataclass
from typing import Protocol

from megooarti.repositories.apk.packages import Apk
from megooarti.repositories.apk.versions import NOARCH

INDEX = "APKINDEX.tar.gz"
_BLOCK = 512


class Signs(Protocol):
    def sign(self, data: bytes) -> bytes: ...


@dataclass(frozen=True)
class Listed:
    """A package that an index lists, and its file."""

    size: int
    apk: Apk


def _joined(info: dict, key: str) -> str:
    said = info.get(key) or []
    return " ".join(said) if isinstance(said, list) else str(said)


def record(listed: Listed, architecture: str) -> str:
    """A package's record, as `apk index` writes it, and the line that ends it.

    `architecture` is its directory's: what a package for no architecture is listed as.
    """
    info = listed.apk.info
    arch = info.get("arch", "")
    lines = [
        f"C:{listed.apk.checksum}",
        f"P:{info.get('pkgname', '')}",
        f"V:{info.get('pkgver', '')}",
        f"A:{architecture if arch == NOARCH else arch}",
        f"S:{listed.size}",
        f"I:{info.get('size', '0')}",
        f"T:{info.get('pkgdesc', '')}",
        f"U:{info.get('url', '')}",
        f"L:{info.get('license', '')}",
    ]
    for key, field in (("o", "origin"), ("m", "maintainer")):
        if info.get(field):
            lines.append(f"{key}:{info[field]}")
    if info.get("builddate", "0") not in ("", "0"):
        lines.append(f"t:{info['builddate']}")
    if info.get("commit"):
        lines.append(f"c:{info['commit']}")
    if info.get("provider_priority", "0") not in ("", "0"):
        lines.append(f"k:{info['provider_priority']}")
    for key, field in (("D", "depend"), ("p", "provides"), ("i", "install_if")):
        said = _joined(info, field)
        if said:
            lines.append(f"{key}:{said}")
    return "\n".join(lines) + "\n\n"


def apkindex(listed: Sequence[Listed], architecture: str) -> str:
    """`APKINDEX`: every package's record, in the order given."""
    return "".join(record(each, architecture) for each in listed)


def _tar_member(name: str, data: bytes, moment: int) -> bytes:
    """One file of a tar: its header and its content, padded to a whole block."""
    member = tarfile.TarInfo(name)
    member.size = len(data)
    member.mtime = moment
    member.mode = 0o644
    member.uname = member.gname = "root"
    header = member.tobuf(format=tarfile.USTAR_FORMAT, encoding="utf-8", errors="strict")
    return header + data + b"\0" * (-len(data) % _BLOCK)


def archive(description: str, text: str, moment: int) -> bytes:
    """The second stream: a tar of `DESCRIPTION` and `APKINDEX`, packed with gzip."""
    tar = (
        _tar_member("DESCRIPTION", description.encode(), moment)
        + _tar_member("APKINDEX", text.encode(), moment)
        + b"\0" * (2 * _BLOCK)
    )
    return gzip.compress(tar, compresslevel=9, mtime=0)


def signature(packed: bytes, key_name: str, signer: Signs, moment: int) -> bytes:
    """The first stream: the signature of the second, as `abuild-sign` makes it.

    A tar of one file and no end, so that the two streams read as one archive.
    """
    signed = signer.sign(packed)
    tar = _tar_member(f".SIGN.RSA.{key_name}", signed, moment)
    return gzip.compress(tar, compresslevel=9, mtime=0)


def index_file(
    listed: Sequence[Listed],
    architecture: str,
    description: str,
    key_name: str,
    signer: Signs,
    moment: int,
) -> bytes:
    """A whole `APKINDEX.tar.gz`, signed."""
    packed = archive(description, apkindex(listed, architecture), moment)
    return signature(packed, key_name, signer, moment) + packed
```

```python
"""What a path of an apk repository is.

As Alpine's mirrors have them: packages at `<any path>/<architecture>/<name>-<version>.apk`
and an `APKINDEX.tar.gz` in each architecture's directory. A client lists the path
above the architectures (`.../v3.24/main`), and apk adds `/<architecture>/...` itself.
Beside them, at the root, is the key a hosted repository signs with, under the name a
client saves it as: `megooarti-<repository>.rsa.pub`.
"""

from dataclasses import dataclass

from megooarti.repositories.apk import versions
from megooarti.repositories.apk.index import INDEX


@dataclass(frozen=True)
class ApkPath:
    kind: str  # key, index, package, other
    directory: str = ""  # an index's or a package's
    filename: str = ""

    @property
    def architecture(self) -> str:
        """The directory's last part: the architecture its packages are for."""
        return self.directory.rpartition("/")[2]


def key_name(repository: str) -> str:
    """The file a client saves a repository's key as, and finds it by."""
    return f"megooarti-{repository}.rsa.pub"


def classify(path: str, repository: str) -> ApkPath:
    directory, _, filename = path.rpartition("/")
    if path == key_name(repository):
        return ApkPath("key", filename=filename)
    if filename == INDEX:
        return ApkPath("index", directory, filename)
    if filename.endswith(".apk") and directory:
        return ApkPath("package", directory, filename)
    return ApkPath("other", directory, filename)


def in_directory(directory: str, filename: str) -> str:
    return f"{directory}/{filename}" if directory else filename


def named(path: str) -> tuple[str, str] | None:
    """The name and version a package's file name says, or None.

    `<name>-<version>-r<release>.apk`: the version is the last two parts, as apk names
    its files.
    """
    filename = path.rpartition("/")[2]
    if not filename.endswith(".apk"):
        return None
    stem = filename.removesuffix(".apk")
    rest, _, release = stem.rpartition("-")
    name, _, version = rest.rpartition("-")
    if not (name and version and release.startswith("r")):
        return None
    if versions.NAME.fullmatch(name) is None:
        return None
    return name, f"{version}-{release}"
```

```python
"""The apk format: hosted repositories that apk installs from, and proxies of mirrors.

This is the only apk module that touches the repository context. What a path means,
what a package says of itself and what an index says come from the pure modules beside
it.

A package is uploaded to its architecture's directory, under the name apk asks for it
by (`<name>-<version>.apk`). Its `.PKGINFO` is read once, as it is stored, and kept
with it. Each directory's `APKINDEX.tar.gz` is written from what was kept: once for each
revision of the repository, in a worker thread, signed with the repository's RSA key.
Until the next change it is served from memory.

A proxy is the generic engine: its remote's indexes are metadata, checked again after
the proxy's metadata age, and passed on as the remote signed them.
"""

import asyncio
import hashlib
from collections import defaultdict
from collections.abc import Sequence
from contextlib import aclosing
from typing import Any

from starlette.requests import Request
from starlette.responses import Response

from megooarti.errors import ApiError
from megooarti.repositories import derived, signing
from megooarti.repositories.apk import index, packages, paths, versions
from megooarti.repositories.content import RepositoryContext, Snapshot
from megooarti.repositories.formats import (
    ComponentKey,
    Format,
    Usage,
    declared_hashes,
    declared_size,
    invalid_upload,
    only_fields,
    register,
)
from megooarti.repositories.forms import UploadForm
from megooarti.repositories.paths import normalise_path
from megooarti.storage.backends import StagedBlob

# Where what a package said of itself is kept among its file's attributes, and what is
# said of the version among its component's.
_DECLARED = "apk"
_PACKED = "application/gzip"
_KEY = "application/x-pem-file"
# Where, among the index files of a revision, the index of a directory that holds no
# package is: one that no path can be.
_EMPTY = "/"


def _invalid(reason: object) -> ApiError:
    return ApiError(400, "invalid_package", f"The package cannot be accepted: {reason}.")


def _invalid_path(reason: str) -> ApiError:
    return ApiError(400, "invalid_path", f"The path is not valid: {reason}.")


def _not_found(message: str = "Nothing is served at this address.") -> ApiError:
    return ApiError(404, "not_found", message)


def _not_allowed(allowed: str) -> ApiError:
    return ApiError(
        405,
        "method_not_allowed",
        f"This address accepts {allowed}.",
        headers={"Allow": allowed},
    )


def _is_read(request: Request) -> bool:
    return request.method in ("GET", "HEAD")


def _declared(attributes: dict[str, Any] | None) -> dict[str, Any]:
    declared = (attributes or {}).get(_DECLARED)
    return declared if isinstance(declared, dict) else {}


def _apk_of(attributes: dict[str, Any] | None) -> packages.Apk | None:
    """What a stored package said of itself, as it was kept."""
    said = _declared(attributes).get("apk")
    return packages.Apk.from_json(said) if isinstance(said, dict) else None


def description_of(context: RepositoryContext) -> str:
    """What `apk update` shows of the repository's indexes."""
    return f"MegooArti {context.repository.name}"


# --- Uploading -----------------------------------------------------------------------


def _check_place(directory: str, apk: packages.Apk) -> str:
    """Where a package is kept in a directory, or the refusal of that directory."""
    architecture = directory.rpartition("/")[2]
    if not directory or (apk.arch != versions.NOARCH and architecture != apk.arch):
        raise _invalid_path(
            f"a package for {apk.arch} is kept in a directory of that name, as apk asks for it "
            f"there (`.../{apk.arch}/{apk.filename}`)"
        )
    return f"{directory}/{apk.filename}"


async def _read(context: RepositoryContext, staged: StagedBlob) -> packages.Apk:
    """What a staged package says of itself.

    Only its beginning is read, and the file is closed at once: a file that is still
    open cannot be moved into the store, or removed, on every system.
    """
    try:
        async with aclosing(context.open_staged(staged)) as chunks:
            return await packages.read(chunks)
    except packages.InvalidPackage as error:
        raise _invalid(error) from None


async def _keep(
    context: RepositoryContext, path: str, staged: StagedBlob, apk: packages.Apk
) -> bool:
    """Store a package at its path. Returns whether it is new there."""
    held = await context.component("", apk.name, apk.version)
    known = _declared(held.attributes if held else None).get("architectures", [])
    _, created = await context.store(
        path,
        staged,
        content_type=_PACKED,
        attributes={_DECLARED: {"apk": apk.as_json()}},
        component_attributes={
            _DECLARED: {
                "description": apk.info.get("pkgdesc", ""),
                "architectures": sorted({*known, path.split("/")[-2]}),
            }
        },
    )
    return created


async def _put(context: RepositoryContext, request: Request, parsed: paths.ApkPath) -> Response:
    """One package, as `curl --upload-file` sends it to its path."""
    # Refused before the body is read; the facade checks again when the file is stored.
    context.require_write()
    await context.release()  # the body needs no connection
    staged = await context.stage(
        request.stream(),
        expected_size=declared_size(request),
        expected_hashes=declared_hashes(request),
    )
    try:
        apk = await _read(context, staged)
        path = _check_place(parsed.directory, apk)
        if path != f"{parsed.directory}/{parsed.filename}":
            raise _invalid_path(f"apk asks for this package as {apk.filename}")
    except ApiError:
        await context.discard(staged)
        raise
    created = await _keep(context, path, staged, apk)
    return Response(status_code=201 if created else 204)


# --- The indexes ---------------------------------------------------------------------


def _listed(snapshot: Snapshot) -> dict[str, list[index.Listed]]:
    """The packages each directory's index lists, by the directory."""
    listed: dict[str, list[index.Listed]] = defaultdict(list)
    for held in snapshot.files:
        apk = _apk_of(held.attributes)
        directory = held.path.rpartition("/")[0]
        if apk is None or not directory:
            continue  # nothing a hosted repository holds, but it belongs to no index
        listed[directory].append(index.Listed(held.size, apk))
    return listed


def _written(
    snapshot: Snapshot, description: str, key_name: str, signer: signing.RsaSigner
) -> derived.Written:
    """Every directory's `APKINDEX.tar.gz` of a revision, by its path; and an empty one."""
    moment = int(snapshot.changed.timestamp())
    files = {}
    for directory, listed in [*_listed(snapshot).items(), (_EMPTY, [])]:
        architecture = directory.rpartition("/")[2]
        files[paths.in_directory(directory, index.INDEX)] = index.index_file(
            listed, architecture, description, key_name, signer, moment
        )
    return derived.Written(snapshot.revision, snapshot.changed, files)


async def hosted_indexes(context: RepositoryContext) -> derived.Written:
    """The indexes of this repository's revision: kept, or written now, once."""
    revision, _ = await context.revision()

    async def write() -> derived.Written:
        snapshot = await context.snapshot()
        key = await signing.key_of(context.db, context.settings, context.repository)
        signer = signing.signer(context.settings, key)
        await context.release()  # writing them needs no connection
        return await asyncio.to_thread(
            _written,
            snapshot,
            description_of(context),
            paths.key_name(context.repository.name),
            signer,
        )

    return await derived.written(context.repository.id, revision, write)


def index_file(written: derived.Written, directory: str) -> bytes:
    """A directory's index, from what was written of a revision: an empty one if it has none."""
    found = written.files.get(paths.in_directory(directory, index.INDEX))
    return found if found is not None else written.files[paths.in_directory(_EMPTY, index.INDEX)]


async def _index(context: RepositoryContext, request: Request, parsed: paths.ApkPath) -> Response:
    written = await hosted_indexes(context)
    data = index_file(written, parsed.directory)
    return context.respond_with(
        data,
        request,
        filename=index.INDEX,
        content_type=_PACKED,
        last_modified=written.changed,
        etag=hashlib.sha256(data).hexdigest(),
        # Two revisions can be made within one second: only the bytes say which one a
        # client has.
        dated=False,
    )


async def _public_key(context: RepositoryContext, request: Request) -> Response:
    key = await signing.key_of(context.db, context.settings, context.repository)
    return context.respond_with(
        key.public_key.encode(),
        request,
        filename=paths.key_name(context.repository.name),
        content_type=_KEY,
        last_modified=key.created_at,
        etag=key.fingerprint.lower(),
    )


class ApkFormat(Format):
    name = "apk"
    types = frozenset({"hosted", "proxy"})
    derives_indexes = True
    signs = signing.RSA

    def describe_component(
        self, path: str, attributes: dict[str, Any] | None = None
    ) -> ComponentKey | None:
        """A package belongs to its name and version: what it said, or its file's name."""
        apk = _apk_of(attributes)
        if apk is not None:
            return ComponentKey("", apk.name, apk.version)
        named = paths.named(path)
        return None if named is None else ComponentKey("", named[0], named[1])

    def search_text(self, key: ComponentKey, attributes: dict[str, Any]) -> str:
        """Its name and version, its description, and its architectures."""
        declared = _declared(attributes)
        words = [super().search_text(key, attributes)]
        description = declared.get("description")
        if isinstance(description, str):
            words.append(description)
        architectures = declared.get("architectures")
        if isinstance(architectures, list):
            words.extend(str(architecture) for architecture in architectures)
        return " ".join(words)

    async def upload(self, context: RepositoryContext, form: UploadForm) -> list[str]:
        """Store packages in a `directory`, each under the name apk asks for it by."""
        only_fields(form, ("directory",))
        if not form.files:
            raise invalid_upload("file", "At least one apk package is needed.")
        directory = form.fields.get("directory", "").strip("/")
        if directory:
            normalise_path(directory)
        read = []
        for file in form.files:
            if file.field != "file":
                raise invalid_upload(file.field, "A package is sent as `file`.")
            apk = await _read(context, file.staged)
            path = _check_place(directory, apk)
            if any(path == other for other, _ in read):
                raise invalid_upload("file", f"Two files are the same package: {file.filename}.")
            read.append((path, apk))
        for (path, apk), file in zip(read, form.files, strict=True):
            await _keep(context, path, file.staged, apk)
        return [path for path, _ in read]

    def usage(self, address: str, key: ComponentKey, files: Sequence[str]) -> list[Usage]:
        if (
            versions.NAME.fullmatch(key.name) is None
            or versions.VERSION.fullmatch(key.version) is None
        ):
            return []
        return [Usage("apk", "shell", f"apk add {key.name}={key.version}")]

    def content_type(self, path: str, declared: str | None) -> str | None:
        if path.endswith((".apk", index.INDEX)):
            return _PACKED
        return declared

    def is_metadata(self, path: str) -> bool:
        """A directory's index changes as packages are published; packages do not."""
        return path.rpartition("/")[2] == index.INDEX

    async def handle_hosted(
        self, context: RepositoryContext, request: Request, path: str
    ) -> Response:
        parsed = paths.classify(path, context.repository.name)
        if parsed.kind == "package":
            if _is_read(request):
                return await context.respond(path, request)
            if request.method == "PUT":
                return await _put(context, request, parsed)
            if request.method != "DELETE":
                raise _not_allowed("GET, HEAD, PUT, DELETE")
            if not await context.delete(path):
                raise _not_found("No such package.")
            return Response(status_code=204)
        if not _is_read(request):
            if request.method == "PUT" and parsed.kind == "other":
                raise _invalid_path(
                    "a package is kept at `<directory>/<architecture>/<name>-<version>.apk`"
                )
            raise _not_allowed("GET, HEAD")
        if parsed.kind == "key":
            return await _public_key(context, request)
        if parsed.kind == "index":
            return await _index(context, request, parsed)
        raise _not_found()


register(ApkFormat())
```

````markdown
# apk repositories

What is true of every repository is in [Repositories](../repositories.md). This is
what is this format's own: Alpine Linux packages, installed with apk.

A hosted repository holds the `.apk` files you build with abuild, laid out as Alpine's
mirrors are: each architecture's packages in a directory of that name, under a path
of your choosing (`v3.24/main/x86_64/`). It writes each directory's
`APKINDEX.tar.gz` and signs it with an RSA key of its own:

```bash
curl -u admin -H 'Content-Type: application/json' -d '{
  "name": "apk-hosted", "format": "apk", "type": "hosted"
}' http://localhost:8000/api/v1/repositories

curl -u ci --upload-file megooarti-hello-1.0-r0.apk \
  https://repo.example.com/repository/apk-hosted/v3.24/main/x86_64/
```

On each machine that installs from it, as root: the repository's public key, saved
under the name apk finds it by, and the repository, with the account apk signs in with.
apk adds the machine's architecture to the address itself.

```bash
wget -q -O /etc/apk/keys/megooarti-apk-hosted.rsa.pub \
  "https://ci:$MEGOOARTI_TOKEN@repo.example.com/repository/apk-hosted/megooarti-apk-hosted.rsa.pub"
echo "https://ci:$MEGOOARTI_TOKEN@repo.example.com/repository/apk-hosted/v3.24/main" \
  >> /etc/apk/repositories

apk update && apk add megooarti-hello
```

A proxy caches Alpine's mirror. apk goes on checking Alpine's own signatures, with the
keys it already has:

```bash
curl -u admin -H 'Content-Type: application/json' -d '{
  "name": "apk-alpine", "format": "apk", "type": "proxy",
  "proxy": {"remote_url": "https://dl-cdn.alpinelinux.org/alpine"}

  name and an API token. `/etc/apk/repositories` then holds a secret: keep it readable
  by root alone.
- **A package is uploaded to its architecture's directory**, under the name apk asks
  for it by, `<name>-<version>.apk`, with `PUT` (`curl --upload-file` to an address
  ending in `/` adds the file's name), or through the web UI or
  [the API](../api.md#uploading), with a `directory` field (the architecture's
  directory) and one or more `file` fields, which are stored under that name whatever
  they are called. A package for an architecture uploaded to another's directory, or
  under another name, is refused with `400 invalid_path`. A package for no
  architecture (`noarch`) may go in any architecture's directory, and is listed there
  as that architecture's, as `abuild` lists it.
- **What is read of a package** is its `.PKGINFO`, at most 16 MiB of its signature
  and control part. A file that is not an apk package as `abuild` writes it is refused
  with `400 invalid_package`, and so is one in apk-tools 3's newer package format
  (ADB), which Alpine does not publish yet. A package's own signature is not checked:
  apk installs a package the repository's signed index names, by its checksum,
  whatever key it was built with.
- **A package's version** is its name and `<version>-r<release>`: that is what the
  web UI shows, and what `apk add` is given (`apk add megooarti-hello=1.0-r0`). Each
  architecture's file is one file of it.
- **Uploading a package again** to the same path follows the deployment policy. With
  `disable_redeploy` it answers `409`.
- **The indexes are written from the packages**: each directory's `APKINDEX.tar.gz`,
  with each package's record as apk-tools 3's `apk index` writes it, signed as
  `abuild-sign` signs one (RSA, SHA-1). Every directory has one: one without packages
  has an empty one, so a machine can be set up before anything is uploaded for it.
  They are written once after each change and kept in memory until the next. A client
  is sent an index again unless it has the same bytes (`If-None-Match`).
- **The signing key** is made the first time it is needed: an RSA key of 4096 bits,
  served at `/repository/<name>/megooarti-<name>.rsa.pub`.
  `GET /api/v1/repositories/<name>/signing-key` shows it, and
  `POST /api/v1/repositories/<name>/signing-key/generate` or `PUT` of a PEM private
  key in `private_key` (as `abuild-keygen` makes one, of 2048 bits or more) replaces
  it, for whoever holds `admin:repositories:write`. From then on the indexes are
  signed with the new key only: every machine must fetch it again. The private key is
  kept sealed with the installation's secret key, and is never shown.
- **Deleting** a package (`DELETE` on its address) takes it out of its directory's
  index at once.
- **A proxy**'s remote is a mirror's root. Each `APKINDEX.tar.gz` is checked again
  with the remote after `metadata_max_age_minutes`; packages never change, and are
  kept.
````

```python
def apk(release: str, directory: Path, script: str):
    """Run a shell script in a release's image, beside the stack, with `directory`."""
    command = [
        "docker",
        "run",
        "--rm",
        "--network",
        NETWORK,
        "--volume",
        f"{directory}:/src:ro",
        IMAGES[release],
        "sh",
        "-c",
        f"{SETUP}\n{script}",
    ]
    return subprocess.run(
        command,
        capture_output=True,
        text=True,
        encoding="utf-8",
        errors="replace",
        timeout=1800,
        check=False,
    )


def said(result: subprocess.CompletedProcess[str]) -> str:
    return f"exit {result.returncode}\n{result.stdout[-3000:]}\n{result.stderr[-3000:]}"


def send(method: str, path: str, data: bytes | None = None) -> tuple[int, bytes]:
    """A request to a repository from outside, as `ci`: (status, body)."""
    credentials = base64.b64encode(f"{USERNAME}:{PASSWORD}".encode()).decode()
    request = urllib.request.Request(
        f"http://127.0.0.1:{HTTP_PORT}/repository/{path}",
        method=method,
        data=data,
        headers={"Authorization": f"Basic {credentials}"},
    )
    try:
        with urllib.request.urlopen(request, timeout=60) as response:
            return response.status, response.read()
    except urllib.error.HTTPError as error:
        return error.code, error.read()
```
