# YUM Repositories Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** dnf on Fedora and Rocky Linux installs from a hosted YUM repository whose metadata MegooArti writes, as `createrepo_c` writes it, and signs with the repository's own key, and through a proxy of a distribution's mirror.

**Architecture:** An RPM's lead and headers are read once, as it is uploaded, and what `createrepo_c` would list of it is kept in the asset's attributes. The repository's `repodata_depth` says which directories have a `repodata/`. Each revision's `repodata/` files are written from a snapshot of the repository, in a worker thread, by plan 12a's machinery: `primary.xml`, `filelists.xml` and `other.xml`, packed with gzip and named by their hash, and `repomd.xml`, signed as `repomd.xml.asc` with the repository's OpenPGP key. They are kept in memory by revision, with the files the revision before named. A proxy is the generic engine, with `repomd.xml` as metadata.

**Tech Stack:** Python 3.13, FastAPI, SQLAlchemy 2 (async), `pysequoia`; pytest; Docker images `fedora:44` (rpmbuild, createrepo_c, dnf 5) and `rockylinux/rockylinux:10` (dnf 4) for the fixtures and the real-client tests.

**Spec:** [docs/superpowers/specs/2026-10-14-linux-package-formats-design.md](../specs/2026-10-14-linux-package-formats-design.md), sections 4, 6.1 to 6.3, 9, 10, 11 and section 12, with what plans 12a and 12b settled (P1 to P12, Q1 to Q14). Groups of YUM repositories (6.4) are plan 12d (R1).

## Global Constraints

- **A format never touches a table or a file:** it works through the repository context (plan 12a's `revision()`, `snapshot()`, `open_staged()`, `respond_with()`, and the `derived` cache).
- **What is read of an uploaded package is bounded** (spec 9): an RPM's headers at 64 MiB, refused with `400 invalid_package` beyond that, without the rest being read.
- **No answer carries a private key.** The repository's key is plan 12a's, made the first time it is needed.
- **Every test of a stack is marked `docker`** and reaches the stack through the gateway (`http://gateway` from a container, `http://127.0.0.1:18000` from the tests).
- **A table's line under its headings is `| --- | --- |`.** Commits end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

**Working directories:** run `uv` and `pytest` commands in `backend/`, and `git` commands in the repository root. Backend tests need the `db` Compose service; set `MEGOOARTI_TEST_DATABASE_URL` as `docs/development.md` describes.

## Review Focus

What the tests of this plan do not reach, most likely first. The reviewer reads for these.

1. **A large hosted repository**: every revision reads every package's kept attributes (the file list of each, which for a package such as `kernel-modules` is thousands of paths) and writes every directory's metadata again, not only the one that changed. Memory, time, and the first request after a change.
2. **A package whose headers say something unexpected**: tags of another type than rpm writes, counts that disagree between the names, flags and versions of one kind of dependency, strings that are not UTF-8 or hold characters XML cannot, a file list whose indexes point past its directories. None may make the metadata of another package wrong, or the server answer `500`.
3. **What dnf does between two revisions**: a client that read `repomd.xml` before a change and fetches what it named after two more, after a restart of the backend, or from another process; `If-None-Match` on the hash-named files.
4. **Paths**: a package in a directory named `repodata` deeper down, a path with spaces or characters that need escaping in `<location href>`, two packages of one name and version in two directories of one `repodata/`, a file at exactly the depth (`el9/x86_64.rpm` at depth 1).
5. **The key's lifetime**, as for APT: replaced while a client is between `repomd.xml` and its signature, unreadable after the secret key changed.

```python
# The types of a header's values, and the tags these tests write.
INT16, INT32, STRING, BIN, STRING_ARRAY, I18NSTRING = 3, 4, 6, 7, 8, 9
NAME, VERSION, RELEASE, EPOCH, SUMMARY, DESCRIPTION, BUILDTIME = range(1000, 1007)
SIZE, LICENSE, ARCH, SOURCERPM, SOURCEPACKAGE = 1009, 1014, 1022, 1044, 1106
FILEMODES, FILEFLAGS, DIRINDEXES, BASENAMES, DIRNAMES = 1030, 1037, 1116, 1117, 1118
REQUIRENAME, REQUIREFLAGS, REQUIREVERSION = 1049, 1048, 1050
PROVIDENAME, PROVIDEFLAGS, PROVIDEVERSION = 1047, 1112, 1113
CHANGELOGTIME, CHANGELOGNAME, CHANGELOGTEXT = 1080, 1081, 1082
PAYLOADSIZE = 1007  # in the signature header

type Value = str | bytes | list[str] | list[int]


def header(tags: dict[int, tuple[int, Value]]) -> bytes:
    """A header: its magic, its index of tags, and its store, each value aligned."""
    index, store = bytearray(), bytearray()
    for tag, (kind, value) in sorted(tags.items()):
        if kind == INT32:
            store += b"\0" * (-len(store) % 4)
            data, count = struct.pack(f">{len(value)}I", *value), len(value)
        elif kind == INT16:
            store += b"\0" * (-len(store) % 2)
            data, count = struct.pack(f">{len(value)}H", *value), len(value)
        elif kind == STRING:
            data, count = value.encode() + b"\0" if isinstance(value, str) else value + b"\0", 1
        elif kind == BIN:
            data, count = value, len(value)
        else:
            data, count = b"".join(item.encode() + b"\0" for item in value), len(value)
        index += struct.pack(">IIII", tag, kind, len(store), count)
        store += data
    count = len(index) // 16
    return b"\x8e\xad\xe8\x01\0\0\0\0" + struct.pack(">II", count, len(store)) + index + store


def lead(name: str, *, source: bool = False) -> bytes:
    return (
        b"\xed\xab\xee\xdb\x03\x00"
        + struct.pack(">HH", 1 if source else 0, 1)
        + name.encode()[:65].ljust(66, b"\0")
        + struct.pack(">HH", 1, 5)
        + b"\0" * 16
    )


def make_rpm(
    name: str = "megooarti-hello",
    version: str = "1.0",
    release: str = "1",
    arch: str = "noarch",
    *,
    epoch: int | None = None,
    summary: str = "Says hello",
    requires: Sequence[tuple[str, int, str]] = (("bash", 0, ""),),
    files: Sequence[str] = ("/usr/bin/megooarti-hello",),
    changelog: Sequence[tuple[int, str, str]] = (),
    source: bool = False,
    extra: dict[int, tuple[int, Value]] | None = None,
    payload: bytes = b"the files, packed",
) -> bytes:
    """An RPM that says what it is given, as rpmbuild lays one out."""
    directories = sorted({path.rpartition("/")[0] + "/" for path in files})
    tags: dict[int, tuple[int, Value]] = {
        NAME: (STRING, name),
        VERSION: (STRING, version),
        RELEASE: (STRING, release),
        SUMMARY: (I18NSTRING, [summary]),
        DESCRIPTION: (I18NSTRING, [f"{summary}, at length."]),
        BUILDTIME: (INT32, [1792000000]),
        SIZE: (INT32, [len(payload)]),
        LICENSE: (STRING, "MIT"),
        ARCH: (STRING, arch),
        PROVIDENAME: (STRING_ARRAY, [name]),
        PROVIDEFLAGS: (INT32, [8]),
        PROVIDEVERSION: (STRING_ARRAY, [f"{version}-{release}"]),
    }
    if epoch is not None:
        tags[EPOCH] = (INT32, [epoch])
    if not source:
        tags[SOURCERPM] = (STRING, f"{name}-{version}-{release}.src.rpm")
    else:
        tags[SOURCEPACKAGE] = (INT32, [1])
    if files:
        tags[BASENAMES] = (STRING_ARRAY, [path.rpartition("/")[2] for path in files])
        tags[DIRNAMES] = (STRING_ARRAY, directories)
        tags[DIRINDEXES] = (
            INT32,
            [directories.index(path.rpartition("/")[0] + "/") for path in files],
        )
        tags[FILEMODES] = (INT16, [0o100644] * len(files))
        tags[FILEFLAGS] = (INT32, [0] * len(files))
    if requires:
        tags[REQUIRENAME] = (STRING_ARRAY, [said for said, _, _ in requires])
        tags[REQUIREFLAGS] = (INT32, [flags for _, flags, _ in requires])
        tags[REQUIREVERSION] = (STRING_ARRAY, [version for _, _, version in requires])
    if changelog:
        tags[CHANGELOGTIME] = (INT32, [time for time, _, _ in changelog])
        tags[CHANGELOGNAME] = (STRING_ARRAY, [author for _, author, _ in changelog])
        tags[CHANGELOGTEXT] = (STRING_ARRAY, [text for _, _, text in changelog])
    tags.update(extra or {})
    signature = header({PAYLOADSIZE: (INT32, [len(payload)])})
    signature += b"\0" * (-len(signature) % 8)
    return lead(f"{name}-{version}-{release}", source=source) + signature + header(tags) + payload


async def pieces(data: bytes, size: int = 1000) -> AsyncIterator[bytes]:
    """Bytes as they arrive, a piece at a time."""
    for at in range(0, len(data), size):
        yield data[at : at + size]
```

```python
"""RPM's names and versions: how they are written, split and compared."""

import re

# A package's name, as rpm takes one.
NAME = re.compile(r"[A-Za-z0-9_+][A-Za-z0-9._+-]{0,254}")
# A version or a release: what a command can be given.
PART = re.compile(r"[A-Za-z0-9._+~^]{1,128}")


def evr(epoch: str, version: str, release: str) -> str:
    """`epoch:version-release`, as dnf is given it: without an epoch of 0."""
    return f"{version}-{release}" if epoch in ("", "0") else f"{epoch}:{version}-{release}"


def split(evr: str) -> tuple[str, str, str] | None:
    """A component's `[epoch:]version-release`, if it can be put in a command as it is."""
    epoch, _, rest = evr.rpartition(":")
    version, _, release = rest.rpartition("-")
    if epoch and not (epoch.isascii() and epoch.isdigit()):
        return None
    if PART.fullmatch(version) is None or PART.fullmatch(release) is None:
        return None
    return epoch or "0", version, release


def split_evr(said: str) -> tuple[str, str, str]:
    """The epoch, version and release of a dependency's version, as createrepo_c splits it.

    An epoch that is not a number is not one, and none is 0. The version ends at the
    first `-`; a release may be empty.
    """
    epoch, colon, rest = said.partition(":")
    if not colon:
        epoch, rest = "", said
    elif not (epoch.isascii() and epoch.isdigit()):
        epoch = ""
    version, _, release = rest.partition("-")
    return epoch or "0", version, release


def _alnum(text: str, at: int) -> bool:
    return at < len(text) and text[at].isascii() and text[at].isalnum()


def compare(one: str, two: str) -> int:
    """rpm's `rpmvercmp`: -1, 0 or 1 as `one` is older, the same or newer than `two`."""
    if one == two:
        return 0
    i = j = 0
    while i < len(one) or j < len(two):
        while i < len(one) and not _alnum(one, i) and one[i] not in "~^":
            i += 1
        while j < len(two) and not _alnum(two, j) and two[j] not in "~^":
            j += 1
        a = one[i] if i < len(one) else ""
        b = two[j] if j < len(two) else ""
        if a == "~" or b == "~":  # a tilde sorts before everything, its end too
            if a != "~":
                return 1
            if b != "~":
                return -1
            i, j = i + 1, j + 1
            continue
        if a == "^" or b == "^":  # a caret sorts after its end, before anything else
            if not a:
                return -1
            if not b:
                return 1
            if a != "^":
                return 1
            if b != "^":
                return -1
            i, j = i + 1, j + 1
            continue
        if not (a and b):
            break
        numeric = a.isdigit()
        same = str.isdigit if numeric else str.isalpha
        end_one, end_two = i, j
        while end_one < len(one) and one[end_one].isascii() and same(one[end_one]):
            end_one += 1
        while end_two < len(two) and two[end_two].isascii() and same(two[end_two]):
            end_two += 1
        if end_two == j:  # a number is newer than letters
            return 1 if numeric else -1
        left, right = one[i:end_one], two[j:end_two]
        if numeric:
            left, right = left.lstrip("0"), right.lstrip("0")
            if len(left) != len(right):
                return 1 if len(left) > len(right) else -1
        if left != right:
            return 1 if left > right else -1
        i, j = end_one, end_two
    if i >= len(one) and j >= len(two):
        return 0
    return -1 if i >= len(one) else 1
```

```python
"""What an RPM says of itself: its lead and its headers.

An RPM is a lead of 96 bytes, a signature header, padded to a multiple of eight bytes,
the header, and the files, packed. Only the first three are read, as the package
arrives or from where it was stored: the files are never looked at. The headers are
bounded, so a package cannot make the server hold more than 64 MiB of them.

What is read is what `createrepo_c` writes into a repository's metadata, worked out as
it works it out: the same dependencies left out, the same `pre`, the same changelog.
"""

import struct
from collections.abc import AsyncIterator
from dataclasses import asdict, dataclass, field
from typing import Any

from megooarti.repositories.yum import versions

# The most of the two headers that is read: a real one is kilobytes, a large one a few
# megabytes.
HEADER_MOST = 64 * 1024 * 1024
CHANGELOGS_KEPT = 10
_LEAD = 96
_LEAD_MAGIC = b"\xed\xab\xee\xdb"
_HEADER_MAGIC = b"\x8e\xad\xe8\x01"
_SOURCE = 1

# Tags of the header.
_NAME, _VERSION, _RELEASE, _EPOCH = 1000, 1001, 1002, 1003
_SUMMARY, _DESCRIPTION, _BUILDTIME, _BUILDHOST = 1004, 1005, 1006, 1007
_SIZE, _VENDOR, _LICENSE, _PACKAGER, _GROUP, _URL, _ARCH = 1009, 1011, 1014, 1015, 1016, 1020, 1022
_FILEMODES, _FILEFLAGS, _SOURCERPM, _ARCHIVESIZE = 1030, 1037, 1044, 1046
_CHANGELOGTIME, _CHANGELOGNAME, _CHANGELOGTEXT = 1080, 1081, 1082
_SOURCEPACKAGE, _DIRINDEXES, _BASENAMES, _DIRNAMES = 1106, 1116, 1117, 1118
_LONGSIZE = 5009
# The same in the signature header.
_SIG_PAYLOADSIZE, _SIG_LONGARCHIVESIZE = 1007, 271

# Each kind of dependency: its names, flags and versions, in the order createrepo_c
# writes them.
DEPENDENCIES = {
    "provides": (1047, 1112, 1113),
    "requires": (1049, 1048, 1050),
    "conflicts": (1054, 1053, 1055),
    "obsoletes": (1090, 1114, 1115),
    "suggests": (5049, 5051, 5050),
    "enhances": (5055, 5057, 5056),
    "recommends": (5046, 5048, 5047),
    "supplements": (5052, 5054, 5053),
}

# What a dependency's flags say of its version.
_COMPARED = {2: "LT", 4: "GT", 8: "EQ", 10: "LE", 12: "GE"}
# A requirement needed before the package is installed (rpm's `isInstallPreReq`),
# or said with the old `PreReq` (`isLegacyPreReq`): createrepo_c marks these `pre`.
_PREREQ = 1 << 6
_INSTALL_ONLY = (1 << 9) | (1 << 10) | (1 << 24) | (1 << 26) | (1 << 7) | (1 << 5)
_ALL_REQUIRES = _INSTALL_ONLY | _PREREQ | (1 << 8) | (0x1F << 11) | (1 << 19) | (3 << 20)
_RPMFILE_GHOST = 1 << 6
_DIRECTORY = 0o040000
_FILE_TYPE = 0o170000

# Types of a header's values.
_INT16, _INT32, _INT64, _STRING, _BIN, _STRING_ARRAY, _I18NSTRING = 3, 4, 5, 6, 7, 8, 9


class InvalidPackage(ValueError):
    """Bytes that are not an RPM the server can list."""


@dataclass(frozen=True)
class Entry:
    """One dependency, as createrepo_c lists it."""

    name: str
    flags: str = ""  # LT, GT, EQ, LE or GE; empty when no version is said
    epoch: str = ""
    version: str = ""
    release: str = ""
    pre: bool = False


@dataclass(frozen=True)
class Changelog:
    author: str
    date: int
    text: str


@dataclass(frozen=True)
class Rpm:
    """What a package says of itself."""

    name: str
    epoch: str  # "0" when it says none
    version: str
    release: str
    arch: str
    summary: str = ""
    description: str = ""
    packager: str = ""
    url: str = ""
    license: str = ""
    vendor: str = ""
    group: str = ""
    buildhost: str = ""
    sourcerpm: str = ""
    build_time: int = 0
    installed_size: int = 0
    archive_size: int = 0
    header_start: int = 0
    header_end: int = 0
    # By kind, in DEPENDENCIES' order: only the kinds it has.
    dependencies: dict[str, list[Entry]] = field(default_factory=dict)
    # Each path, and "dir", "ghost" or "" for a file.
    files: list[tuple[str, str]] = field(default_factory=list)
    changelogs: list[Changelog] = field(default_factory=list)  # the newest ten, oldest first

    @property
    def evr(self) -> str:
        """Its version as dnf is given it: the epoch only when it has one."""
        return versions.evr(self.epoch, self.version, self.release)

    def as_json(self) -> dict[str, Any]:
        return asdict(self)

    @classmethod
    def from_json(cls, said: dict[str, Any]) -> "Rpm":
        return cls(
            **{
                **said,
                "dependencies": {
                    kind: [Entry(**entry) for entry in entries]
                    for kind, entries in said.get("dependencies", {}).items()
                },
                "files": [(str(path), str(kind)) for path, kind in said.get("files", [])],
                "changelogs": [Changelog(**entry) for entry in said.get("changelogs", [])],
            }
        )


class _Reader:
    """Bytes from pieces, a given number at a time."""

    def __init__(self, chunks: AsyncIterator[bytes]) -> None:
        self._chunks = chunks
        self._held = bytearray()

    async def exactly(self, count: int) -> bytes:
        while len(self._held) < count:
            chunk = await anext(self._chunks, None)
            if chunk is None:
                raise InvalidPackage("it ends early")
            self._held += chunk
        taken = bytes(self._held[:count])
        del self._held[:count]
        return taken


class _Header:
    """One header's values, by tag."""

    def __init__(self, index: bytes, store: bytes) -> None:
        self._store = store
        self._index: dict[int, tuple[int, int, int]] = {}
        for at in range(0, len(index), 16):
            tag, kind, offset, count = struct.unpack(">IIII", index[at : at + 16])
            if offset >= len(store) and count:
                raise InvalidPackage("its header points outside itself")
            self._index[tag] = (kind, offset, count)

    def __contains__(self, tag: int) -> bool:
        return tag in self._index

    def _strings(self, tag: int) -> list[str]:
        kind, offset, count = self._index.get(tag, (0, 0, 0))
        if kind not in (_STRING, _STRING_ARRAY, _I18NSTRING):
            return []
        found, at = [], offset
        for _ in range(count if kind != _STRING else 1):
            end = self._store.find(b"\0", at)
            if end < 0:
                raise InvalidPackage("a string of its header does not end")
            found.append(_text(self._store[at:end]))
            at = end + 1
        return found

    def string(self, tag: int) -> str:
        """A string, or the first of several (a summary has one for each language)."""
        strings = self._strings(tag)
        return strings[0] if strings else ""

    def strings(self, tag: int) -> list[str]:
        return self._strings(tag)

    def numbers(self, tag: int) -> list[int]:
        kind, offset, count = self._index.get(tag, (0, 0, 0))
        width = {_INT16: 2, _INT32: 4, _INT64: 8}.get(kind)
        if width is None:
            return []
        data = self._store[offset : offset + width * count]
        if len(data) != width * count:
            raise InvalidPackage("a number of its header lies outside it")
        return list(struct.unpack(f">{count}{'HIQ'[width // 4]}", data))

    def number(self, *tags: int) -> int:
        """The first of the tags it has, as a number."""
        for tag in tags:
            numbers = self.numbers(tag)
            if numbers:
                return numbers[0]
        return 0


def _text(raw: bytes) -> str:
    """A header's string. Old packages wrote Latin-1, which createrepo_c reads as such."""
    try:
        return raw.decode("utf-8")
    except UnicodeDecodeError:
        return raw.decode("latin-1")


async def _header(reader: _Reader, budget: int) -> tuple[_Header, int]:
    """The next header, and how many bytes it is."""
    intro = await reader.exactly(16)
    if intro[:4] != _HEADER_MAGIC:
        raise InvalidPackage("it has no RPM header where one belongs")
    count, size = struct.unpack(">II", intro[8:16])
    length = 16 + 16 * count + size
    if length > budget:
        raise InvalidPackage(f"its headers are larger than {HEADER_MOST // (1024 * 1024)} MiB")
    index = await reader.exactly(16 * count)
    store = await reader.exactly(size)
    return _Header(index, store), length


def _flags(number: int) -> str:
    return _COMPARED.get(number & 0xF, "")


def _is_pre(number: int) -> bool:
    return bool(number & _INSTALL_ONLY) or number & _ALL_REQUIRES == _PREREQ


def is_primary(path: str) -> bool:
    """Whether createrepo_c lists a file in `primary.xml`, where dnf finds it at once."""
    return path.startswith("/etc/") or "bin/" in path or path == "/usr/lib/sendmail"


def _libc_version(name: str) -> str:
    """What is between the first parentheses of `libc.so.6(GLIBC_2.38)(64bit)`."""
    start = name.find("(")
    end = name.find(")", start)
    return name[start + 1 : end] if start >= 0 and end >= 0 else ""


def _dependencies(header: _Header, files: set[str]) -> dict[str, list[Entry]]:
    """Each kind of dependency, as createrepo_c lists it.

    Of what a package requires, it leaves out what rpm itself provides (`rpmlib(...)`),
    its own files that `primary.xml` lists, what the package provides itself in the
    same words, and what it requires twice; of `libc.so.6`, it keeps the highest
    version alone, last.
    """
    found: dict[str, list[Entry]] = {}
    provided: dict[str, tuple[str, str, bool]] = {}
    for kind, (names_tag, flags_tag, versions_tag) in DEPENDENCIES.items():
        names = header.strings(names_tag)
        numbers = header.numbers(flags_tag)
        said = header.strings(versions_tag)
        if len(numbers) != len(names) or len(said) != len(names):
            numbers = (numbers + [0] * len(names))[: len(names)]
            said = (said + [""] * len(names))[: len(names)]
        entries: list[Entry] = []
        seen: dict[str, tuple[str, str, bool]] = {}
        libc: Entry | None = None
        for name, number, version in zip(names, numbers, said, strict=True):
            flags = _flags(number)
            pre = False
            if kind == "requires":
                if name.startswith("rpmlib("):
                    continue
                if name.startswith("/") and name in files and is_primary(name):
                    continue
                if provided.get(name) == (flags, version, pre):
                    continue
                pre = _is_pre(number)
                if seen.get(name) == (flags, version, pre):
                    continue
            epoch, ver, rel = versions.split_evr(version) if version else ("", "", "")
            entry = Entry(name, flags, epoch, ver, rel, pre)
            if kind == "provides":
                provided[name] = (flags, version, pre)
            if kind == "requires":
                if name.startswith("libc.so.6"):
                    if (
                        libc is None
                        or versions.compare(_libc_version(libc.name), _libc_version(name)) < 0
                    ):
                        libc = entry
                    continue
                seen[name] = (flags, version, pre)
            entries.append(entry)
        if libc is not None:
            entries.append(libc)
        if entries:
            found[kind] = entries
    return found


def _files(header: _Header) -> list[tuple[str, str]]:
    basenames = header.strings(_BASENAMES)
    directories = header.strings(_DIRNAMES)
    indexes = header.numbers(_DIRINDEXES)
    modes = header.numbers(_FILEMODES)
    flags = header.numbers(_FILEFLAGS)
    if not (len(indexes) == len(basenames) and len(modes) in (0, len(basenames))):
        raise InvalidPackage("its list of files does not hold together")
    files = []
    for number, (basename, index) in enumerate(zip(basenames, indexes, strict=True)):
        if index >= len(directories):
            raise InvalidPackage("its list of files names a directory it does not have")
        mode = modes[number] if modes else 0
        if mode & _FILE_TYPE == _DIRECTORY:
            kind = "dir"
        elif number < len(flags) and flags[number] & _RPMFILE_GHOST:
            kind = "ghost"
        else:
            kind = ""
        files.append((directories[index] + basename, kind))
    return files


def _changelogs(header: _Header) -> list[Changelog]:
    """The newest ten entries, oldest first.

    Of two entries with the same time, createrepo_c moves the newer one a second
    later, and so on along a run of them, so that each has a time of its own.
    """
    times = header.numbers(_CHANGELOGTIME)
    names = header.strings(_CHANGELOGNAME)
    texts = header.strings(_CHANGELOGTEXT)
    kept: list[list[Any]] = []  # oldest first
    last = None
    for time, name, text in list(zip(times, names, texts, strict=False))[:CHANGELOGS_KEPT]:
        kept.insert(0, [name.rstrip(" ") or name[:1], time, text])
        if time == last:
            moved = time
            for previous in kept[1:]:
                if previous[1] != moved:
                    break
                previous[1] += 1
                moved += 1
        else:
            last = time
    return [Changelog(author, date, text) for author, date, text in kept]


def describe(header: _Header, signature: _Header, start: int, end: int) -> Rpm:
    """What a package's headers say, as createrepo_c would list it."""
    name = header.string(_NAME)
    version = header.string(_VERSION)
    release = header.string(_RELEASE)
    arch = header.string(_ARCH)
    if not (name and version and release and arch):
        raise InvalidPackage("it says no name, version, release or architecture")
    if versions.NAME.fullmatch(name) is None:
        raise InvalidPackage(f"its name cannot be a package's: {name[:80]!r}")
    files = _files(header)
    epoch = header.numbers(_EPOCH)
    return Rpm(
        name=name,
        epoch=str(epoch[0]) if epoch else "0",
        version=version,
        release=release,
        arch=arch,
        summary=header.string(_SUMMARY),
        description=header.string(_DESCRIPTION),
        packager=header.string(_PACKAGER),
        url=header.string(_URL),
        license=header.string(_LICENSE),
        vendor=header.string(_VENDOR),
        group=header.string(_GROUP),
        buildhost=header.string(_BUILDHOST),
        sourcerpm=header.string(_SOURCERPM),
        build_time=header.number(_BUILDTIME),
        installed_size=header.number(_LONGSIZE, _SIZE),
        archive_size=signature.number(_SIG_LONGARCHIVESIZE, _SIG_PAYLOADSIZE)
        or header.number(_ARCHIVESIZE),
        header_start=start,
        header_end=end,
        dependencies=_dependencies(header, {path for path, _ in files}),
        files=files,
        changelogs=_changelogs(header),
    )


async def read(chunks: AsyncIterator[bytes]) -> Rpm:
    """What an RPM says of itself. Raises InvalidPackage.

    Reads no more of `chunks` than the lead and the headers: the caller closes them.
    """
    reader = _Reader(chunks)
    lead = await reader.exactly(_LEAD)
    if lead[:4] != _LEAD_MAGIC:
        raise InvalidPackage("it is not an RPM")
    if struct.unpack(">H", lead[6:8])[0] == _SOURCE:
        raise InvalidPackage("it is a source RPM, which dnf does not install")
    signature, length = await _header(reader, HEADER_MOST)
    padding = -length % 8
    await reader.exactly(padding)
    start = _LEAD + length + padding
    header, size = await _header(reader, HEADER_MOST - length)
    if _SOURCEPACKAGE in header:
        raise InvalidPackage("it is a source RPM, which dnf does not install")
    return describe(header, signature, start, start + size)
```

```python
"""What a path of a YUM repository is.

Packages are where their uploaders put them. A hosted repository's `repodata_depth`
says where the `repodata/` directories are: at depth 0, one at the root for every
package; at depth 2, one in each directory two levels down (`el9/x86_64/repodata/`),
for the packages under it. Beside them is `public.key`, the key a hosted repository
signs with.
"""

import re
from dataclasses import dataclass

from megooarti.repositories.yum import versions

PUBLIC_KEY = "public.key"
REPOMD = "repomd.xml"
SIGNATURE = "repomd.xml.asc"
DEPTH_MOST = 5
# A `repodata/` file named by its hash, which never changes.
HASHED = re.compile(r"[0-9a-f]{32,128}-[^/]+")


@dataclass(frozen=True)
class YumPath:
    kind: str  # key, repodata, package, other
    directory: str = ""  # of a package: the directory its repodata is in; of repodata, its own
    filename: str = ""


def repodata_of(path: str) -> tuple[str, str] | None:
    """The directory and the file's name of a path in a `repodata/`, or None."""
    directory, _, rest = ("/" + path).rpartition("/repodata/")
    if not rest or "/" in rest:
        return None
    return directory.removeprefix("/"), rest


def directory_of(path: str, depth: int) -> str | None:
    """The directory whose `repodata/` lists a package, or None if it is not that deep."""
    parts = path.split("/")[:-1]
    if len(parts) < depth:
        return None
    return "/".join(parts[:depth])


def classify(path: str, depth: int = 0) -> YumPath:
    if path == PUBLIC_KEY:
        return YumPath("key")
    found = repodata_of(path)
    if found is not None:
        return YumPath("repodata", found[0], found[1])
    if path.endswith(".rpm") and "/repodata/" not in f"/{path}":
        directory = directory_of(path, depth)
        return YumPath("package", directory or "", path.rpartition("/")[2])
    return YumPath("other")


def deep_enough(path: str, depth: int) -> bool:
    return directory_of(path, depth) is not None


def at_depth(directory: str, depth: int) -> bool:
    """Whether a directory is one that has a `repodata/` at this depth."""
    return len(directory.split("/")) == depth if directory else depth == 0


def in_repodata(directory: str, filename: str) -> str:
    """A `repodata/` file's path."""
    return f"{directory}/repodata/{filename}" if directory else f"repodata/{filename}"


def named(path: str) -> tuple[str, str, str] | None:
    """The name, `version-release` and architecture an RPM's file name says, or None.

    `name-version-release.arch.rpm`: the version and release are the last two parts
    before the architecture, as rpm itself names its files. A name says no epoch.
    """
    filename = path.rpartition("/")[2]
    if not filename.endswith(".rpm"):
        return None
    stem, _, arch = filename.removesuffix(".rpm").rpartition(".")
    name, _, rest = stem.rpartition("-")
    name, _, version = name.rpartition("-")
    if not (name and version and rest and arch) or versions.NAME.fullmatch(name) is None:
        return None
    return name, f"{version}-{rest}", arch


def hashed(filename: str) -> bool:
    return HASHED.fullmatch(filename) is not None
```

Create `backend/src/megooarti/repositories/yum/repodata.py`:

```python
"""A directory's `repodata/`: what dnf reads to know the packages under it.

`primary.xml` lists each package, its dependencies and its files that dnf most often
looks for; `filelists.xml` every file; `other.xml` the changelogs. Each is written as
`createrepo_c` writes it, packed with gzip, and named by its hash; `repomd.xml` names
the three, and is what a repository signs.

They are written from what was read of each package at upload, and from nothing
else: the same packages make the same bytes, in any process.
"""

import gzip
import hashlib
import re
from collections.abc import Iterable, Sequence
from dataclasses import dataclass

from megooarti.repositories.yum.rpms import DEPENDENCIES, Entry, Rpm, is_primary

_COMMON = "http://linux.duke.edu/metadata/common"
_RPM = "http://linux.duke.edu/metadata/rpm"
_START = '<?xml version="1.0" encoding="UTF-8"?>\n'
# Characters XML 1.0 cannot hold: they are left out.
_UNWRITABLE = re.compile("[\x00-\x08\x0b\x0c\x0e-\x1f￾￿]")
_IN_TEXT = {"&": "&amp;", "<": "&lt;", ">": "&gt;", "\r": "&#13;"}
_IN_ATTRIBUTE = {**_IN_TEXT, '"': "&quot;", "\n": "&#10;", "\t": "&#9;"}
_TEXT_ESCAPED = re.compile("[&<>\r]")
_ATTRIBUTE_ESCAPED = re.compile('[&<>"\n\r\t]|[^\x00-\x7f]')


@dataclass(frozen=True)
class Listed:
    """A package that a `repodata/` lists, and its file."""

    location: str  # its path under the directory `repodata/` is in
    size: int
    sha256: str
    time: int  # when its file was stored, in seconds since 1970
    rpm: Rpm


def text(value: str) -> str:
    """Text as libxml2 writes it between tags."""
    return _TEXT_ESCAPED.sub(lambda m: _IN_TEXT[m[0]], _UNWRITABLE.sub("", value))


def attribute(value: str) -> str:
    """Text as libxml2 writes it in an attribute: beyond ASCII as character references."""

    def escaped(found: re.Match[str]) -> str:
        character = found[0]
        return _IN_ATTRIBUTE.get(character) or f"&#x{ord(character):X};"

    return _ATTRIBUTE_ESCAPED.sub(escaped, _UNWRITABLE.sub("", value))


def _version(rpm: Rpm) -> str:
    return (
        f'<version epoch="{attribute(rpm.epoch)}" ver="{attribute(rpm.version)}" '
        f'rel="{attribute(rpm.release)}"/>'
    )


def _entry(entry: Entry, requires: bool) -> str:
    said = [f'name="{attribute(entry.name)}"']
    if entry.flags:
        said.append(f'flags="{entry.flags}"')
        for name, value in (("epoch", entry.epoch), ("ver", entry.version), ("rel", entry.release)):
            if value:
                said.append(f'{name}="{attribute(value)}"')
    if requires and entry.pre:
        said.append('pre="1"')
    return f"      <rpm:entry {' '.join(said)}/>\n"


def _files(files: Iterable[tuple[str, str]], indent: str) -> str:
    written = []
    for path, kind in files:
        typed = f' type="{kind}"' if kind else ""
        written.append(f"{indent}<file{typed}>{text(path)}</file>\n")
    return "".join(written)


def _primary_package(listed: Listed) -> str:
    rpm = listed.rpm
    parts = [
        '<package type="rpm">\n',
        f"  <name>{text(rpm.name)}</name>\n",
        f"  <arch>{text(rpm.arch)}</arch>\n",
        f"  {_version(rpm)}\n",
        f'  <checksum type="sha256" pkgid="YES">{listed.sha256}</checksum>\n',
        f"  <summary>{text(rpm.summary)}</summary>\n",
        f"  <description>{text(rpm.description)}</description>\n",
        f"  <packager>{text(rpm.packager)}</packager>\n",
        f"  <url>{text(rpm.url)}</url>\n",
        f'  <time file="{listed.time}" build="{rpm.build_time}"/>\n',
        f'  <size package="{listed.size}" installed="{rpm.installed_size}" '
        f'archive="{rpm.archive_size}"/>\n',
        f'  <location href="{attribute(listed.location)}"/>\n',
        "  <format>\n",
        f"    <rpm:license>{text(rpm.license)}</rpm:license>\n",
        f"    <rpm:vendor>{text(rpm.vendor)}</rpm:vendor>\n",
        f"    <rpm:group>{text(rpm.group)}</rpm:group>\n",
        f"    <rpm:buildhost>{text(rpm.buildhost)}</rpm:buildhost>\n",
        f"    <rpm:sourcerpm>{text(rpm.sourcerpm)}</rpm:sourcerpm>\n",
        f'    <rpm:header-range start="{rpm.header_start}" end="{rpm.header_end}"/>\n',
    ]
    for kind in DEPENDENCIES:
        entries = rpm.dependencies.get(kind)
        if entries:
            parts.append(f"    <rpm:{kind}>\n")
            parts.extend(_entry(entry, kind == "requires") for entry in entries)
            parts.append(f"    </rpm:{kind}>\n")
    parts.append(_files(((p, k) for p, k in rpm.files if is_primary(p)), "    "))
    parts.append("  </format>\n</package>\n")
    return "".join(parts)


def primary(listed: Sequence[Listed]) -> bytes:
    """`primary.xml`: every package, as createrepo_c writes it."""
    head = f'<metadata xmlns="{_COMMON}" xmlns:rpm="{_RPM}" packages="{len(listed)}">\n'
    body = "".join(_primary_package(each) for each in listed)
    return (_START + head + body + "</metadata>").encode()


def _owned(listed: Listed) -> str:
    rpm = listed.rpm
    return (
        f'<package pkgid="{listed.sha256}" name="{attribute(rpm.name)}" '
        f'arch="{attribute(rpm.arch)}">\n  {_version(rpm)}\n'
    )


def filelists(listed: Sequence[Listed]) -> bytes:
    """`filelists.xml`: every file of every package."""
    head = (
        f'<filelists xmlns="http://linux.duke.edu/metadata/filelists" packages="{len(listed)}">\n'
    )
    body = "".join(_owned(each) + _files(each.rpm.files, "  ") + "</package>\n" for each in listed)
    return (_START + head + body + "</filelists>").encode()


def other(listed: Sequence[Listed]) -> bytes:
    """`other.xml`: the changelogs that were kept of every package."""
    head = f'<otherdata xmlns="http://linux.duke.edu/metadata/other" packages="{len(listed)}">\n'
    parts = [_START, head]
    for each in listed:
        parts.append(_owned(each))
        for entry in each.rpm.changelogs:
            parts.append(
                f'  <changelog author="{attribute(entry.author)}" date="{entry.date}">'
                f"{text(entry.text)}</changelog>\n"
            )
        parts.append("</package>\n")
    parts.append("</otherdata>")
    return "".join(parts).encode()


def pack(data: bytes) -> bytes:
    """Packed with gzip, with no date or name in it: the same bytes every time."""
    return gzip.compress(data, compresslevel=6, mtime=0)


def repodata(listed: Sequence[Listed], moment: int) -> dict[str, bytes]:
    """Every file of a `repodata/`, by its name in it. `moment` is the revision's time."""
    files: dict[str, bytes] = {}
    data = []
    for kind, write in (("primary", primary), ("filelists", filelists), ("other", other)):
        opened = write(listed)
        packed = pack(opened)
        digest = hashlib.sha256(packed).hexdigest()
        name = f"{digest}-{kind}.xml.gz"
        files[name] = packed
        data.append(
            f'  <data type="{kind}">\n'
            f'    <checksum type="sha256">{digest}</checksum>\n'
            f'    <open-checksum type="sha256">{hashlib.sha256(opened).hexdigest()}'
            "</open-checksum>\n"
            f'    <location href="repodata/{name}"/>\n'
            f"    <timestamp>{moment}</timestamp>\n"
            f"    <size>{len(packed)}</size>\n"
            f"    <open-size>{len(opened)}</open-size>\n"
            "  </data>\n"
        )
    files["repomd.xml"] = (
        f'{_START}<repomd xmlns="http://linux.duke.edu/metadata/repo" xmlns:rpm="{_RPM}">\n'
        f"  <revision>{moment}</revision>\n" + "".join(data) + "</repomd>\n"
    ).encode()
    return files
```

```python
"""The YUM format: hosted repositories that dnf installs from, and proxies of mirrors.

This is the only YUM module that touches the repository context. What a path means,
what a package says of itself and what its metadata says come from the pure modules
beside it.

A package is uploaded to the path it is kept at. Its headers are read once, as it is
stored, and what they say is kept with it. Each `repodata/` is written from what was
kept: once for each revision of the repository, in a worker thread, with `repomd.xml`
signed by the repository's key. Until the next change it is served from memory, and
so are the hash-named files of the revision before, which a client that read the
older `repomd.xml` a moment ago is still fetching.

A proxy is the generic engine: its remote's `repomd.xml` is metadata, checked again
after the proxy's metadata age, and passed on as the remote wrote it; the files it
names carry their hash in their names, and never change.
"""

import asyncio
import hashlib
from collections import defaultdict
from collections.abc import Sequence
from contextlib import aclosing
from typing import Any

from starlette.requests import Request
from starlette.responses import Response

from megooarti.clock import utcnow
from megooarti.errors import ApiError
from megooarti.repositories import derived, signing
from megooarti.repositories.content import RepositoryContext, Snapshot
from megooarti.repositories.formats import (
    ComponentKey,
    Format,
    Usage,
    declared_hashes,
    declared_size,
    invalid_upload,
    only_fields,
    register,
)
from megooarti.repositories.forms import UploadForm
from megooarti.repositories.paths import normalise_path
from megooarti.repositories.yum import paths, repodata, rpms, versions
from megooarti.storage.backends import StagedBlob

# Where what a package said of itself is kept among its file's attributes, and what is
# said of the version among its component's.
_DECLARED = "yum"
_RPM = "application/x-rpm"
_XML = "application/xml"
_PACKED = {".gz": "application/gzip", ".xz": "application/x-xz", ".zst": "application/zstd"}
_SIGNATURE = "application/pgp-signature"
_KEY = "application/pgp-keys"
# Where, among the index files of a revision, the `repodata/` of a directory that holds
# no package is: one that no path can be.
_EMPTY = "/"


def _invalid(reason: object) -> ApiError:
    return ApiError(400, "invalid_package", f"The package cannot be accepted: {reason}.")


def _invalid_path(reason: str) -> ApiError:
    return ApiError(400, "invalid_path", f"The path is not valid: {reason}.")


def _not_found(message: str = "Nothing is served at this address.") -> ApiError:
    return ApiError(404, "not_found", message)


def _not_allowed(allowed: str) -> ApiError:
    return ApiError(
        405,
        "method_not_allowed",
        f"This address accepts {allowed}.",
        headers={"Allow": allowed},
    )


def _is_read(request: Request) -> bool:
    return request.method in ("GET", "HEAD")


def _invalid_setting(field: str, message: str) -> ApiError:
    details = [{"field": field, "message": message}]
    return ApiError(422, "validation_error", "The request is not valid.", details)


def _declared(attributes: dict[str, Any] | None) -> dict[str, Any]:
    declared = (attributes or {}).get(_DECLARED)
    return declared if isinstance(declared, dict) else {}


def _rpm_of(attributes: dict[str, Any] | None) -> rpms.Rpm | None:
    """What a stored package said of itself, as it was kept."""
    said = _declared(attributes).get("rpm")
    return rpms.Rpm.from_json(said) if isinstance(said, dict) else None


def depth_of(context: RepositoryContext) -> int:
    return context.repository.config.get("format_config", {}).get("repodata_depth", 0)


# --- Uploading -----------------------------------------------------------------------


def _check_path(path: str, depth: int) -> None:
    """Refuse a path a package cannot be kept at."""
    parsed = paths.classify(path, depth)
    if parsed.kind != "package":
        raise _invalid_path("a package's path ends in `.rpm`, outside `repodata/`")
    if not paths.deep_enough(path, depth):
        raise _invalid_path(
            f"this repository's metadata is {depth} directories down "
            f"(repodata_depth), so a package must be at least that deep"
        )


async def _read(context: RepositoryContext, staged: StagedBlob) -> rpms.Rpm:
    """What a staged package says of itself.

    Only its headers are read, and the file is closed at once: a file that is still
    open cannot be moved into the store, or removed, on every system.
    """
    try:
        async with aclosing(context.open_staged(staged)) as chunks:
            return await rpms.read(chunks)
    except rpms.InvalidPackage as error:
        raise _invalid(error) from None


async def _keep(context: RepositoryContext, path: str, staged: StagedBlob, rpm: rpms.Rpm) -> bool:
    """Store a package at its path. Returns whether it is new there."""
    held = await context.component("", rpm.name, rpm.evr)
    known = _declared(held.attributes if held else None).get("architectures", [])
    _, created = await context.store(
        path,
        staged,
        content_type=_RPM,
        attributes={_DECLARED: {"rpm": rpm.as_json(), "stored": int(utcnow().timestamp())}},
        component_attributes={
            _DECLARED: {
                "summary": rpm.summary,
                "architectures": sorted({*known, rpm.arch}),
            }
        },
    )
    return created


async def _put(context: RepositoryContext, request: Request, path: str) -> Response:
    """One package, as `curl --upload-file` sends it to its path."""
    _check_path(path, depth_of(context))
    # Refused before the body is read; the facade checks again when the file is stored.
    context.require_write()
    await context.release()  # the body needs no connection
    staged = await context.stage(
        request.stream(),
        expected_size=declared_size(request),
        expected_hashes=declared_hashes(request),
    )
    try:
        rpm = await _read(context, staged)
    except ApiError:
        await context.discard(staged)
        raise
    created = await _keep(context, path, staged, rpm)
    return Response(status_code=201 if created else 204)


# --- The metadata --------------------------------------------------------------------


def _listed(snapshot: Snapshot, depth: int) -> dict[str, list[repodata.Listed]]:
    """The packages each directory's `repodata/` lists, by the directory."""
    listed: dict[str, list[repodata.Listed]] = defaultdict(list)
    for held in snapshot.files:
        rpm = _rpm_of(held.attributes)
        directory = paths.directory_of(held.path, depth)
        if rpm is None or directory is None:
            continue  # nothing a hosted repository holds, but it belongs to no metadata
        location = held.path[len(directory) + 1 :] if directory else held.path
        stored = _declared(held.attributes).get("stored", 0)
        listed[directory].append(
            repodata.Listed(location, held.size, held.sha256, int(stored), rpm)
        )
    return listed


def _signed(listed: Sequence[repodata.Listed], moment: int, signer: signing.Signer):
    files = repodata.repodata(listed, moment)
    files[paths.SIGNATURE] = signer.detached(files[paths.REPOMD])
    return files


def _carried(previous: derived.Written | None) -> dict[str, bytes]:
    """The hash-named files the last revision's `repomd.xml` named: a client may still want them."""
    if previous is None:
        return {}
    carried = {}
    for key, data in previous.files.items():
        found = paths.repodata_of(key)
        if found is None or not paths.hashed(found[1]):
            continue
        repomd = previous.files.get(paths.in_repodata(found[0], paths.REPOMD), b"")
        if f'href="repodata/{found[1]}"'.encode() in repomd:
            carried[key] = data
    return carried


def _written(
    snapshot: Snapshot, depth: int, signer: signing.Signer, previous: derived.Written | None
) -> derived.Written:
    """Every `repodata/` file of a revision, by its path; and the last revision's."""
    moment = int(snapshot.changed.timestamp())
    listed = _listed(snapshot, depth)
    # At depth 0 the root always has one; deeper, any directory without packages has
    # the same, empty one.
    listed.setdefault("" if depth == 0 else _EMPTY, [])
    files = _carried(previous)
    for directory, packages in listed.items():
        for name, data in _signed(packages, moment, signer).items():
            files[paths.in_repodata(directory, name)] = data
    return derived.Written(snapshot.revision, snapshot.changed, files)


async def hosted_repodata(context: RepositoryContext) -> derived.Written:
    """The `repodata/` files of this repository's revision: kept, or written now, once."""
    revision, _ = await context.revision()

    async def write() -> derived.Written:
        snapshot = await context.snapshot()
        key = await signing.key_of(context.db, context.settings, context.repository)
        signer = signing.signer(context.settings, key)
        previous = derived.peek(context.repository.id)
        await context.release()  # writing them needs no connection
        return await asyncio.to_thread(_written, snapshot, depth_of(context), signer, previous)

    return await derived.written(context.repository.id, revision, write)


def repodata_content_type(filename: str) -> str:
    if filename.endswith(".asc"):
        return _SIGNATURE
    if filename.endswith(".xml"):
        return _XML
    return _PACKED.get(filename[filename.rfind(".") :], "application/octet-stream")


async def _repodata(
    context: RepositoryContext, request: Request, parsed: paths.YumPath
) -> Response:
    depth = depth_of(context)
    if not paths.at_depth(parsed.directory, depth):
        raise _not_found(
            f"This repository's metadata is {depth} directories down (repodata_depth)."
        )
    written = await hosted_repodata(context)
    data = written.files.get(paths.in_repodata(parsed.directory, parsed.filename))
    if data is None and paths.in_repodata(parsed.directory, paths.REPOMD) not in written.files:
        data = written.files.get(paths.in_repodata(_EMPTY, parsed.filename))
    if data is None:
        raise _not_found("This repository's metadata has no such file.")
    return context.respond_with(
        data,
        request,
        filename=parsed.filename,
        content_type=repodata_content_type(parsed.filename),
        last_modified=written.changed,
        etag=hashlib.sha256(data).hexdigest(),
        # Two revisions can be made within one second: only the bytes say which one a
        # client has.
        dated=False,
    )


async def _public_key(context: RepositoryContext, request: Request) -> Response:
    key = await signing.key_of(context.db, context.settings, context.repository)
    return context.respond_with(
        key.public_key.encode(),
        request,
        filename=paths.PUBLIC_KEY,
        content_type=_KEY,
        last_modified=key.created_at,
        etag=key.fingerprint.lower(),
    )


class YumFormat(Format):
    name = "yum"
    types = frozenset({"hosted", "proxy"})
    derives_indexes = True
    signs = signing.OPENPGP

    def validate_config(
        self, repository_type: str, config: dict[str, Any], current: dict[str, Any] | None = None
    ) -> dict[str, Any]:
        """A hosted repository's `repodata_depth`, which never changes."""
        if repository_type != "hosted":
            return super().validate_config(repository_type, config, current)
        unknown = sorted(set(config) - {"repodata_depth"})
        if unknown:
            raise _invalid_setting(f"format_config.{unknown[0]}", "This is not a setting of YUM.")
        stored = 0 if current is None else current.get("repodata_depth", 0)
        depth = config.get("repodata_depth", stored)
        if type(depth) is not int or not 0 <= depth <= paths.DEPTH_MOST:
            raise _invalid_setting(
                "format_config.repodata_depth",
                f"The depth of the metadata is a whole number from 0 to {paths.DEPTH_MOST}.",
            )
        if current is not None and depth != stored:
            raise _invalid_setting(
                "format_config.repodata_depth",
                "The depth of the metadata cannot change once the repository is made.",
            )
        return {"repodata_depth": depth}

    def describe_component(
        self, path: str, attributes: dict[str, Any] | None = None
    ) -> ComponentKey | None:
        """A package belongs to its name and version: what it said, or its file's name."""
        rpm = _rpm_of(attributes)
        if rpm is not None:
            return ComponentKey("", rpm.name, rpm.evr)
        named = paths.named(path) if paths.classify(path).kind == "package" else None
        return None if named is None else ComponentKey("", named[0], named[1])

    def search_text(self, key: ComponentKey, attributes: dict[str, Any]) -> str:
        """Its name and version, its summary, and its architectures."""
        declared = _declared(attributes)
        words = [super().search_text(key, attributes)]
        summary = declared.get("summary")
        if isinstance(summary, str):
            words.append(summary)
        architectures = declared.get("architectures")
        if isinstance(architectures, list):
            words.extend(str(architecture) for architecture in architectures)
        return " ".join(words)

    async def upload(self, context: RepositoryContext, form: UploadForm) -> list[str]:
        """Store packages in a `directory`, each by its file's name."""
        only_fields(form, ("directory",))
        if not form.files:
            raise invalid_upload("file", "At least one RPM is needed.")
        directory = form.fields.get("directory", "").strip("/")
        depth = depth_of(context)
        read = []
        for file in form.files:
            if file.field != "file":
                raise invalid_upload(file.field, "A package is sent as `file`.")
            if "/" in file.filename or "\\" in file.filename:
                raise invalid_upload("file", f"A file's name cannot hold a slash: {file.filename}")
            path = normalise_path(f"{directory}/{file.filename}" if directory else file.filename)
            _check_path(path, depth)
            if any(path == other for other, _ in read):
                raise invalid_upload("file", f"Two files are named {file.filename}.")
            read.append((path, await _read(context, file.staged)))
        for (path, rpm), file in zip(read, form.files, strict=True):
            await _keep(context, path, file.staged, rpm)
        return [path for path, _ in read]

    def usage(self, address: str, key: ComponentKey, files: Sequence[str]) -> list[Usage]:
        if versions.NAME.fullmatch(key.name) is None or versions.split(key.version) is None:
            return []
        return [Usage("dnf", "shell", f"sudo dnf install {key.name}-{key.version}")]

    def content_type(self, path: str, declared: str | None) -> str | None:
        parsed = paths.classify(path)
        if parsed.kind == "package":
            return _RPM
        if parsed.kind == "repodata":
            return repodata_content_type(parsed.filename)
        return declared

    def is_metadata(self, path: str) -> bool:
        """`repomd.xml` changes as packages are published; what it names by hash does not."""
        parsed = paths.classify(path)
        return parsed.kind == "repodata" and not paths.hashed(parsed.filename)

    async def handle_hosted(
        self, context: RepositoryContext, request: Request, path: str
    ) -> Response:
        parsed = paths.classify(path, depth_of(context))
        if parsed.kind == "package":
            if _is_read(request):
                return await context.respond(path, request)
            if request.method == "PUT":
                return await _put(context, request, path)
            if request.method != "DELETE":
                raise _not_allowed("GET, HEAD, PUT, DELETE")
            if not await context.delete(path):
                raise _not_found("No such package.")
            return Response(status_code=204)
        if not _is_read(request):
            if request.method == "PUT" and parsed.kind == "other":
                raise _invalid_path("a package's path ends in `.rpm`, outside `repodata/`")
            raise _not_allowed("GET, HEAD")
        if parsed.kind == "key":
            return await _public_key(context, request)
        if parsed.kind == "repodata":
            return await _repodata(context, request, parsed)
        raise _not_found()


register(YumFormat())
```

````markdown
What is true of every repository is in [Repositories](../repositories.md). This is
what is this format's own: RPM packages, for Fedora, Rocky Linux, RHEL and their kin,
installed with dnf.

A hosted repository holds the `.rpm` files you build, and writes and signs their
metadata with a key of its own. Its `repodata_depth` says where the metadata is: at 0,
one `repodata/` at the root for every package; at 2, as here, one in each directory
two levels down, for the packages under it, so that one repository can hold a
directory for each release and architecture:

```bash
curl -u admin -H 'Content-Type: application/json' -d '{
  "name": "yum-hosted", "format": "yum", "type": "hosted",
  "format_config": {"repodata_depth": 2}
}' http://localhost:8000/api/v1/repositories

curl -u ci --upload-file megooarti-hello-1.0-1.noarch.rpm \
  https://repo.example.com/repository/yum-hosted/el10/x86_64/
```

repository itself, with the account dnf signs in with. `repo_gpgcheck=1` has dnf check

`.../fedora/linux/releases/44/Everything/x86_64/os` and the key

distribution (BaseOS, AppStream, updates, ...): make one for each, and take away the
`metalink=` or `mirrorlist=` lines of the distribution's own `.repo` files, which
would lead dnf past MegooArti.

- **Credentials** go in the `.repo` file, as above: a user name and a password, or a

  UI or [the API](../api.md#uploading), with a `directory` field and one or more `file`

  as many directories down as the repository's `repodata_depth`; otherwise it is
  refused with `400 invalid_path`. A file that is not an RPM, and a source RPM, are
  refused with `400 invalid_package`. At most 64 MiB of a package's headers are read.
- **`repodata_depth`** is chosen when the repository is made, from 0 to 5, and fixed
  after. Every directory exactly that deep has a `repodata/`: one without packages has
  an empty one, so a machine can be set up before anything is uploaded for it.
- **A package's version** is its name and `epoch:version-release`, the epoch only when
  it is not 0: that is what the web UI shows, and what `dnf install` is given
  (`dnf install megooarti-tool-2:0.3-2`). Each architecture's file is one file of it.
- **Uploading a package again** to the same path follows the deployment policy. With
  `disable_redeploy` it answers `409`.
- **The metadata is written from the packages**: `primary.xml`, `filelists.xml` and
  `other.xml` (the ten newest changelog entries), packed with gzip and named by their
  hash, as `createrepo_c` writes them, and `repomd.xml`, which names them and is signed
  as `repomd.xml.asc`. It is written once after each change and kept in memory until
  the next. The files the `repomd.xml` before the last change named are kept as well,
  for a machine that read it a moment before. A client is sent `repomd.xml` again
  unless it has the same bytes (`If-None-Match`): two changes within one second have
  the same date.
- **The signing key** is made the first time it is needed: an Ed25519 OpenPGP key that
  never expires. `GET /api/v1/repositories/<name>/signing-key` shows it, and
  `POST /api/v1/repositories/<name>/signing-key/generate` (with
  `{"algorithm": "rsa4096"}` for an RSA key) or `PUT` of an armoured private key in
  `private_key` replaces it, for whoever holds `admin:repositories:write`. From then on
  the metadata is signed with the new key only: every machine must fetch the new
  `public.key`. The private key is kept sealed with the installation's secret key, and
  is never shown. MegooArti signs the metadata, not the packages: sign those with
  `rpmsign` before uploading them if machines are to check them (`gpgcheck=1`).
- **Deleting** a package (`DELETE` on its address) takes it out of the metadata at
  once.
- **A proxy**'s `repodata/repomd.xml` (and its signature, if the remote has one) is
  checked again with the remote after `metadata_max_age_minutes`; the files it names
  carry their hash in their names, and are kept, as packages are. A metalink or a
  mirror list is not proxied.
````

```python
def send(method: str, path: str, data: bytes | None = None) -> tuple[int, bytes]:
    """A request to a repository from outside, as `ci`: (status, body)."""

        data=data,

    )
    try:
        with urllib.request.urlopen(request, timeout=60) as response:
            return response.status, response.read()
    except urllib.error.HTTPError as error:
        return error.code, error.read()
```
