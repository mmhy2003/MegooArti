# NuGet Hosted Repositories Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** .NET developers push packages to a hosted NuGet repository with `dotnet nuget push`, find them with `dotnet package search`, restore them into projects, and delete them, over NuGet's V3 protocol, signing in with an API token.

**Architecture:** A new format, `nuget`, in `backend/src/megooarti/repositories/nuget/`: pure modules for ids and versions (`versions.py`), reading a package's zip and `.nuspec` without unpacking it (`packages.py`), what a path is (`paths.py`), V3's documents (`documents.py`) and search (`queries.py`), and the one module that touches the repository context (`format.py`). A package's `.nuspec` is read once, as it is pushed, and kept with its version; V3's documents are written from those on each request, as npm's package documents are. Two small changes outside the format: the repository context learns to find a name without regard to case and to list the versions a search's words find, and the content route takes NuGet's `X-NuGet-ApiKey` as an API token.

**Tech Stack:** Python 3.13, FastAPI, SQLAlchemy, `python-multipart`, expat; pytest; the .NET SDKs 10 and 8 (`mcr.microsoft.com/dotnet/sdk`) for the real-client tests.

**Spec:** [docs/superpowers/specs/2026-10-15-nuget-design.md](../specs/2026-10-15-nuget-design.md), sections 4 (4.1 to 4.3), 5, 9, 10 and the row of plan 13a in section 12.

| # | Decision | Reason |
| --- | --- | --- |
| W1 | A hosted repository's V3 documents are written from the database on each request, as npm's package documents are, and kept nowhere (in place of 5's "kept by revision"): an id's versions and registration from that id's versions, search from the versions whose stored words hold what was asked. | Each document is of one id, or of what one search found: one query, where a cache of every id's documents would be written again after every push. |

## Global Constraints

- **A format never touches a table or a file**: the format works through the repository context; what it needs of the database is a method of the context.
- **What is read of a package is bounded** (spec 9): its zip's directory at 10,000 entries (and 16 MiB), its `.nuspec` at 1 MiB; nothing but the `.nuspec` is inflated.
- **XML is read with expat, a DOCTYPE refused**, as Maven's metadata is: a `.nuspec` comes from whoever pushed it.
- **A search takes at most 1,000 results, and `skip + take` is at most 3,000** (spec 9).
- **Every test of a stack is marked `docker`.** A real client reaches the stack at `http://gateway/`, in a container on its network.
- **A table's line under its headings is `| --- | --- |`.** Commits end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

**Working directories:** run `uv` and `pytest` commands in `backend/`, and `git` commands in the repository root. Backend tests need the `db` Compose service; set `MEGOOARTI_TEST_DATABASE_URL` as `docs/development.md` describes.

```python
"""NuGet packages made in memory, as `dotnet pack` lays them out, for the tests."""

import io
import zipfile
from xml.sax.saxutils import escape

NUSPEC_2013 = "http://schemas.microsoft.com/packaging/2013/05/nuspec.xsd"


def nuspec(
    package_id: str = "MegooArti.Hello",
    version: str = "1.0.0",
    *,
    namespace: str = NUSPEC_2013,
    description: str = "Says hello.",
    authors: str = "MegooArti",
    tags: str = "hello greeting",
    dependencies: str = "",
    package_types: str = "",
    more: str = "",
) -> bytes:
    """A `.nuspec`: `dependencies` and `package_types` are their elements' inner XML."""
    parts = [
        f"<id>{escape(package_id)}</id>",
        f"<version>{escape(version)}</version>",
        f"<authors>{escape(authors)}</authors>",
        f"<description>{escape(description)}</description>",
        f"<tags>{escape(tags)}</tags>" if tags else "",
        f"<dependencies>{dependencies}</dependencies>" if dependencies else "",
        f"<packageTypes>{package_types}</packageTypes>" if package_types else "",
        more,
    ]
    return (
        '<?xml version="1.0" encoding="utf-8"?>\n'
        f'<package xmlns="{namespace}"><metadata>{"".join(parts)}</metadata></package>\n'
    ).encode()


def nupkg(
    package_id: str = "MegooArti.Hello",
    version: str = "1.0.0",
    *,
    spec: bytes | None = None,
    files: dict[str, bytes] | None = None,
    method: int = zipfile.ZIP_DEFLATED,
    **fields: str,
) -> bytes:
    """A package: its `.nuspec` at the top, a library, and what NuGet's packer adds."""
    written = io.BytesIO()
    with zipfile.ZipFile(written, "w", compression=method) as archive:
        archive.writestr("_rels/.rels", b"<Relationships/>")
        archive.writestr(
            f"{package_id}.nuspec",
            spec if spec is not None else nuspec(package_id, version, **fields),
        )
        archive.writestr("lib/net8.0/Hello.dll", b"MZ" + b"\0" * 64)
        archive.writestr("[Content_Types].xml", b"<Types/>")
        for name, data in (files or {}).items():
            archive.writestr(name, data)
    return written.getvalue()


def snupkg(package_id: str = "MegooArti.Hello", version: str = "1.0.0") -> bytes:
    """A symbol package of a package: its `.nuspec` says `SymbolsPackage`."""
    spec = nuspec(package_id, version, package_types='<packageType name="SymbolsPackage"/>')
    return nupkg(package_id, version, spec=spec, files={"lib/net8.0/Hello.pdb": b"BSJB"})


def reader(data: bytes):
    """What `packages.read` asks for its bytes by, from bytes in memory."""

    async def read(start: int, length: int) -> bytes:
        return data[start : start + length]

    return read
```

```python
"""NuGet's ids and versions: what each may be, how a version is written, and their order.

As NuGet's own client has them: an id is matched without regard to case, and a version
is normalized before it is compared or put into an address (no leading zeros, no
fourth part of 0, no build metadata).
"""

import re
from dataclasses import dataclass

# An id, as NuGet takes one: words joined by dots or hyphens, at most 100 characters.
ID = re.compile(r"[A-Za-z0-9_]+([.-][A-Za-z0-9_]+)*")
ID_MOST = 100
_VERSION = re.compile(
    r"(?P<numbers>[0-9]+(\.[0-9]+){0,3})"
    r"(-(?P<release>[0-9A-Za-z-]+(\.[0-9A-Za-z-]+)*))?"
    r"(\+(?P<metadata>[0-9A-Za-z-]+(\.[0-9A-Za-z-]+)*))?"
)
# A part of a version is at most this: NuGet keeps each in a 32-bit integer.
_PART_MOST = 2**31 - 1
VERSION_MOST = 64


def is_id(text: str) -> bool:
    return len(text) <= ID_MOST and ID.fullmatch(text) is not None


@dataclass(frozen=True)
class Version:
    """A version as NuGet reads one."""

    numbers: tuple[int, int, int, int]
    release: tuple[str, ...]  # the release labels: none for a stable version
    metadata: str  # build metadata: never part of an address, never compared

    @property
    def normalized(self) -> str:
        """As NuGet writes it: three parts, a fourth only if it is not 0, and the labels."""
        major, minor, patch, revision = self.numbers
        text = f"{major}.{minor}.{patch}" + (f".{revision}" if revision else "")
        return f"{text}-{'.'.join(self.release)}" if self.release else text

    @property
    def is_prerelease(self) -> bool:
        return bool(self.release)

    @property
    def is_semver2(self) -> bool:
        """Whether only a client of SemVer 2.0.0 reads it: labels with dots, or metadata."""
        return len(self.release) > 1 or bool(self.metadata)

    def sort_key(self) -> tuple:
        """Its place among versions: a stable version after its prereleases."""
        labels = tuple(
            (0, int(label), "") if label.isdigit() else (1, 0, label.lower())
            for label in self.release
        )
        return (self.numbers, not self.release, labels)


def parse(text: str) -> Version | None:
    """A version, or None for text that is not one."""
    if len(text) > VERSION_MOST:
        return None
    found = _VERSION.fullmatch(text.strip())
    if found is None:
        return None
    numbers = [int(part) for part in found["numbers"].split(".")]
    if any(number > _PART_MOST for number in numbers):
        return None
    release = tuple(found["release"].split(".")) if found["release"] else ()
    padded = (numbers + [0, 0, 0])[:4]
    return Version((padded[0], padded[1], padded[2], padded[3]), release, found["metadata"] or "")


def normalize(text: str) -> str | None:
    """A version's normalized text, or None for text that is not one."""
    version = parse(text)
    return None if version is None else version.normalized


def ordered(texts: list[str]) -> list[str]:
    """Versions from the oldest to the newest. Text that is not a version is left out."""
    parsed = [(version, text) for text in texts if (version := parse(text)) is not None]
    return [text for _, text in sorted(parsed, key=lambda pair: pair[0].sort_key())]
```

```python
"""What a NuGet package says of itself: the `.nuspec` in its zip.

A package can be gigabytes, so it is never unpacked. Its zip is read from the end, where
the directory of its entries is, and only the `.nuspec` is inflated, to a bound. The
bytes are asked for by position (`Read`), so that the caller decides where they come
from. Pure, but for that.
"""

import struct
import zlib
from collections.abc import Awaitable, Callable
from dataclasses import asdict, dataclass, field
from typing import Any
from xml.etree import ElementTree
from xml.parsers import expat

from megooarti.repositories.nuget import versions

# The bounds of what is read of a package (section 9 of the spec).
ENTRIES_MOST = 10_000
NUSPEC_MOST = 1024 * 1024
# A directory of that many files, with names of an ordinary length, is far less than this.
DIRECTORY_MOST = 16 * 1024 * 1024
_DEPTH_MOST = 32
_ELEMENTS_MOST = 20_000
# A zip's end record, and its comment at the most.
_END = b"PK\x05\x06"
_END_SIZE = 22
_TAIL_MOST = _END_SIZE + 0xFFFF
_CENTRAL = b"PK\x01\x02"
_LOCAL = b"PK\x03\x04"
# A file's entry in the directory: its signature, versions, flags, method, time, date,
# CRC, sizes, the lengths of its name, extra field and comment, and where it is.
_CENTRAL_HEADER = "<4sHHHHHHIIIHHHHHII"
_STORED, _DEFLATED = 0, 8
SYMBOLS = "SymbolsPackage"

# The bytes of a package from a position, as many as asked for (fewer at its end).
Read = Callable[[int, int], Awaitable[bytes]]


class InvalidPackage(Exception):
    """A file that is not a NuGet package that can be accepted. The message says why."""


@dataclass(frozen=True)
class Entry:
    """A file in a package's zip, as its directory describes it."""

    name: str
    method: int
    compressed: int
    size: int
    offset: int  # of its local header


@dataclass(frozen=True)
class Dependency:
    id: str
    range: str  # as NuGet writes a range: `[1.0.0, )` for "1.0.0 or later"


@dataclass(frozen=True)
class DependencyGroup:
    target_framework: str  # "" for every framework
    dependencies: tuple[Dependency, ...] = ()


@dataclass(frozen=True)
class Nuspec:
    """What a package's `.nuspec` says: what NuGet's feeds publish of it."""

    id: str
    version: str  # normalized
    original_version: str  # as the package wrote it
    title: str = ""
    authors: str = ""
    owners: str = ""
    description: str = ""
    summary: str = ""
    release_notes: str = ""
    copyright: str = ""
    language: str = ""
    tags: str = ""
    project_url: str = ""
    license_url: str = ""
    license_expression: str = ""
    icon_url: str = ""
    readme: str = ""
    require_license_acceptance: bool = False
    development_dependency: bool = False
    min_client_version: str = ""
    package_types: tuple[str, ...] = ()
    dependency_groups: tuple[DependencyGroup, ...] = field(default=())

    @property
    def is_symbols(self) -> bool:
        """Whether it is a symbol package (`.snupkg`), which goes beside its package."""
        return SYMBOLS in self.package_types

    @property
    def is_prerelease(self) -> bool:
        parsed = versions.parse(self.version)
        return parsed is not None and parsed.is_prerelease

    def as_json(self) -> dict[str, Any]:
        return asdict(self)

    @classmethod
    def from_json(cls, said: dict[str, Any]) -> "Nuspec":
        groups = tuple(
            DependencyGroup(
                group["target_framework"],
                tuple(Dependency(**dependency) for dependency in group["dependencies"]),
            )
            for group in said.get("dependency_groups", [])
        )
        plain = {
            key: value
            for key, value in said.items()
            if key in cls.__dataclass_fields__ and key not in ("dependency_groups", "package_types")
        }
        return cls(
            **plain, package_types=tuple(said.get("package_types", [])), dependency_groups=groups
        )


# --- The zip --------------------------------------------------------------------------


async def entries(read: Read, size: int) -> list[Entry]:
    """The files a package's zip has, from its directory at the end."""
    tail_start = max(0, size - _TAIL_MOST)
    tail = await read(tail_start, size - tail_start)
    at = tail.rfind(_END)
    if at < 0 or len(tail) - at < _END_SIZE:
        raise InvalidPackage("it is not a zip file")
    (_, _, _, _, count, length, start, _) = struct.unpack("<4sHHHHIIH", tail[at : at + _END_SIZE])
    if count == 0xFFFF or length == 0xFFFFFFFF or start == 0xFFFFFFFF:
        raise InvalidPackage("it is a ZIP64 file: a package of 4 GiB or more is not accepted")
    if count > ENTRIES_MOST:
        raise InvalidPackage(f"it has more than {ENTRIES_MOST} files")
    if length > DIRECTORY_MOST:
        raise InvalidPackage(f"its zip directory is larger than {DIRECTORY_MOST} bytes")
    if start + length > size:
        raise InvalidPackage("its zip directory is not where its end says")
    directory = await read(start, length)
    found, position = [], 0
    for _ in range(count):
        header = directory[position : position + 46]
        if len(header) < 46 or header[:4] != _CENTRAL:
            raise InvalidPackage("its zip directory is broken")
        fields = struct.unpack(_CENTRAL_HEADER, header)
        flags, method, compressed, unpacked = fields[3], fields[4], fields[8], fields[9]
        name_length, extra_length, comment_length, offset = (
            fields[10],
            fields[11],
            fields[12],
            fields[16],
        )
        raw = directory[position + 46 : position + 46 + name_length]
        if flags & 0x1:
            raise InvalidPackage("it has an encrypted file")
        name = raw.decode("utf-8" if flags & 0x800 else "cp437", errors="replace")
        found.append(Entry(name, method, compressed, unpacked, offset))
        position += 46 + name_length + extra_length + comment_length
    return found


async def extract(read: Read, entry: Entry, most: int) -> bytes:
    """One file of the zip, inflated: at most `most` bytes of it."""
    if entry.size > most:
        raise InvalidPackage(f"{entry.name} is larger than {most} bytes")
    local = await read(entry.offset, 30)
    if len(local) < 30 or local[:4] != _LOCAL:
        raise InvalidPackage(f"{entry.name} is not where the zip directory says")
    name_length, extra_length = struct.unpack("<HH", local[26:30])
    data = await read(entry.offset + 30 + name_length + extra_length, entry.compressed)
    if len(data) != entry.compressed:
        raise InvalidPackage(f"{entry.name} is cut short")
    if entry.method == _STORED:
        content = data
    elif entry.method == _DEFLATED:
        inflater = zlib.decompressobj(-zlib.MAX_WBITS)
        try:
            content = inflater.decompress(data, most + 1)
        except zlib.error:
            raise InvalidPackage(f"{entry.name} cannot be inflated") from None
    else:
        raise InvalidPackage(f"{entry.name} is compressed in a way NuGet does not use")
    if len(content) > most or len(content) != entry.size:
        raise InvalidPackage(f"{entry.name} is not the size the zip directory says")
    return content


def nuspec_entry(found: list[Entry]) -> Entry:
    """The package's `.nuspec`: the one file of that kind at the zip's top."""
    at_top = [entry for entry in found if "/" not in entry.name and entry.name.endswith(".nuspec")]
    if len(at_top) != 1:
        raise InvalidPackage("it does not have exactly one .nuspec at its top")
    return at_top[0]


@dataclass(frozen=True)
class Package:
    """What was read of a package: what its `.nuspec` says, and the `.nuspec` itself."""

    nuspec: Nuspec
    spec: bytes


async def read(read: Read, size: int) -> Package:
    """What a package says of itself. Raises InvalidPackage."""
    found = await entries(read, size)
    spec = await extract(read, nuspec_entry(found), NUSPEC_MOST)
    return Package(parse_nuspec(spec), spec)


# --- The .nuspec ----------------------------------------------------------------------


def _refuse_doctype(*_: object) -> None:
    raise InvalidPackage("its .nuspec has a DOCTYPE, which is not allowed")


def _tree(data: bytes) -> ElementTree.Element:
    """The `.nuspec`'s elements, by their names without a namespace."""
    builder = ElementTree.TreeBuilder()
    depth = elements = 0

    def start(tag: str, attributes: dict[str, str]) -> None:
        nonlocal depth, elements
        depth, elements = depth + 1, elements + 1
        if depth > _DEPTH_MOST or elements > _ELEMENTS_MOST:
            raise InvalidPackage("its .nuspec is too large to read")
        local = {name.rpartition(" ")[2]: value for name, value in attributes.items()}
        builder.start(tag.rpartition(" ")[2], local)

    def end(tag: str) -> None:
        nonlocal depth
        depth -= 1
        builder.end(tag.rpartition(" ")[2])

    # A namespace is given as `<uri> <name>`: each schema's `.nuspec` is read alike.
    parser = expat.ParserCreate(namespace_separator=" ")
    parser.buffer_text = True
    parser.StartDoctypeDeclHandler = _refuse_doctype
    parser.StartElementHandler = start
    parser.EndElementHandler = end
    parser.CharacterDataHandler = builder.data
    try:
        parser.Parse(data, True)
    except expat.ExpatError as error:
        raise InvalidPackage(f"its .nuspec is not well-formed XML (line {error.lineno})") from None
    except (ValueError, LookupError):
        raise InvalidPackage("its .nuspec is in an encoding that cannot be read") from None
    return builder.close()


def _text(parent: ElementTree.Element, name: str) -> str:
    child = parent.find(name)
    return "" if child is None else (child.text or "").strip()


def _flag(parent: ElementTree.Element, name: str) -> bool:
    return _text(parent, name).lower() == "true"


def _range(written: str) -> str:
    """A dependency's range as NuGet writes one: a bare version is that version or later."""
    written = written.strip()
    if not written:
        return "(, )"
    if written[0] in "[(":
        return written
    normalized = versions.normalize(written)
    return f"[{normalized or written}, )"


def _dependencies(parent: ElementTree.Element) -> tuple[Dependency, ...]:
    return tuple(
        Dependency(element.get("id", "").strip(), _range(element.get("version", "")))
        for element in parent.findall("dependency")
        if element.get("id", "").strip()
    )


def _groups(metadata: ElementTree.Element) -> tuple[DependencyGroup, ...]:
    dependencies = metadata.find("dependencies")
    if dependencies is None:
        return ()
    groups = [
        DependencyGroup(group.get("targetFramework", "").strip(), _dependencies(group))
        for group in dependencies.findall("group")
    ]
    flat = _dependencies(dependencies)
    if flat:
        groups.insert(0, DependencyGroup("", flat))
    return tuple(groups)


def parse_nuspec(data: bytes) -> Nuspec:
    """What a `.nuspec` says. Raises InvalidPackage."""
    root = _tree(data)
    metadata = root.find("metadata") if root.tag == "package" else None
    if metadata is None:
        raise InvalidPackage("its .nuspec has no <package><metadata>")
    package_id = _text(metadata, "id")
    if not versions.is_id(package_id):
        raise InvalidPackage(f"its id is not one NuGet takes: {package_id[:100]!r}")
    written = _text(metadata, "version")
    version = versions.parse(written)
    if version is None:
        raise InvalidPackage(f"its version is not one NuGet takes: {written[:64]!r}")
    license_element = metadata.find("license")
    expression = ""
    if license_element is not None and license_element.get("type") == "expression":
        expression = (license_element.text or "").strip()
    types = metadata.find("packageTypes")
    package_types = (
        ()
        if types is None
        else tuple(
            element.get("name", "")
            for element in types.findall("packageType")
            if element.get("name")
        )
    )
    return Nuspec(
        id=package_id,
        version=version.normalized,
        original_version=written,
        title=_text(metadata, "title"),
        authors=_text(metadata, "authors"),
        owners=_text(metadata, "owners"),
        description=_text(metadata, "description"),
        summary=_text(metadata, "summary"),
        release_notes=_text(metadata, "releaseNotes"),
        copyright=_text(metadata, "copyright"),
        language=_text(metadata, "language"),
        tags=_text(metadata, "tags"),
        project_url=_text(metadata, "projectUrl"),
        license_url=_text(metadata, "licenseUrl"),
        license_expression=expression,
        icon_url=_text(metadata, "iconUrl"),
        readme=_text(metadata, "readme"),
        require_license_acceptance=_flag(metadata, "requireLicenseAcceptance"),
        development_dependency=_flag(metadata, "developmentDependency"),
        min_client_version=metadata.get("minClientVersion", ""),
        package_types=package_types,
        dependency_groups=_groups(metadata),
    )
```

```python
"""What a path of a NuGet repository is (section 4.2 of the spec).

Ids and versions are lower case in every path, as NuGet's clients ask for them; a
version in a path is normalized.
"""

from dataclasses import dataclass

from megooarti.repositories.nuget import versions

SERVICE_INDEX = "index.json"
PACKAGES = "v3/package/"
REGISTRATION = "v3/registration/"
SEARCH = "v3/search"
AUTOCOMPLETE = "v3/autocomplete"
PUBLISH = "api/v2/package"
SYMBOL_PUBLISH = "api/v2/symbolpackage"


@dataclass(frozen=True)
class NuGetPath:
    # service-index, versions, package, nuspec, symbols, registration, leaf, search,
    # autocomplete, publish, symbol-publish, delete, other
    kind: str
    id: str = ""  # lower case
    version: str = ""  # normalized, lower case


def _version(text: str) -> str | None:
    """A version in a path: normalized, lower case. None if it is not one."""
    normalized = versions.normalize(text)
    return None if normalized is None else normalized.lower()


def package_path(package_id: str, version: str) -> str:
    """Where a package is kept, and fetched from."""
    lower, at = package_id.lower(), version.lower()
    return f"{PACKAGES}{lower}/{at}/{lower}.{at}.nupkg"


def nuspec_path(package_id: str, version: str) -> str:
    lower = package_id.lower()
    return f"{PACKAGES}{lower}/{version.lower()}/{lower}.nuspec"


def symbols_path(package_id: str, version: str) -> str:
    """Where a package's symbol package is kept, beside it."""
    lower, at = package_id.lower(), version.lower()
    return f"{PACKAGES}{lower}/{at}/{lower}.{at}.snupkg"


def classify(path: str) -> NuGetPath:
    if path == SERVICE_INDEX:
        return NuGetPath("service-index")
    if path in (SEARCH, AUTOCOMPLETE):
        return NuGetPath("search" if path == SEARCH else "autocomplete")
    # dotnet pushes to the address the service index gives, with a slash after it.
    if path.rstrip("/") in (PUBLISH, SYMBOL_PUBLISH):
        return NuGetPath("publish" if path.rstrip("/") == PUBLISH else "symbol-publish")
    parts = path.split("/")
    if path.startswith(PUBLISH + "/") and len(parts) == 5:
        version = _version(parts[4])
        if versions.is_id(parts[3]) and version is not None:
            return NuGetPath("delete", parts[3].lower(), version)
    if path.startswith(PACKAGES) and len(parts) in (4, 5):
        package_id = parts[2]
        if package_id != package_id.lower() or not versions.is_id(package_id):
            return NuGetPath("other")
        if len(parts) == 4:
            return NuGetPath("versions" if parts[3] == "index.json" else "other", package_id)
        version = _version(parts[3])
        if version is None or version != parts[3]:
            return NuGetPath("other")
        filename = parts[4]
        if filename == f"{package_id}.{version}.nupkg":
            return NuGetPath("package", package_id, version)
        if filename == f"{package_id}.nuspec":
            return NuGetPath("nuspec", package_id, version)
        if filename == f"{package_id}.{version}.snupkg":
            return NuGetPath("symbols", package_id, version)
        return NuGetPath("other")
    if path.startswith(REGISTRATION) and len(parts) == 4:
        package_id = parts[2]
        if package_id != package_id.lower() or not versions.is_id(package_id):
            return NuGetPath("other")
        if parts[3] == "index.json":
            return NuGetPath("registration", package_id)
        version = _version(parts[3].removesuffix(".json"))
        if parts[3].endswith(".json") and version == parts[3].removesuffix(".json"):
            return NuGetPath("leaf", package_id, version)
    return NuGetPath("other")
```

Create `backend/src/megooarti/repositories/nuget/queries.py`:

```python
"""What V3's search and autocomplete ask for, and which ids answer it, in which order.

Pure functions. A query is read as nuget.org reads one: words that each must be in an
id, a title, a description, the tags or the authors; `packageid:<id>` for one id
exactly, and `id:<text>` for ids that contain it. An exact id comes first, then ids
that begin with what was typed, then the rest, each by id.
"""

from collections.abc import Mapping, Sequence
from dataclasses import dataclass

from megooarti.errors import ApiError
from megooarti.repositories.nuget.documents import Published

# What one search may ask for (section 9 of the spec).
TAKE_MOST = 1000
SKIP_AND_TAKE_MOST = 3000
TAKE_DEFAULT = 20


@dataclass(frozen=True)
class Query:
    words: tuple[str, ...]  # lower case
    exact_id: str = ""  # lower case
    id_contains: str = ""  # lower case
    prerelease: bool = False
    skip: int = 0
    take: int = TAKE_DEFAULT

    @property
    def stored_words(self) -> tuple[str, ...]:
        """What a package's stored search text must hold: every word, and the id's."""
        return tuple(word for word in (*self.words, self.exact_id, self.id_contains) if word)


def _invalid(name: str, message: str) -> ApiError:
    details = [{"field": name, "message": message}]
    return ApiError(400, "invalid_query", message, details)


def _number(text: str | None, name: str, default: int) -> int:
    if text is None or text == "":
        return default
    if not (text.isascii() and text.isdigit() and len(text) <= 9):
        raise _invalid(name, f"{name} is a whole number, 0 or more.")
    return int(text)


def parse(arguments: Mapping[str, str]) -> Query:
    """A query from a request's arguments. Raises a 400 for one beyond the bounds."""
    skip = _number(arguments.get("skip"), "skip", 0)
    take = _number(arguments.get("take"), "take", TAKE_DEFAULT)
    if take > TAKE_MOST:
        raise _invalid("take", f"take is at most {TAKE_MOST}.")
    if skip + take > SKIP_AND_TAKE_MOST:
        raise _invalid("skip", f"skip and take together are at most {SKIP_AND_TAKE_MOST}.")
    words, exact, contains = [], "", ""
    for word in arguments.get("q", "").lower().split():
        field, colon, value = word.partition(":")
        if colon and field == "packageid" and value:
            exact = value
        elif colon and field == "id" and value:
            contains = value
        else:
            words.append(word)
    return Query(
        words=tuple(words),
        exact_id=exact,
        id_contains=contains,
        prerelease=arguments.get("prerelease", "").lower() == "true",
        skip=skip,
        take=take,
    )


def _text(held: Published) -> str:
    said = held.nuspec
    return " ".join(
        (said.id, said.title, said.description, said.tags, said.authors, said.summary)
    ).lower()


def _matches(query: Query, package_id: str, held: Sequence[Published]) -> bool:
    lower = package_id.lower()
    if query.exact_id and lower != query.exact_id:
        return False
    if query.id_contains and query.id_contains not in lower:
        return False
    return any(all(word in _text(one) for word in query.words) for one in held)


def _rank(query: Query, package_id: str) -> tuple:
    lower, typed = package_id.lower(), " ".join(query.words)
    return (lower != typed, not lower.startswith(typed), lower)


def select(
    query: Query, held: Mapping[str, Sequence[Published]]
) -> tuple[list[list[Published]], int]:
    """The page of ids that answer, each with the versions it may show, and how many answer.

    `held` is every version of each id that may answer, by id. A prerelease is shown
    only if the query asks for them; an id with nothing else is then not found.
    """
    answering = []
    for package_id, versions_held in held.items():
        shown = [one for one in versions_held if query.prerelease or not one.nuspec.is_prerelease]
        if shown and _matches(query, package_id, shown):
            answering.append((package_id, shown))
    answering.sort(key=lambda pair: _rank(query, pair[0]))
    page = answering[query.skip : query.skip + query.take]
    return [shown for _, shown in page], len(answering)
```

Create `backend/src/megooarti/repositories/nuget/format.py`:

```python
"""The NuGet format: hosted repositories that .NET's clients push to and restore from.

This is the only NuGet module that touches the repository context. What a path means,
what a package says of itself, what a document says and which packages a search finds
come from the pure modules beside it.

A package's `.nuspec` is read once, as it is pushed, and kept with its version: with
its file and as its component's attributes. The documents of V3 (an id's versions, its
registration, search) are written from those on each request, as npm's package
documents are, so they are right after every push and delete: each is of one id, or of
what a search found, and asks the database for nothing else.

An id is matched without regard to case, as NuGet's clients match it. The first push
of an id spells it; later ones are kept under that spelling. A version is kept
normalized and in lower case, as it is in every address; what its package wrote is in
its `.nuspec`.
"""

import json
import xml.sax.saxutils
from collections import defaultdict
from collections.abc import Sequence
from contextlib import aclosing
from dataclasses import replace
from typing import Any

from starlette.requests import Request
from starlette.responses import Response

from megooarti.errors import ApiError
from megooarti.repositories import forms
from megooarti.repositories.content import ComponentInfo, RepositoryContext
from megooarti.repositories.formats import (
    ComponentKey,
    Format,
    Usage,
    invalid_upload,
    managed_by_format,
    only_fields,
    plain,
    register,
)
from megooarti.repositories.models import Repository
from megooarti.repositories.nuget import documents, packages, paths, queries, versions
from megooarti.repositories.nuget.documents import Published
from megooarti.storage.backends import StagedBlob

# Where what a package said of itself is kept, among a file's attributes and among its
# version's component's.
_DECLARED = "nuget"
_PACKAGE = "application/octet-stream"
_NUSPEC = "application/xml"
_JSON = "application/json"


def _invalid(reason: object) -> ApiError:
    return ApiError(400, "invalid_package", f"The package cannot be accepted: {reason}.")


def _not_found(message: str = "Nothing is served at this address.") -> ApiError:
    return ApiError(404, "not_found", message)


def _not_allowed(allowed: str) -> ApiError:
    return ApiError(
        405, "method_not_allowed", f"This address accepts {allowed}.", headers={"Allow": allowed}
    )


def _nuspec_of(attributes: dict[str, Any] | None) -> packages.Nuspec | None:
    said = (attributes or {}).get(_DECLARED)
    return packages.Nuspec.from_json(said) if isinstance(said, dict) else None


def _published(held: Sequence[ComponentInfo]) -> list[Published]:
    """The versions held that a package's `.nuspec` describes, with when each was pushed."""
    return [
        Published(nuspec, one.created)
        for one in held
        if (nuspec := _nuspec_of(one.attributes)) is not None
    ]


# --- Pushing ------------------------------------------------------------------------


def _ranges(context: RepositoryContext, staged: StagedBlob) -> packages.Read:
    """A staged package's bytes by position: it is read from its start each time.

    A package is read three times at the most (its end, its directory, its `.nuspec`),
    and only those bytes are kept. Each reading closes the file at once: a file that is
    still open cannot be moved into the store, or removed, on every system.
    """

    async def read(start: int, length: int) -> bytes:
        kept, position = bytearray(), 0
        async with aclosing(context.open_staged(staged)) as chunks:
            async for chunk in chunks:
                end = position + len(chunk)
                if end > start and position < start + length:
                    kept += chunk[max(0, start - position) : start + length - position]
                position = end
                if position >= start + length:
                    break
        return bytes(kept)

    return read


async def _read(context: RepositoryContext, staged: StagedBlob) -> packages.Package:
    try:
        return await packages.read(_ranges(context, staged), staged.size)
    except packages.InvalidPackage as error:
        raise _invalid(error) from None


async def _received(context: RepositoryContext, request: Request) -> StagedBlob:
    """The one package a push sends, staged: as `multipart/form-data`, as every client sends it."""
    context.require_write()  # refused before the body is read
    await context.release()  # the body needs no connection
    try:
        form = await forms.read(
            request.stream(),
            request.headers.get("Content-Type", ""),
            stage=context.stage,
            discard=context.discard,
        )
    except forms.InvalidForm as error:
        raise _invalid(f"the push cannot be read: {error}") from None
    if len(form.files) != 1:
        for file in form.files:
            await context.discard(file.staged)
        raise _invalid("a push sends one package")
    return form.files[0].staged


async def _spelled(context: RepositoryContext, nuspec: packages.Nuspec) -> packages.Nuspec:
    """The `.nuspec`'s id as the repository already spells it, if it has the id."""
    spelling = await context.spelling("", nuspec.id)
    return nuspec if spelling is None or spelling == nuspec.id else replace(nuspec, id=spelling)


async def _keep_package(
    context: RepositoryContext, staged: StagedBlob, package: packages.Package
) -> bool:
    """A package and its `.nuspec`, each at its path. Returns whether the version is new."""
    nuspec = await _spelled(context, package.nuspec)
    said = {_DECLARED: nuspec.as_json()}
    _, created = await context.store(
        paths.package_path(nuspec.id, nuspec.version),
        staged,
        content_type=_PACKAGE,
        attributes=said,
        component_attributes=said,
    )
    spec = await context.stage_bytes(package.spec)
    await context.store(
        paths.nuspec_path(nuspec.id, nuspec.version), spec, content_type=_NUSPEC, attributes=said
    )
    return created


async def _keep_symbols(
    context: RepositoryContext, staged: StagedBlob, package: packages.Package
) -> bool:
    """A symbol package, beside the package it is of: that must be here."""
    nuspec = await _spelled(context, package.nuspec)
    if await context.stat(paths.package_path(nuspec.id, nuspec.version)) is None:
        await context.discard(staged)
        raise _not_found(
            f"This repository has no {nuspec.id} {nuspec.version}: push the package first."
        )
    _, created = await context.store(
        paths.symbols_path(nuspec.id, nuspec.version),
        staged,
        content_type=_PACKAGE,
        attributes={_DECLARED: nuspec.as_json()},
    )
    return created


async def _push(context: RepositoryContext, request: Request, *, symbols: bool) -> Response:
    """`PUT api/v2/package` and `api/v2/symbolpackage`. A symbol package may come to
    the first, as older clients send it."""
    staged = await _received(context, request)
    try:
        package = await _read(context, staged)
        if symbols and not package.nuspec.is_symbols:
            raise _invalid("a package is pushed to api/v2/package, not as symbols")
    except ApiError:
        await context.discard(staged)
        raise
    keep = _keep_symbols if package.nuspec.is_symbols else _keep_package
    created = await keep(context, staged, package)
    return Response(status_code=201 if created else 200)


# --- Deleting -----------------------------------------------------------------------


async def _delete_version(context: RepositoryContext, package_id: str, version: str) -> bool:
    """Every file of a version: its package, `.nuspec` and symbols. False if it has none."""
    spelling = await context.spelling("", package_id)
    if spelling is None:
        return False
    deleted = False
    for held in await context.files("", spelling, version):
        deleted = await context.delete(held.path) or deleted
    return deleted


# --- Reading ------------------------------------------------------------------------


async def _base(context: RepositoryContext, request: Request) -> str:
    return f"{await context.public_url(request)}/"


async def _respond(context: RepositoryContext, request: Request, document: Any) -> Response:
    """A document written for this request, as JSON."""
    data = json.dumps(document, ensure_ascii=False, separators=(",", ":")).encode()
    _, changed = await context.revision()
    return context.respond_with(
        data,
        request,
        filename="index.json",
        content_type=_JSON,
        last_modified=changed,
        # Two changes can be made within one second: only the bytes say which a client has.
        dated=False,
    )


async def _held(context: RepositoryContext, package_id: str) -> list[Published]:
    """Every version of an id this repository holds. Raises 404 for none."""
    spelling = await context.spelling("", package_id)
    held = [] if spelling is None else _published(await context.components("", spelling))
    if not held:
        raise _not_found(f"This repository has no package {package_id}.")
    return held


async def _search(context: RepositoryContext, request: Request) -> Response:
    query = queries.parse(request.query_params)
    by_id: dict[str, list[ComponentInfo]] = defaultdict(list)
    for name, held in await context.matching("", query.stored_words):
        by_id[name].append(held)
    found, total = queries.select(query, {name: _published(held) for name, held in by_id.items()})
    return await _respond(
        context, request, documents.search_result(await _base(context, request), found, total)
    )


async def _autocomplete(context: RepositoryContext, request: Request) -> Response:
    """Ids that contain what was typed; or, given an `id`, its versions."""
    arguments = request.query_params
    prerelease = arguments.get("prerelease", "").lower() == "true"
    if "id" in arguments:
        spelling = await context.spelling("", arguments["id"])
        held = [] if spelling is None else _published(await context.components("", spelling))
        shown = versions.ordered(
            [one.nuspec.version for one in held if prerelease or not one.nuspec.is_prerelease]
        )
        return await _respond(context, request, documents.autocomplete(shown, len(shown)))
    query = queries.parse({**arguments, "q": ""})
    typed = arguments.get("q", "").strip().lower()
    by_id: dict[str, list[ComponentInfo]] = defaultdict(list)
    for name, held in await context.matching("", [typed] if typed else []):
        by_id[name].append(held)
    ids = sorted(
        (
            name
            for name, held in by_id.items()
            if typed in name.lower()
            and any(prerelease or not one.nuspec.is_prerelease for one in _published(held))
        ),
        key=lambda name: (not name.lower().startswith(typed), name.lower()),
    )
    page = ids[query.skip : query.skip + query.take]
    return await _respond(context, request, documents.autocomplete(page, len(ids)))


async def _read_request(
    context: RepositoryContext, request: Request, path: str, parsed: paths.NuGetPath
) -> Response:
    if parsed.kind == "service-index":
        return await _respond(
            context, request, documents.service_index(await _base(context, request))
        )
    if parsed.kind in ("package", "nuspec", "symbols"):
        return await context.respond(path, request)
    if parsed.kind == "versions":
        held = await _held(context, parsed.id)
        listed = [one.nuspec.version for one in held]
        return await _respond(context, request, documents.version_list(listed))
    if parsed.kind == "registration":
        held = await _held(context, parsed.id)
        return await _respond(
            context, request, documents.registration(await _base(context, request), held)
        )
    if parsed.kind == "leaf":
        held = [
            one
            for one in await _held(context, parsed.id)
            if one.nuspec.version.lower() == parsed.version
        ]
        if not held:
            raise _not_found(f"This repository has no {parsed.id} {parsed.version}.")
        return await _respond(
            context, request, documents.leaf(await _base(context, request), held[0])
        )
    if parsed.kind == "search":
        return await _search(context, request)
    if parsed.kind == "autocomplete":

class NuGetFormat(Format):
    name = "nuget"
    types = frozenset({"hosted"})
    derives_indexes = True

    def default_deployment_policy(self, config: dict[str, Any]) -> str:
        """A version is pushed once, as nuget.org takes it: a second push is `409`."""
        return "disable_redeploy"

    def describe_component(
        self, path: str, attributes: dict[str, Any] | None = None
    ) -> ComponentKey | None:
        """A package's files belong to its id and version: as its `.nuspec` said, or its path."""
        nuspec = _nuspec_of(attributes)
        if nuspec is not None:
            return ComponentKey("", nuspec.id, nuspec.version.lower())
        parsed = paths.classify(path)
        if parsed.kind in ("package", "nuspec", "symbols"):
            return ComponentKey("", parsed.id, parsed.version)
        return None

    def search_text(self, key: ComponentKey, attributes: dict[str, Any]) -> str:
        """Its id and version, and the words of its `.nuspec` that NuGet's search reads."""
        nuspec = _nuspec_of(attributes)
        words = [super().search_text(key, attributes)]
        if nuspec is not None:
            words += [nuspec.title, nuspec.description, nuspec.summary, nuspec.tags, nuspec.authors]
        return " ".join(word for word in words if word)

    async def upload(self, context: RepositoryContext, form: forms.UploadForm) -> list[str]:
        """Store packages and symbol packages as pushes would: each where its `.nuspec` says."""
        only_fields(form, ())
        if not form.files:
            raise invalid_upload("file", "At least one NuGet package is needed.")
        read = []
        for file in form.files:
            if file.field != "file":
                raise invalid_upload(file.field, "A package is sent as `file`.")
            read.append((file.staged, await _read(context, file.staged)))
        # Packages first: a symbol package goes beside its package.
        read.sort(key=lambda pair: pair[1].nuspec.is_symbols)
        stored = []
        for staged, package in read:
            nuspec = package.nuspec
            if nuspec.is_symbols:
                await _keep_symbols(context, staged, package)
                stored.append(paths.symbols_path(nuspec.id, nuspec.version))
            else:
                await _keep_package(context, staged, package)
                stored.append(paths.package_path(nuspec.id, nuspec.version))
        return stored

    async def delete_asset(self, context: RepositoryContext, path: str) -> bool:
        """A package goes with its version's every file; its `.nuspec` goes with it."""
        parsed = paths.classify(path)
        if parsed.kind == "package":
            return await _delete_version(context, parsed.id, parsed.version)
        if parsed.kind == "nuspec":
            package = paths.package_path(parsed.id, parsed.version)
            if await context.stat(path) is not None and await context.stat(package) is not None:
                raise managed_by_format(
                    "A package's .nuspec goes with it: delete the package, or its version."
                )
        return await context.delete(path)

    def usage(self, address: str, key: ComponentKey, files: Sequence[str]) -> list[Usage]:
        if not plain(key.name, key.version) or not versions.is_id(key.name):
            return []
        return [
            Usage("dotnet", "shell", f"dotnet add package {key.name} --version {key.version}"),
            Usage(
                "PackageReference",
                "xml",
                f'<PackageReference Include="{key.name}" Version="{key.version}" />',
            ),
            Usage(
                "Package Manager",
                "shell",
                f"Install-Package {key.name} -Version {key.version}",
            ),
        ]

    def setup(self, address: str, repository: Repository) -> list[Usage]:
        return setup_of(address, repository.name)

    def content_type(self, path: str, declared: str | None) -> str | None:
        kind = paths.classify(path).kind
        if kind in ("package", "symbols"):
            return _PACKAGE
        if kind == "nuspec":
            return _NUSPEC
        return declared

    async def handle_hosted(
        self, context: RepositoryContext, request: Request, path: str
    ) -> Response:
        parsed = paths.classify(path)
        if request.method in ("GET", "HEAD"):
            if parsed.kind in ("publish", "symbol-publish", "delete"):
                raise _not_allowed("PUT" if parsed.kind != "delete" else "DELETE")
            return await _read_request(context, request, path, parsed)
        if request.method == "PUT" and parsed.kind in ("publish", "symbol-publish"):
            return await _push(context, request, symbols=parsed.kind == "symbol-publish")
        if request.method == "DELETE" and parsed.kind == "delete":
            if not await _delete_version(context, parsed.id, parsed.version):
                raise _not_found(f"This repository has no {parsed.id} {parsed.version}.")
            return Response(status_code=204)
        if parsed.kind in ("publish", "symbol-publish"):
            raise _not_allowed("PUT")
        if parsed.kind == "delete":
            raise _not_allowed("DELETE")
        raise _not_allowed("GET, HEAD")
```

````markdown
# NuGet repositories

What is true of every repository is in [Repositories](../repositories.md). This is
what is this format's own: .NET packages, pushed and restored with `dotnet`.

A hosted repository holds the packages you build, and serves them over NuGet's V3
protocol, as nuget.org does. Its address for a client is the repository's own, then
`index.json`:

```bash

```

`dotnet` signs in with. The repository's page in the web UI gives these, with its own
address, under "Set up a machine".

- **Credentials.** A push's API key is an API token (`--api-key`, sent as
  `X-NuGet-ApiKey`); so is the password of a source's credentials. A user name and a
  password work for a source too. NuGet's clients send credentials over plain HTTP only
  to a source marked `allowInsecureConnections="true"` in `nuget.config`: use HTTPS.
- **A push** is `dotnet nuget push`, or the web UI or [the API](../api.md#uploading)
  with one or more `file` fields. What is read of a package is its `.nuspec`, at most
  1 MiB, from a zip of at most 10,000 files: the zip is never unpacked. A file that is
  not a NuGet package, or whose `.nuspec` has no id or no version NuGet takes, is
  refused with `400 invalid_package`. A package of 4 GiB or more (a ZIP64 file) is
  refused too.
- **A version is pushed once.** A hosted NuGet repository's deployment policy is
  `disable_redeploy` unless you choose another: a second push of a version answers
  `409`, which `dotnet nuget push --skip-duplicate` takes for "already there". With
  `allow_redeploy` it replaces the version.
- **Ids are matched without regard to case**, as NuGet's clients match them: the first
  push of an id spells it, and later versions are kept under that spelling. A version
  is normalized as NuGet normalizes it (`1.0` is `1.0.0`, and build metadata is left
  out). Addresses are in lower case.
- **Symbol packages** (`.snupkg`, made by `dotnet pack` with `--include-symbols
  -p:SymbolPackageFormat=snupkg`) are pushed with their package by `dotnet nuget push`,
  and kept beside it. One pushed before its package is refused with `404`.
- **Deleting** a version (`dotnet nuget delete <id> <version>`, which needs the
  `delete` permission, or the web UI) removes it and its every file: its package, its
  `.nuspec` and its symbol package. A package's `.nuspec` cannot be deleted on its own.
- **The feed is written from the packages** on each request: an id's versions, its
  registration (in pages of 64 versions) and search. Nothing is stored but the
  packages, so the feed is right after every push and delete.
- **Search** (`dotnet package search`, and Visual Studio's Browse tab) finds an id by
  the words of its id, title, description, tags and authors; `packageid:<id>` finds one
  id exactly, and `id:<text>` the ids that contain it. Prereleases are found when they
  are asked for. A search takes at most 1,000 results, and none past the 3,000th.
  MegooArti counts no downloads.
````
