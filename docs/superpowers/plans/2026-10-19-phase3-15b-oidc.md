# External Identity: OIDC Sign-in Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** An administrator adds an OIDC provider (Keycloak, Entra ID, Okta, Google) as a sign-in source, with a form, tests it and turns it on; the sign-in screen then offers "Sign in with <name>", the provider signs the person in and sends them back, and they are a user of MegooArti, their groups giving them roles — proved against a real Keycloak.

**Architecture:** `security/oidc.py` is the `oidc` kind of plan 15a's registry (its settings, its Test) and the provider's side: metadata and keys kept an hour, the token request, and the checks of an ID token with `pyjwt[crypto]`. `security/api/oidc.py` serves the two addresses a browser goes through: `start` sends it to the provider with a state, a nonce and PKCE sealed in a cookie of ten minutes; `callback` trades the code, checks the ID token, makes or refreshes the user with 15a's `provision`, and starts a session as a password sign-in does (`start_session`, factored out of `/auth/login`). Kinds now reach the outside through `sources.Outbound`, the server's one outbound client. The web UI gains the sign-in screen's providers, a source's page with the OIDC form, and its group mapping as rows.

**Tech Stack:** Python 3.13, FastAPI, SQLAlchemy, httpx, `pyjwt[crypto]`, `secrets_box`; Next.js, React, TanStack Query, Vitest; Docker and Keycloak 26.0 for the container test.

**Spec:** [docs/superpowers/specs/2026-10-19-identity-audit-selectors-design.md](../specs/2026-10-19-identity-audit-selectors-design.md): section 5, with 4 (and its "Settled while building plan 15a"), 11, 12, 14 and the row of plan 15b in 13.

## Global Constraints

- **An ID token is checked before anyone is made or signed in**: its signature by the provider's keys, `iss`, `aud`, `exp`, `nonce`, at most five minutes' skew (section 5). Tokens are checked with `pyjwt[crypto]`.
- **The state, the nonce and the PKCE verifier (S256) are kept sealed in a cookie of ten minutes** (section 5).
- **A provider's refusal, or a token that does not check, is said on the sign-in screen and logged; nothing is created** (section 5).
- **Every secret of a source is sealed, and shown to nobody again** (E5); a kept secret is never sent where it was not given for (S16).
- **A user belongs to one source; a user of a source has no password here** (E2).
- **Every test of the stack is marked `docker`.**
- **A table's line under its headings is `| --- | --- |`** (one `---` cell a column). Commits end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

**Working directories:** run `uv` and `pytest` commands in `backend/`, with `MEGOOARTI_TEST_DATABASE_URL` set to your test database; `pnpm` commands in `frontend/`; `git` commands in the repository root.

## Review Focus

What could hurt a person using this most, and which test of this plan pins it.

1. **An ID token taken that is not this provider's, for this client, of this sign-in** (another audience, issuer, nonce or key; expired; a provider naming another in `iss`): nobody is made or signed in. Task 2: `test_an_id_token_that_does_not_check_makes_nobody`, `test_an_id_token_signed_by_another_key_makes_nobody`, `test_an_answer_naming_another_provider_is_refused`.
2. **Someone else's sign-in finished in a person's browser** (a code of the attacker's, sent to the victim's callback): refused, as the state is not this browser's. Task 2: `test_a_callback_of_another_sign_in_or_none_is_refused`.
3. **A sign-in that sends the browser to another site afterwards** (`next=https://evil.example`): the server sends it only to its own sign-in screen, which goes home. Task 2: `test_where_to_go_next_is_given_only_to_the_sign_in_screen`.
4. **The client secret sent to an address an administrator was tricked into setting**: a changed issuer asks for the secret again. Task 1: `test_the_client_secret_is_asked_again_for_another_issuer`.
5. **A provider that is down, or a source turned off**: the sign-in screen says so at once; nothing hangs or answers 500. Task 2: `test_a_source_that_is_off_or_a_provider_that_is_down_is_said_at_once`.

"""An OIDC provider that exists only in the tests' process (spec 12): its metadata, its
keys, made here, and its token endpoint, which checks what a real one does (the code,
the redirect address, PKCE, the client's secret) and signs ID tokens with those keys."""

import base64
import hashlib
import json
import secrets
import time
from typing import Any
from urllib.parse import parse_qs, urlsplit

import httpx
import jwt
from cryptography.hazmat.primitives.asymmetric import rsa

from megooarti.repositories.remote import new_client

ISSUER = "https://sso.example/realms/corp"
CLIENT_ID = "megooarti"
CLIENT_SECRET = "the client's secret: with a colon"


def query_of(address: str) -> dict[str, str]:
    return {name: values[0] for name, values in parse_qs(urlsplit(address).query).items()}


class Key:
    def __init__(self, kid: str) -> None:
        self.kid = kid
        self.private = rsa.generate_private_key(public_exponent=65537, key_size=2048)

    def public_jwk(self) -> dict[str, Any]:
        jwk = json.loads(jwt.algorithms.RSAAlgorithm.to_jwk(self.private.public_key()))
        return {**jwk, "kid": self.kid, "use": "sig", "alg": "RS256"}

    def sign(self, claims: dict[str, Any], **header: Any) -> str:
        return jwt.encode(
            claims, self.private, algorithm="RS256", headers={"kid": self.kid, **header}
        )


class FakeProvider:
    def __init__(self) -> None:
        self.keys = [Key("key-1")]
        self.people: dict[str, dict[str, Any]] = {}
        self.codes: dict[str, dict[str, Any]] = {}
        self.asked: list[str] = []  # the paths asked of it, in order
        self.down = False
        self.issuer_said = ISSUER  # what its metadata calls it
        # Changes to the next ID token's claims, or how it is signed, as a test wants.
        self.claims_changed: dict[str, Any] = {}
        self.signer: Key | None = None
        self.token_error: str | None = None

    def person(self, login: str, **claims: Any) -> None:
        self.people[login] = {"sub": f"subject-of-{login}", "preferred_username": login, **claims}

    def client(self) -> httpx.AsyncClient:
        return new_client(httpx.MockTransport(self._answer))

    # --- what a browser does there -------------------------------------------------------

    def authorize(self, address: str, login: str) -> str:
        """The person signs in at the provider: a code for the client's redirect address."""
        asked = query_of(address)
        assert address.startswith(f"{ISSUER}/protocol/openid-connect/auth?"), address
        assert asked["response_type"] == "code" and asked["client_id"] == CLIENT_ID
        assert asked["code_challenge_method"] == "S256"
        code = secrets.token_urlsafe(16)
        self.codes[code] = {
            "login": login,
            "nonce": asked["nonce"],
            "challenge": asked["code_challenge"],
            "redirect_uri": asked["redirect_uri"],
        }
        return code

    def rotate(self) -> None:
        """Sign with a new key from now on, as providers do now and then."""
        self.keys = [Key(f"key-{len(self.keys) + 1}")]

    # --- the provider's own addresses ------------------------------------------------------

    def _answer(self, request: httpx.Request) -> httpx.Response:
        self.asked.append(request.url.path)
        if self.down:
            raise httpx.ConnectError("the provider is down", request=request)
        path = request.url.path
        if path == "/realms/corp/.well-known/openid-configuration":
            return httpx.Response(200, json=self._metadata())
        if path == "/realms/corp/protocol/openid-connect/certs":
            return httpx.Response(200, json={"keys": [key.public_jwk() for key in self.keys]})
        if path == "/realms/corp/protocol/openid-connect/token" and request.method == "POST":
            return self._token(request)
        return httpx.Response(404)

    def _metadata(self) -> dict[str, Any]:
        return {
            "issuer": self.issuer_said,
            "authorization_endpoint": f"{ISSUER}/protocol/openid-connect/auth",
            "token_endpoint": f"{ISSUER}/protocol/openid-connect/token",
            "jwks_uri": f"{ISSUER}/protocol/openid-connect/certs",
            "id_token_signing_alg_values_supported": ["RS256"],
            "token_endpoint_auth_methods_supported": ["client_secret_basic"],
        }

    def _token(self, request: httpx.Request) -> httpx.Response:
        form = {name: values[0] for name, values in parse_qs(request.content.decode()).items()}
        expected = base64.b64encode(
            b"megooarti:the%20client%27s%20secret%3A%20with%20a%20colon"
        ).decode()
        if request.headers.get("Authorization") != f"Basic {expected}":
            return httpx.Response(401, json={"error": "invalid_client"})
        given = self.codes.pop(form.get("code", ""), None)
        if self.token_error or given is None:
            return httpx.Response(400, json={"error": self.token_error or "invalid_grant"})
        digest = hashlib.sha256(form.get("code_verifier", "").encode()).digest()
        challenge = base64.urlsafe_b64encode(digest).rstrip(b"=").decode()
        if challenge != given["challenge"] or form.get("redirect_uri") != given["redirect_uri"]:
            return httpx.Response(400, json={"error": "invalid_grant"})
        now = int(time.time())
        claims = {
            "iss": ISSUER,
            "aud": CLIENT_ID,
            "iat": now,
            "exp": now + 300,
            "nonce": given["nonce"],
            **self.people[given["login"]],
            **self.claims_changed,
        }
        claims = {name: value for name, value in claims.items() if value is not None}
        token = (self.signer or self.keys[0]).sign(claims)
        return httpx.Response(
            200, json={"id_token": token, "access_token": "x", "token_type": "Bearer"}
        )
```

"""An OIDC source as it is kept and tested (spec 5): its settings checked, its secret
sealed and bound to its issuer, the provider's metadata and keys asked for and kept an
hour, and the address to register at the provider."""

import pytest

from tests.accounts import error_code
from tests.security.provider import CLIENT_ID, CLIENT_SECRET, ISSUER

SOURCES = "/api/v1/auth-sources"


def oidc(name: str = "Corp SSO", **settings) -> dict:
    return {
        "kind": "oidc",
        "name": name,
        "settings": {
            "issuer": ISSUER,
            "client_id": CLIENT_ID,
            "client_secret": CLIENT_SECRET,
            **settings,
        },
    }


async def test_an_oidc_source_is_kept_with_its_defaults_and_its_secret_sealed(admin_client):
    made = await admin_client.post(SOURCES, json=oidc(issuer=f"{ISSUER}/", scopes="email groups"))

    assert made.status_code == 201, made.text
    body = made.json()
    assert body["settings"] == {
        "issuer": ISSUER,  # without the slash it was given with
        "client_id": CLIENT_ID,
        "scopes": ["openid", "email", "groups"],
        "require_verified_email": False,
        "username_claim": "preferred_username",
        "name_claim": "name",
        "email_claim": "email",
        "groups_claim": "groups",
    }
    assert body["secrets"] == ["client_secret"]
    assert CLIENT_SECRET not in made.text


async def test_the_address_to_register_at_the_provider_is_under_the_base_url(admin_client):
    made = (await admin_client.post(SOURCES, json=oidc())).json()
    callback = f"/api/v1/auth/oidc/{made['id']}/callback"

    await admin_client.put(
        "/api/v1/settings/base-url", json={"base_url": "https://repo.example.org"}
    )
    based = (await admin_client.get(f"{SOURCES}/{made['id']}")).json()

    assert made["redirect_uri"] == f"https://test{callback}"
    assert based["redirect_uri"] == f"https://repo.example.org{callback}"

"""OIDC sign-in sources (spec 5): people sign in at an identity provider (Keycloak, Entra
ID, Okta, Google), which sends them back with a code; the code is traded for an ID token,
which says who they are.

Here are the kind, its settings, and the provider's side of it: its metadata and keys,
kept for an hour.
"""

import re
import time
import uuid
from dataclasses import dataclass
from typing import Any
from urllib.parse import urlsplit

import httpx
import structlog

from megooarti.security import sources
from megooarti.security.sources import Outbound, SourceUnavailable, Tested, invalid

log = structlog.get_logger(__name__)

KIND = "oidc"
# How long a provider's metadata and keys are kept before they are asked for again.
KEPT_SECONDS = 3600
# How far a provider's clock may be from ours (spec 5).
SKEW_SECONDS = 300
# What an ID token may be signed with: never `none`, nor a secret shared with us (HS*).
ALGORITHMS = frozenset(
    {"RS256", "RS384", "RS512", "PS256", "PS384", "PS512", "ES256", "ES384", "ES512", "EdDSA"}
)
DEFAULT_SCOPES = ["openid", "profile", "email"]
CLAIMS = {
    "username_claim": "preferred_username",
    "name_claim": "name",
    "email_claim": "email",
    "groups_claim": "groups",
}
# A scope as RFC 6749 3.3 has it; a claim's name as JSON keys go, without anything odd.
_SCOPE = re.compile(r"[\x21\x23-\x5b\x5d-\x7e]{1,128}")
_CLAIM = re.compile(r"[A-Za-z0-9_.:/-]{1,128}")


@dataclass(frozen=True)
class Provider:
    """What a provider's metadata says, as far as sign-in needs it."""

    issuer: str
    authorization_endpoint: str
    token_endpoint: str
    jwks_uri: str
    algorithms: frozenset[str]
    auth_methods: frozenset[str]


# url -> (when it was fetched, what it was): metadata and keys alike.
_kept: dict[str, tuple[float, Any]] = {}


def forget() -> None:
    """Forget every provider's metadata and keys (for the tests)."""
    _kept.clear()


def _url(value: Any, field: str) -> str:
    text = str(value or "").strip().rstrip("/")
    parts = urlsplit(text)
    if parts.scheme not in ("http", "https") or not parts.hostname:
        raise invalid(field, "Must be an http or https address.")
    if parts.username or parts.password or parts.query or parts.fragment:
        raise invalid(field, "Must have no user name, password, query or fragment.")
    return text


class OidcKind(sources.Kind):
    name = KIND
    secrets = ("client_secret",)
    # The secret is sent to the issuer's token endpoint: to another issuer, it is asked again.
    bound = ("issuer", "client_id")
    in_browser = True

    def checked(self, settings: dict[str, Any]) -> dict[str, Any]:
        client_id = str(settings.get("client_id") or "").strip()
        if not 1 <= len(client_id) <= 255:
            raise invalid("settings.client_id", "The client ID the provider gave is required.")
        scopes = settings.get("scopes", DEFAULT_SCOPES)
        if isinstance(scopes, str):
            scopes = scopes.split()
        if not isinstance(scopes, list) or not all(
            isinstance(scope, str) and _SCOPE.fullmatch(scope) for scope in scopes
        ):
            raise invalid("settings.scopes", "Scopes are words without spaces or quotes.")
        values: dict[str, Any] = {
            "issuer": _url(settings.get("issuer"), "settings.issuer"),
            "client_id": client_id,
            "client_secret": settings.get("client_secret") or None,
            # openid first, as every provider wants it, and each once.
            "scopes": list(dict.fromkeys(["openid", *scopes])),
            "require_verified_email": bool(settings.get("require_verified_email", False)),
        }
        for name, default in CLAIMS.items():
            claim = str(settings.get(name) or default).strip()
            if not _CLAIM.fullmatch(claim):
                raise invalid(f"settings.{name}", "A claim's name is letters, digits and . _ : / -")
            values[name] = claim
        return values

    async def test(self, outbound, settings, name, password) -> Tested:
        provider = await discover(outbound, settings["issuer"], fresh=True)
        keys = await _keys(outbound, provider, fresh=True)
        signs = ", ".join(sorted(provider.algorithms & ALGORITHMS)) or "nothing this server takes"
        found = len(keys.get("keys", []))
        return Tested(True, f"{provider.issuer} answered. It signs with {signs}; {found} keys.")

    def callback_path(self, source_id: uuid.UUID) -> str:
        return f"/api/v1/auth/oidc/{source_id}/callback"


# --- The provider -----------------------------------------------------------------------


async def _get_json(outbound: Outbound, url: str, fresh: bool) -> Any:
    kept = _kept.get(url)
    if kept is not None and not fresh and time.monotonic() - kept[0] < KEPT_SECONDS:
        return kept[1]
    try:
        response = await outbound.http.get(url, headers={"Accept": "application/json"})
    except httpx.HTTPError as error:
        raise SourceUnavailable(f"{url} could not be reached: {type(error).__name__}.") from None
    if response.status_code != 200:
        raise SourceUnavailable(f"{url} answered {response.status_code}.")
    try:
        value = response.json()
    except ValueError:
        raise SourceUnavailable(f"{url} did not answer JSON.") from None
    if not isinstance(value, dict):
        raise SourceUnavailable(f"{url} did not answer a JSON object.")
    _kept[url] = (time.monotonic(), value)
    return value


async def discover(outbound: Outbound, issuer: str, *, fresh: bool = False) -> Provider:
    """The provider's metadata, from `<issuer>/.well-known/openid-configuration`."""
    said = await _get_json(outbound, f"{issuer}/.well-known/openid-configuration", fresh)
    # The metadata must name the very issuer it was asked of (OpenID Discovery 4.3).
    if said.get("issuer") != issuer:
        raise SourceUnavailable(f"The provider calls itself {said.get('issuer')!r}, not {issuer}.")
    endpoints = {}
    for name in ("authorization_endpoint", "token_endpoint", "jwks_uri"):
        value = said.get(name)
        if not isinstance(value, str) or urlsplit(value).scheme not in ("http", "https"):
            raise SourceUnavailable(f"The provider's metadata has no {name}.")
        endpoints[name] = value
    return Provider(
        issuer=issuer,
        **endpoints,
        algorithms=frozenset(said.get("id_token_signing_alg_values_supported") or ["RS256"]),
        auth_methods=frozenset(
            said.get("token_endpoint_auth_methods_supported") or ["client_secret_basic"]
        ),
    )


async def _keys(outbound: Outbound, provider: Provider, *, fresh: bool = False) -> dict:
    keys = await _get_json(outbound, provider.jwks_uri, fresh)
    if not isinstance(keys.get("keys"), list):
        raise SourceUnavailable("The provider's keys are not a JSON Web Key Set.")
    return keys


sources.register(OidcKind())

"""Signing in at an OIDC provider (spec 5): the two addresses a browser goes through.

`start` sends the browser to the provider, keeping what this sign-in needs sealed in a
cookie of ten minutes; `callback` is where the provider sends it back, with a code, which
is traded for an ID token. Either ends at the sign-in screen: signed in, it goes on to
where the person was going; else it says why not, in words of its own.

import secrets
import uuid
from urllib.parse import quote, urlencode

import structlog

COOKIE_PATH = "/api/v1/auth/oidc/"
LASTS_SECONDS = 600
SIGN_IN = "/login"


async def _sign_in_screen(db: AsyncSession, **query: str) -> RedirectResponse:
    """Back to the sign-in screen, which goes on to `next` once signed in (the UI checks
    that it is an address of its own), or says why the sign-in did not happen."""
    base = (await get_setting(db, "base_url") or "").rstrip("/")
    said = urlencode({name: value for name, value in query.items() if value}, quote_via=quote)
    return RedirectResponse(f"{base}{SIGN_IN}{'?' + said if said else ''}", status_code=302)


async def _source(db: AsyncSession, source_id: uuid.UUID) -> AuthSource | None:
    source = await sources.get_source(db, source_id)
    if source is None or source.kind != oidc.KIND or not source.enabled:
        return None
    return source


def _opened(request: Request, source: AuthSource) -> dict:
    return sources.opened_settings(
        request.app.state.settings, sources.KINDS[oidc.KIND], source.settings
    )


@router.get("/{source_id}/start", response_class=RedirectResponse, status_code=302)
async def start(
    source_id: uuid.UUID,
    request: Request,
    next: str = "",
    db: AsyncSession = Depends(get_session),
) -> RedirectResponse:
    """Send the browser to the provider to sign in, with a state, a nonce and PKCE."""
    next = next[:2048]
    source = await _source(db, source_id)
    if source is None:
        return await _sign_in_screen(db, error="unavailable", next=next)
    settings = _opened(request, source)
    try:
        provider = await oidc.discover(sources.outbound(request.app), settings["issuer"])
    except sources.SourceUnavailable as error:
        log.warning("oidc_unavailable", source=source.name, error=str(error))
        return await _sign_in_screen(db, error="unavailable", next=next)
    started = oidc.Started.new()
    back = await redirect_uri(db, request, source)
    kept = {
        "source": str(source.id),
        "state": started.state,
        "nonce": started.nonce,
        "verifier": started.verifier,
        "next": next,
        "redirect_uri": back,
    }
    response = RedirectResponse(
        oidc.authorization_address(provider, settings, started, back), status_code=302
    )
    response.set_cookie(
        COOKIE,
        seal_at(request.app.state.settings, json.dumps(kept), utcnow()),
        max_age=LASTS_SECONDS,
        httponly=True,
        secure=request.app.state.settings.session_cookie_secure,
        samesite="lax",  # sent along when the provider sends the browser back
        path=COOKIE_PATH,
    )

        response.delete_cookie(COOKIE, path=COOKIE_PATH)
        return response

    if kept is None:
        return await failed("expired", "no sign-in was started here, or it took too long")
    if kept["source"] != str(source_id) or not secrets.compare_digest(kept["state"], state):
        return await failed("failed", "the state is not this browser's sign-in")
    source = await _source(db, source_id)
    if source is None:
        return await failed("unavailable", "the source is not there, or is off")
    if error:
        return await failed("denied", f"the provider answered {error}")
    settings = _opened(request, source)
    reach = sources.outbound(request.app)
    try:
        provider = await oidc.discover(reach, settings["issuer"])
        # RFC 9207: a provider that names itself must name this one.
        if iss and iss != provider.issuer:
            raise oidc.NotChecked(f"the answer came from {iss}")
        token = await oidc.exchange(
            reach, provider, settings, code, kept["verifier"], kept["redirect_uri"]
        )
        claims = await oidc.verify(reach, provider, settings, token, kept["nonce"])
        identity = oidc.identity(claims, settings)
    except sources.SourceUnavailable as problem:
        return await failed("unavailable", str(problem))
    except oidc.NotChecked as problem:
        return await failed("failed", str(problem))
    except oidc.Refused as problem:
        return await failed("refused", str(problem))
    user = await sources.provision(db, source, identity)
    if not await users.can_act(db, user):
        return await failed("refused", f"{user.username} may not sign in")
    response = await _sign_in_screen(db, next=next, signed_in="1")
    await start_session(db, request, response, user, source=source.name)
    response.delete_cookie(COOKIE, path=COOKIE_PATH)
    return response
```

/** One row: the members of a group are given a role. */
export type Grant = { group: string; role: string };
export type Mapping = { group: string; roles: string[] }[];

/** A source's mapping as rows, one a group and a role. */
export function toGrants(mapping: Mapping): Grant[] {
  return mapping.flatMap(({ group, roles }) => roles.map((role) => ({ group, role })));
}

/** Rows as the API keeps them: each group once, with its roles. A row half filled is left out. */
export function toMapping(grants: Grant[]): Mapping {
  const byGroup = new Map<string, string[]>();
  for (const { group, role } of grants) {
    const named = group.trim();
    if (named === "" || role === "") continue;
    const roles = byGroup.get(named) ?? [];
    if (!roles.includes(role)) roles.push(role);
    byGroup.set(named, roles);
  }
  return Array.from(byGroup, ([group, roles]) => ({ group, roles }));
}

/**
 * The roles a source's groups give (E4): a row says that the members of a group are given
 * a role. They are given it at each sign-in, and it is taken back when they are no longer.
 */
export function GroupMapping({
  grants,
  roles,
  onChange,
  error,
}: {
  grants: Grant[];
  /** The roles there are, to choose from. */
  roles: string[];
  onChange: (grants: Grant[]) => void;
  error?: string;
}) {
  const t = useTranslations("source");
  // A role a row has is offered, whether or not the roles there are came yet, or can be seen.
  const offered = Array.from(new Set([...roles, ...grants.map((grant) => grant.role)]))
    .filter(Boolean)
    .sort();
  const set = (index: number, changed: Partial<Grant>) =>
    onChange(grants.map((grant, at) => (at === index ? { ...grant, ...changed } : grant)));

      <legend className="label-caps mb-2 text-fg-muted">{t("mapping")}</legend>
