# NuGet V2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A NuGet repository serves NuGet's V2 protocol beside V3, so that `nuget.exe`, Chocolatey's `choco` and PowerShell's PSResourceGet push to it, find and install from it; and a NuGet proxy can cache a V2 feed, the Chocolatey community feed or the PowerShell Gallery.

**Architecture:** V2 is OData's Atom feeds of versions. A pure module reads a V2 request into a query (`nuget/odata.py`), answering only what the clients of D7 were seen to send; another writes the feeds (`nuget/atom.py`). A hosted repository answers each query from the same records as its V3 documents, on each request (`nuget/v2.py`): a query of one id reads that id's versions, a query of many takes its ids a page at a time from the database. A proxy whose `format_config.protocol` is `v2` passes each query on as it came and makes the feed's addresses its own in what it answers (`nuget/proxied_v2.py`), keeping answers by their whole query and packages where pushed ones are. The setup snippets gain Chocolatey and PowerShell, and three new client tests run `nuget.exe` under Mono, `choco` and `pwsh` against the built image.

**Tech Stack:** Python 3.13, FastAPI, `xml.sax.saxutils`; pytest with the in-process stand-in remote; Mono with `nuget.exe` 6.14, Chocolatey 2.7.4 and PowerShell 7.5 (PSResourceGet 1.1) for the real-client tests, the community feed and the Gallery for their proxies.

**Spec:** [docs/superpowers/specs/2026-10-15-nuget-design.md](../specs/2026-10-15-nuget-design.md), sections 4.2, 4.3, 5 (V2, usage and setup), 6 (a V2 proxy), 7.3 (the queries answered), 9, 10 and the row of plan 13d in section 12, with what plans 13a to 13c settled (W, X and Y in section 4).

## Global Constraints

- **A format never touches a table or a file**: what V2 reads of a hosted repository is the context's (`spelling`, `components`, `components_of`, `package_page`, `respond`), and what a V2 proxy keeps is the proxy engine's (`proxy.document`, `proxy.ask`, `proxy.ensure_cached`).
- **What is read of a remote is bounded**: a V2 answer at 16 MiB, the feed's `$metadata` at 1 MiB.
- **What is asked of a remote goes with its credential**: a V2 proxy asks its feed only for a path of V2's feed or a package, escaped as an address is (X9).
- **A V2 page is at most 100 versions**; a query of many ids reads at most 10,000 of them, and says so past that.
- **Every test of a stack is marked `docker`.** The proxies' real-client tests reach the community feed and the Gallery.
- **A table's line under its headings is `| --- | --- |`** (one `---` cell a column). Commits end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

**Working directories:** run `uv` and `pytest` commands in `backend/`, and `git` commands in the repository root. Backend tests need the `db` Compose service; set `MEGOOARTI_TEST_DATABASE_URL` as `docs/development.md` describes.

## Review Focus

What the tests of this plan do not reach, most likely first. The reviewer reads for these.

1. **What the feeds send that the stand-in does not**: a V2 answer gzipped, in JSON, or naming its packages on another host; a `next` link with `$skiptoken` that the proxy passes on; the Gallery's `$top=6000` answer near the 16 MiB bound; a feed that redirects a query.
2. **Ids and versions as clients write them**: `Packages(Id='MEGOOARTI.HELLO',Version='1.0.0.0')`, `package/<id>/<version>` with a version not normalized, an id spelled otherwise than its first push, a version whose package wrote it with build metadata.
3. **Queries of many ids**: `Packages()` with no `$filter` over a repository of thousands of ids, `$inlinecount=allpages` that reads them all, an order across ids by `Published`, the bound of 10,000 ids.
4. **OData's text**: a literal with a doubled quote, a search term with `&`, `%` or `'`, a literal that contains ` and `, parentheses around a whole `$filter`.
5. **What V2 gives a client to follow**: the `next` link's encoding as each client reads it, `edit-media` links, the `content` address of a version on a proxy, an entry's `Version` against its `NormalizedVersion`.

```python
"""What a request of NuGet's V2 protocol asks for: its function, its arguments and its
OData options, as the clients of the spec's D7 send them.

Pure functions. Only what those clients send is read (7.3 of the spec); anything else
is refused with a message that names it, rather than answered as if it were understood.
"""

import re
from collections.abc import Mapping
from dataclasses import dataclass, field

from megooarti.repositories.nuget import versions

# A page of a V2 feed, at most, as nuget.org's (section 9 of the spec).
TOP_MOST = 100

PACKAGES = "packages"
FIND = "find"
SEARCH = "search"
ENTRY = "entry"

_FUNCTIONS = {"Packages": PACKAGES, "FindPackagesById": FIND, "Search": SEARCH}
_ENTRY = re.compile(r"Packages\(Id='(?P<id>(?:[^']|'')*)',Version='(?P<version>(?:[^']|'')*)'\)")
_ORDERS = {
    "id": "id",
    "version": "version",
    "normalizedversion": "version",
    "downloadcount": "downloads",
    "published": "published",
    "lastupdated": "published",
    "created": "published",
}
# The options and arguments a client may send, by function.
_OPTIONS = {"$filter", "$orderby", "$skip", "$top", "$inlinecount", "semVerLevel"}
_ARGUMENTS = {
    PACKAGES: set(),
    FIND: {"id"},
    SEARCH: {"searchTerm", "targetFramework", "includePrerelease"},
    ENTRY: set(),
}


class UnsupportedQuery(Exception):
    """A request of V2 that this server does not answer. The message says what in it."""


@dataclass(frozen=True)
class Filter:
    """What `$filter` asks of a version: each condition given must hold. Text is in
    lower case; a version is normalized."""

    id: str = ""  # `Id eq '…'`
    id_starts: str = ""  # `startswith(Id, '…')`
    id_contains: str = ""  # `substringof('…', Id)`
    tags: tuple[str, ...] = ()  # `substringof('…', Tags)`: each is in its tags
    versions: tuple[tuple[str, str], ...] = ()  # `NormalizedVersion ge '…'`: (operator, version)
    latest: bool = False  # the newest stable version of its id
    absolute_latest: bool = False  # the newest of its id, prereleases too
    prerelease: bool | None = None  # `IsPrerelease eq …`


@dataclass(frozen=True)
class Query:
    function: str
    id: str = ""  # FindPackagesById's, or the entry's: as given
    version: str = ""  # the entry's: normalized, lower case
    search_term: str = ""
    prerelease: bool = True  # whether a prerelease may be shown
    filter: Filter = field(default_factory=Filter)
    order: tuple[tuple[str, bool], ...] = ()  # (what, descending)
    skip: int = 0
    top: int = TOP_MOST
    inline_count: bool = False
    count: bool = False  # `…/$count`: how many there are, as text


def _literal(text: str, name: str) -> str:
    """A string literal of OData: in single quotes, a quote in it doubled."""
    text = text.strip()
    if len(text) < 2 or text[0] != "'" or text[-1] != "'":
        raise UnsupportedQuery(f"{name} is a string in single quotes")
    inner = text[1:-1]
    if re.search(r"(?<!')'(?!')", inner.replace("''", "")):
        raise UnsupportedQuery(f"{name} has a quote that is not doubled")
    return inner.replace("''", "'")


def _number(text: str, name: str) -> int:
    if not (text.isascii() and text.isdigit() and len(text) <= 9):
        raise UnsupportedQuery(f"{name} is a whole number, 0 or more")
    return int(text)


_OPERATORS = ("eq", "ne", "gt", "ge", "lt", "le")
_STRING = r"('(?:[^']|'')*')"
_FLAG = re.compile(r"(IsLatestVersion|IsAbsoluteLatestVersion)(\s+eq\s+true)?")
_PRERELEASE = re.compile(r"IsPrerelease\s+eq\s+(true|false)")
_ID = re.compile(rf"(?:Id|tolower\(Id\))\s+eq\s+{_STRING}")
_VERSION = re.compile(rf"(?:Version|NormalizedVersion)\s+({'|'.join(_OPERATORS)})\s+{_STRING}")
_STARTS = re.compile(rf"startswith\((?:Id|tolower\(Id\)),\s*{_STRING}\)(\s+eq\s+true)?")
_CONTAINS = re.compile(rf"substringof\({_STRING},\s*(Id|tolower\(Id\)|Tags)\)(\s+eq\s+true)?")


def _unwrapped(text: str) -> str:
    """A condition without the parentheses around all of it."""
    text = text.strip()
    while text.startswith("(") and text.endswith(")"):
        depth = 0
        for at, character in enumerate(text):
            depth += {"(": 1, ")": -1}.get(character, 0)
            if depth == 0 and at < len(text) - 1:
                return text  # the first parenthesis closes before the end
        text = text[1:-1].strip()
    return text


def _condition(text: str, found: dict[str, object]) -> None:
    """One condition of `$filter`, read into what it asks for."""
    if (flag := _FLAG.fullmatch(text)) is not None:
        found["latest" if flag[1] == "IsLatestVersion" else "absolute_latest"] = True
    elif (prerelease := _PRERELEASE.fullmatch(text)) is not None:
        found["prerelease"] = prerelease[1] == "true"
    elif (compared := _ID.fullmatch(text)) is not None:
        found["id"] = _literal(compared[1], "Id").lower()
    elif (compared := _VERSION.fullmatch(text)) is not None:
        value = _literal(compared[2], "Version")
        # A version that is none matches nothing: no version has it.
        normalized = (versions.normalize(value) or f"none:{value}").lower()
        found["versions"] = (*found.get("versions", ()), (compared[1], normalized))  # type: ignore[misc]
    elif (starts := _STARTS.fullmatch(text)) is not None:
        found["id_starts"] = _literal(starts[1], "startswith").lower()
    elif (contains := _CONTAINS.fullmatch(text)) is not None:
        value = _literal(contains[1], "substringof").lower()
        if contains[2] == "Tags":
            found["tags"] = (*found.get("tags", ()), value)  # type: ignore[misc]
        else:
            found["id_contains"] = value
    else:
        raise UnsupportedQuery(f"$filter does not take {text!r} here")


def _filter(text: str) -> Filter:
    found: dict[str, object] = {}
    for part in re.split(r"\s+and\s+", _unwrapped(text)):
        _condition(_unwrapped(part), found)
    return Filter(**found)  # type: ignore[arg-type]


def _order(text: str) -> tuple[tuple[str, bool], ...]:
    order = []
    for part in text.split(","):
        words = part.split()
        what = _ORDERS.get(words[0].lower()) if words else None
        direction = words[1].lower() if len(words) == 2 else "asc"
        if what is None or len(words) > 2 or direction not in ("asc", "desc"):
            raise UnsupportedQuery(f"$orderby does not take {part.strip()!r}")
        order.append((what, direction == "desc"))
    return tuple(order)


def _function(path: str) -> tuple[str, str, str, bool]:
    """A path's function, the id and version of an entry, and whether it is `/$count`."""
    count = path.endswith("/$count")
    path = path.removesuffix("/$count")
    entry = _ENTRY.fullmatch(path)
    if entry is not None and not count:
        return ENTRY, entry["id"].replace("''", "'"), entry["version"].replace("''", "'"), False
    name = path.removesuffix("()")
    if name in _FUNCTIONS:
        return _FUNCTIONS[name], "", "", count
    raise UnsupportedQuery(f"{path!r} is not a function of this feed")


def is_v2(path: str) -> bool:
    """Whether a path is one of V2's: the root, `$metadata`, or a function of its feed."""
    if path in ("", "$metadata"):
        return True
    name = path.removesuffix("/$count")
    return _ENTRY.fullmatch(name) is not None or name.removesuffix("()") in _FUNCTIONS


def parse(path: str, arguments: Mapping[str, str]) -> Query:
    """A request of V2's feed. Raises UnsupportedQuery."""
    function, entry_id, entry_version, count = _function(path)
    unknown = sorted(set(arguments) - _OPTIONS - _ARGUMENTS[function])
    if unknown:
        raise UnsupportedQuery(f"{unknown[0]} is not taken by {path}")
    if function == ENTRY:
        normalized = versions.normalize(entry_version)
        return Query(ENTRY, id=entry_id, version=(normalized or entry_version).lower())
    inline = arguments.get("$inlinecount", "none")
    if inline not in ("allpages", "none"):
        raise UnsupportedQuery("$inlinecount is allpages or none")
    # More than a page is answered with a page, and the address of the next, as nuget.org does.
    top = min(_number(arguments["$top"], "$top"), TOP_MOST) if "$top" in arguments else TOP_MOST
    prerelease = True
    if function == SEARCH:
        flag = arguments.get("includePrerelease", "false").lower()
        if flag not in ("true", "false"):
            raise UnsupportedQuery("includePrerelease is true or false")
        prerelease = flag == "true"
    return Query(
        function,
        id=_literal(arguments["id"], "id") if function == FIND and "id" in arguments else "",
        search_term=_literal(arguments.get("searchTerm", "''"), "searchTerm"),
        prerelease=prerelease,
        filter=_filter(arguments["$filter"]) if arguments.get("$filter") else Filter(),
        order=_order(arguments["$orderby"]) if arguments.get("$orderby") else (),
        skip=_number(arguments.get("$skip", "0") or "0", "$skip"),
        top=top,
        inline_count=inline == "allpages",
        count=count,
    )
```

```python
def entries(answer) -> list[dict[str, str]]:
    """Each entry's properties, and its content's address as `src`."""
    assert answer.status_code == 200, answer.text
    root = ElementTree.fromstring(answer.content)
    found = root.findall(f"{ATOM}entry") if root.tag == f"{ATOM}feed" else [root]
    listed = []
    for entry in found:
        properties = {
            child.tag.removeprefix(D): child.text or "" for child in entry.find(f"{M}properties")
        }
        properties["src"] = entry.find(f"{ATOM}content").get("src")
        listed.append(properties)
    return listed


def versions_of(answer) -> list[tuple[str, str]]:
    return [(one["Id"], one["NormalizedVersion"]) for one in entries(answer)]

    root = ElementTree.fromstring(answer.content)
    links = [link.get("href") for link in root.findall(f"{ATOM}link") if link.get("rel") == "next"]
    return links[0] if links else None
```

```python
"""The documents of NuGet's V2 protocol: OData's Atom feeds of versions, written from
what packages said of themselves.

Pure functions. `base` is the repository's address as a client is given it, ending in
a slash; every address in a document is under it. A version is an entry with the
properties NuGet's clients read, as nuget.org's V2 feed has them.
"""

import base64
from collections.abc import Sequence
from datetime import UTC, datetime
from xml.sax.saxutils import escape, quoteattr

from megooarti.repositories.nuget import versions
from megooarti.repositories.nuget.documents import Published

ATOM = "application/atom+xml;type=feed;charset=utf-8"
ATOM_ENTRY = "application/atom+xml;type=entry;charset=utf-8"
XML = "application/xml;charset=utf-8"
_DECLARATION = '<?xml version="1.0" encoding="utf-8"?>\n'
_NAMESPACES = (
    'xmlns="http://www.w3.org/2005/Atom" '
    'xmlns:d="http://schemas.microsoft.com/ado/2007/08/dataservices" '
    'xmlns:m="http://schemas.microsoft.com/ado/2007/08/dataservices/metadata"'
)
_SCHEME = "http://schemas.microsoft.com/ado/2007/08/dataservices/scheme"
_TYPE = "NuGetGallery.OData.V2FeedPackage"

# Of each id: the normalized versions, in lower case, of its newest stable version and
# of its newest version, prereleases too ("" for none).
Latest = tuple[str, str]


def latest(held: Sequence[Published]) -> Latest:
    """An id's newest stable version, and its newest version, from all it has."""
    ordered = versions.ordered([one.nuspec.version for one in held])
    stable = [one for one in ordered if not versions.parse(one).is_prerelease]  # type: ignore[union-attr]
    return (stable[-1].lower() if stable else "", ordered[-1].lower() if ordered else "")


def _time(when: datetime) -> str:
    """An `Edm.DateTime`, in UTC, as nuget.org writes one."""
    return when.astimezone(UTC).strftime("%Y-%m-%dT%H:%M:%S.%f")[:-3]

    written = []

            written.append(f"::{group.target_framework}")

            f"{dependency.id}:{dependency.range}:{group.target_framework}"
            for dependency in group.dependencies
        ]
    return "|".join(written)
```

```python
"""NuGet's V2 protocol of a hosted repository: OData's Atom feeds of its versions,
written from the same records as V3's documents (E1), on each request (W1).

A query of one id reads that id's versions. A query of many (a `Search()`, or
`Packages()` without an id) takes their ids from the database a page at a time, in the
order of V3's search, and reads each page's versions, until it has the page asked for.
Only a count, or an order across ids by something other than the id, reads them all.
"""

from collections.abc import AsyncIterator, Sequence
from datetime import UTC, datetime
from urllib.parse import quote, urlencode

from starlette.requests import Request
from starlette.responses import Response

from megooarti.errors import ApiError
from megooarti.repositories.content import RepositoryContext
from megooarti.repositories.nuget import atom, odata, paths, queries, records, responses, versions
from megooarti.repositories.nuget.documents import Published

# How many ids are read at a time, for a query of many.
_NAMES_AT_ONCE = 100
# A query of many reads at most this many ids' versions: past it, a client is asked to
# narrow its query.
NAMES_MOST = 10_000

Found = tuple[Published, atom.Latest]


def _unsupported(error: odata.UnsupportedQuery) -> ApiError:
    return ApiError(
        400, "unsupported_query", f"This feed does not answer that query: {error}.", None
    )


_COMPARED = {
    "eq": lambda order: order == 0,
    "ne": lambda order: order != 0,
    "gt": lambda order: order > 0,
    "ge": lambda order: order >= 0,
    "lt": lambda order: order < 0,
    "le": lambda order: order <= 0,
}


def _compare(version: versions.Version, other: str) -> int | None:
    """Where a version is against another: -1, 0 or 1; None if the other is none."""
    parsed = versions.parse(other)
    if parsed is None:
        return None
    mine, theirs = version.sort_key(), parsed.sort_key()
    return (mine > theirs) - (mine < theirs)


def _admits(wanted: odata.Filter, held: Published, newest: atom.Latest) -> bool:
    """Whether a version holds each condition of a query's `$filter`."""
    nuspec = held.nuspec
    lower, version = nuspec.id.lower(), nuspec.version.lower()
    parsed = versions.parse(nuspec.version)
    if parsed is None or (wanted.id and lower != wanted.id):
        return False
    if not lower.startswith(wanted.id_starts) or wanted.id_contains not in lower:
        return False
    tags = nuspec.tags.lower().split()
    if any(not any(tag in one for one in tags) for tag in wanted.tags):
        return False
    for operator, other in wanted.versions:
        order = _compare(parsed, other)
        if order is None or not _COMPARED[operator](order):
            return False
    if wanted.prerelease is not None and parsed.is_prerelease != wanted.prerelease:
        return False
    if wanted.latest and version != newest[0]:
        return False
    return not wanted.absolute_latest or version == newest[1]


def _chosen(held: Sequence[Published], query: odata.Query) -> list[Found]:
    """The versions of one id that a query asks for, the oldest first."""
    newest = atom.latest(held)
    found = [
        (one, newest)
        for one in held
        if (query.prerelease or not one.nuspec.is_prerelease) and _admits(query.filter, one, newest)
    ]
    return sorted(
        found,
        key=lambda pair: versions.parse(pair[0].nuspec.version).sort_key(),  # type: ignore[union-attr]
    )


async def _names(context: RepositoryContext, query: odata.Query) -> AsyncIterator[list[str]]:
    """The ids a query may be of, a page at a time, in the order of V3's search. Its
    `$filter` is held to each of their versions after."""
    wanted = query.filter
    package_id = query.id if query.function == odata.FIND else wanted.id
    if package_id:
        spelling = await context.spelling("", package_id)
        if spelling is not None:
            yield [spelling]
        return
    searched = queries.parse({"q": query.search_term})
    stable = not query.prerelease or wanted.prerelease is False or wanted.latest
    # Ordered by id, the ids are taken in that order; else as V3's search ranks them.
    by_id = bool(query.order) and query.order[0][0] == "id"
    ranked = " ".join(searched.words) or searched.exact_id or wanted.id_starts
    for offset in range(0, NAMES_MOST, _NAMES_AT_ONCE):
        names, _ = await context.package_page(
            "",
            [*searched.words, *wanted.tags],
            exact=searched.exact_id,
            containing=searched.id_contains or wanted.id_contains or wanted.id_starts,
            ranked_by="" if by_id else ranked,
            stable_only=stable,
            limit=_NAMES_AT_ONCE,
            offset=offset,
        )
        if names:
            yield names
        if len(names) < _NAMES_AT_ONCE:
            return
    raise ApiError(
        400,
        "unsupported_query",
        f"This query is of more than {NAMES_MOST} ids: narrow it with a search term or an id.",
        None,
    )


def _sort_key(order: tuple[str, bool]):
    what, _ = order

    def key(pair: Found):
        held = pair[0]
        if what == "id":
            return held.nuspec.id.lower()
        if what == "version":
            return versions.parse(held.nuspec.version).sort_key()  # type: ignore[union-attr]
        if what == "published":
            return held.published
        return 0  # downloads: MegooArti counts none, so the order stays as it is

    return key


def _ordered(found: list[Found], order: Sequence[tuple[str, bool]]) -> list[Found]:
    for one in reversed(order):  # the first is sorted by last, as a stable sort allows
        found = sorted(found, key=_sort_key(one), reverse=one[1])
    return found


def _in_name_order(order: Sequence[tuple[str, bool]]) -> bool:
    """Whether an order keeps each id's versions together, in the ids' order."""
    return all(what in ("id", "downloads") for what, _ in order[:1]) and not any(
        descending for what, descending in order if what == "id"
    )


async def _found(
    context: RepositoryContext, query: odata.Query
) -> tuple[list[Found], bool, int | None]:
    """The page a query asks for, whether there is more, and how many there are if the
    query asks for that."""
    wanted = query.skip + query.top
    every = query.count or query.inline_count or not _in_name_order(query.order)
    found: list[Found] = []
    async for names in _names(context, query):
        held = await context.components_of("", names)
        for name in names:
            found += _chosen(records.published(held.get(name, [])), query)
        if not every and len(found) > wanted:
            break
    total = len(found) if every else None
    found = _ordered(found, query.order)
    return found[query.skip : wanted], len(found) > wanted, total


def _next(base: str, path: str, request: Request, query: odata.Query) -> str:
    """The address of the page after this one: the same query, `$skip` past it."""
    arguments = [
        (name, value) for name, value in request.query_params.multi_items() if name != "$skip"
    ]
    arguments.append(("$skip", str(query.skip + query.top)))
    return f"{base}{path}?{urlencode(arguments, quote_via=quote, safe=chr(39) + '$(),')}"


async def _respond(
    context: RepositoryContext, request: Request, data: bytes, content_type: str
) -> Response:
    return await responses.respond(context, request, data, content_type, "feed.xml")


async def _entry(context: RepositoryContext, request: Request, query: odata.Query) -> Response:
    spelling = await context.spelling("", query.id)
    held = [] if spelling is None else records.published(await context.components("", spelling))
    chosen = [one for one in held if one.nuspec.version.lower() == query.version]
    if not chosen:
        raise ApiError(404, "not_found", f"This repository has no {query.id} {query.version}.")
    base = await responses.base(context, request)
    document = atom.entry(base, chosen[0], atom.latest(held))
    return await _respond(context, request, document, atom.ATOM_ENTRY)


async def download(
    context: RepositoryContext, request: Request, parsed: paths.NuGetPath
) -> Response:
    """`package/<id>/<version>`: V2's address of a package."""
    spelling = await context.spelling("", parsed.id)
    if spelling is None:
        raise ApiError(404, "not_found", f"This repository has no package {parsed.id}.")
    return await context.respond(paths.package_path(spelling, parsed.version), request)


async def answer(context: RepositoryContext, request: Request, path: str) -> Response:
    """A request of V2's feed: its root, `$metadata`, or a query of its versions."""
    base = await responses.base(context, request)
    if path == "":
        return await _respond(context, request, atom.service_document(base), atom.XML)
    if path == "$metadata":
        return await _respond(context, request, atom.METADATA, atom.XML)
    try:
        query = odata.parse(path, request.query_params)
    except odata.UnsupportedQuery as error:
        raise _unsupported(error) from None
    if query.function == odata.ENTRY:
        return await _entry(context, request, query)
    page, more, total = await _found(context, query)
    if query.count:
        count = str(total).encode()
        return await responses.respond(context, request, count, "text/plain", "count")
    title = path.removesuffix("()")
    document = atom.feed(
        base,
        title,
        page,
        updated=datetime.now(UTC),
        count=total if query.inline_count else None,
        next_address=_next(base, path, request, query) if more else "",
    )
    return await _respond(context, request, document, atom.ATOM)
```

```python
"""A proxy of a V2 feed: the Chocolatey community feed, the PowerShell Gallery, or any
feed that serves NuGet's V2 protocol (section 6 of the spec).

A client's query is passed on as it came, its path and its query string, and what the
feed answers has the feed's addresses made the proxy's as it is sent: each entry's,
its package's, and the next page's. A query's answer is metadata, kept by the whole
query and asked about again after the proxy's metadata age; a search is passed on every
time and not kept. A package is a cached file, kept where a pushed one would be, and
read as a pushed one is. The feed's `$metadata` is passed on as it is; the root, which
names the one collection, is the proxy's own.
"""

import hashlib
import re
from urllib.parse import quote

from starlette.requests import Request
from starlette.responses import Response

from megooarti.errors import ApiError
from megooarti.repositories import proxy
from megooarti.repositories.content import RepositoryContext
from megooarti.repositories.nuget import atom, paths, responses
from megooarti.repositories.proxy import Absent, Answer, Source

# Where what the feed answered is kept: paths no client asks for.
KEPT = ".remote/"
METADATA = f"{KEPT}$metadata"
ANSWERS = f"{KEPT}v2/"
SEARCHES = f"{KEPT}v2/search"
# What is read of the feed's answers, at the most.
FEED_MOST = 16 * 1024 * 1024
METADATA_MOST = 1024 * 1024
# What of a function's path is sent as it is: its parentheses, quotes, `=` and commas.
_SAFE = "()'=,$/"
_ADDRESS = re.compile(r'(xml:base|href|src)="([^"]*)"')
_ID = re.compile(r"<id>([^<]*)</id>")


def _not_found() -> ApiError:
    return ApiError(404, "not_found", "Nothing is served at this address.")


def root(context: RepositoryContext) -> str:
    """The feed's root, ending in a slash."""
    return context.repository.config["proxy"]["remote_url"].rstrip("/") + "/"


def kept_path(path: str, query: str) -> str:
    """Where the answer to a query is kept: by the whole query, path and string."""
    return f"{ANSWERS}{hashlib.sha256(f'{path}?{query}'.encode()).hexdigest()}.xml"


def rewrite(data: bytes, feed: str, base: str) -> bytes:
    """An answer of the feed with its addresses made the proxy's: those under the feed's
    root as the proxy is given it, and under the root the answer names (`xml:base`)."""
    text = data.decode("utf-8")
    declared = re.search(r'xml:base="([^"]*)"', text)
    prefixes = {feed.rstrip("/")} | ({declared[1].rstrip("/")} if declared else set())
    ordered = sorted((prefix for prefix in prefixes if prefix), key=len, reverse=True)
    target = base.rstrip("/")

    def swap(value: str) -> str:
        for prefix in ordered:
            if value == prefix or value.startswith(prefix + "/"):
                return target + value[len(prefix) :]
        return value

    text = _ADDRESS.sub(lambda found: f'{found[1]}="{swap(found[2])}"', text)
    text = _ID.sub(lambda found: f"<id>{swap(found[1])}</id>", text)
    return text.encode("utf-8")


def _content_type(path: str) -> str:
    if path.endswith("/$count"):
        return "text/plain"
    if path.startswith("Packages(") and path.endswith(")"):
        return atom.ATOM_ENTRY
    return atom.ATOM


async def _answer(context: RepositoryContext, request: Request, path: str) -> bytes:
    """What the feed answers a query: kept, or for a search, asked each time."""
    query = request.url.query
    address = f"{root(context)}{quote(path, safe=_SAFE)}" + (f"?{query}" if query else "")
    if path.split("/")[0].removesuffix("()") != "Search":
        return await proxy.document(
            context,
            kept_path(path, query),
            Source(address),
            limit=FEED_MOST,
            content_type=_content_type(path),
        )
    answer = await proxy.ask(
        context, SEARCHES, Source(address, remember_missing=False, blocks=False), limit=FEED_MOST
    )
    if isinstance(answer, Absent):
        raise _not_found()
    if not isinstance(answer, Answer):
        raise answer.error
    return answer.body


async def handle_proxy(context: RepositoryContext, request: Request, path: str) -> Response:
    """Answer a request to a V2 proxy. The route has checked `read`."""
    if request.method not in ("GET", "HEAD"):
        raise ApiError(
            405,
            "method_not_allowed",
            "A proxy repository accepts GET and HEAD.",
            headers={"Allow": "GET, HEAD"},
        )
    base = await responses.base(context, request)
    if path == "":
        document = atom.service_document(base)
        return await responses.respond(context, request, document, atom.XML, "feed.xml")
    if path == "$metadata":
        data = await proxy.document(
            context,
            METADATA,
            Source(f"{root(context)}$metadata"),
            limit=METADATA_MOST,
            content_type=atom.XML,
        )
        return await responses.respond(context, request, data, atom.XML, "metadata.xml")
    parsed = paths.classify(path)
    if parsed.kind == "v2":
        data = await _answer(context, request, path)
        content_type = _content_type(path)
        if content_type != "text/plain":
            try:
                data = rewrite(data, root(context), base)
            except UnicodeDecodeError:
                raise await proxy.refuse(
                    context, path, "it sent an answer that is not UTF-8"
                ) from None
        return await responses.respond(context, request, data, content_type, "feed.xml")
    if parsed.kind == "download":
        package_id, version = path.split("/")[1:]
        kept = paths.package_path(parsed.id, parsed.version)
        address = f"{root(context)}package/{quote(package_id, safe='')}/{quote(version, safe='')}"
        await proxy.ensure_cached(context, kept, source=Source(address))
        return await context.respond(kept, request)
    raise _not_found()
```

```python
def hosted(name: str = "nuget-hosted") -> dict:
    return {"name": name, "format": "nuget", "type": "hosted"}


def proxy(name: str, remote_url: str, protocol: str = "v3") -> dict:
    return {
        "name": name,
        "format": "nuget",
        "type": "proxy",
        "format_config": {"protocol": protocol},
        # Not left alone after one failure: the internet may be slow once.
        "proxy": {"remote_url": remote_url, "auto_block": False},
    }


def run(
    image: str,
    work: Path,
    command: list[str],
    *,
    volumes: dict[Path, str] | None = None,
    environment: dict[str, str] | None = None,
) -> subprocess.CompletedProcess[str]:
    """Run a command in a client's image, beside the stack, in `work` (as /work)."""
    mounts = [f"{work}:/work", *(f"{path}:{at}" for path, at in (volumes or {}).items())]
    settings = {
        "DOTNET_CLI_TELEMETRY_OPTOUT": "1",
        "POWERSHELL_TELEMETRY_OPTOUT": "1",
        **(environment or {}),
    }
    arguments = ["docker", "run", "--rm", "--network", NETWORK, "--workdir", "/work"]
    for mount in mounts:
        arguments += ["--volume", mount]
    for name, value in settings.items():
        arguments += ["--env", f"{name}={value}"]
    return subprocess.run(
        [*arguments, image, *command],
        capture_output=True,
        text=True,
        encoding="utf-8",
        errors="replace",
        timeout=1800,
        check=False,
    )


def said(result: subprocess.CompletedProcess[str]) -> str:
    return f"exit {result.returncode}\n{result.stdout[-3000:]}\n{result.stderr[-3000:]}"


def fetch(path: str, repository: str) -> int:
    """The status of a read of a repository from outside, as `ci`."""
    credentials = base64.b64encode(f"{USERNAME}:{PASSWORD}".encode()).decode()
    request = urllib.request.Request(
        f"http://127.0.0.1:{HTTP_PORT}/repository/{repository}/{path}",
        headers={"Authorization": f"Basic {credentials}"},
    )
    try:
        with urllib.request.urlopen(request, timeout=60) as response:
            return response.status
    except urllib.error.HTTPError as error:
        return error.code
```

```python
@pytest.fixture(scope="module")
def work(administrator, tmp_path_factory) -> tuple[Path, str]:
    """The folder `pwsh` works in, with its scripts; and the token to publish with. A
    hosted repository, and a V2 proxy of the Gallery."""
    token = prepare(
        administrator,
        hosted(HOSTED),
        proxy(GALLERY, "https://www.powershellgallery.com/api/v2/", protocol="v2"),
    )
    folder = tmp_path_factory.mktemp("pwsh")
    for name, script in (("publish.ps1", PUBLISH), ("install.ps1", INSTALL)):
        (folder / name).write_text(script, encoding="utf-8", newline="\n")
    return folder, token


def pwsh(work: tuple[Path, str], script: str, *arguments: str):
    folder, _ = work
    return run(IMAGE, folder, ["pwsh", "-NoProfile", "-File", f"/work/{script}", *arguments])


@pytest.mark.parametrize(
    ("uri", "api_version", "version"),
    [
        # V2's address without its slash: PSResourceGet adds one.
        (f"{ADDRESS}/{HOSTED}", "v2", "1.0.0"),
        (f"{ADDRESS}/{HOSTED}/index.json", "v3", "2.0.0"),
    ],
    ids=["v2", "v3"],
)
def test_psresourceget_publishes_finds_and_installs_a_module(work, uri, api_version, version):
    _, token = work

    done = pwsh(
        work, "publish.ps1", "-Uri", uri, "-ApiVersion", api_version, "-Token", token,
        "-Version", version,
    )  # fmt: skip

    assert done.returncode == 0, said(done)
    assert f"found {MODULE} {version}" in done.stdout
    assert done.stdout.rstrip().endswith(f"hello from {MODULE}")
    assert fetch(f"package/{MODULE}/{version}", HOSTED) == 200


def test_psresourceget_installs_from_a_proxy_of_the_gallery(work):
    installed = pwsh(work, "install.ps1", "-Uri", f"{ADDRESS}/{GALLERY}", "-ApiVersion", "v2")

    assert installed.returncode == 0, said(installed)
    assert f"installed {FROM_GALLERY_VERSION}" in installed.stdout
    lower = FROM_GALLERY.lower()
    kept = f"v3/package/{lower}/{FROM_GALLERY_VERSION}/{lower}.{FROM_GALLERY_VERSION}.nupkg"
    assert fetch(kept, GALLERY) == 404  # kept, and served at V2's address alone
    assert fetch(f"package/{FROM_GALLERY}/{FROM_GALLERY_VERSION}", GALLERY) == 200
```
